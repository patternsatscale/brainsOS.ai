# Knowledge Base (`knowledge/`)

The `knowledge/` directory stores synthesized facts, reference documentation, research notes, and conceptual knowledge generated by human operators and the Hermes agent runtime.

## Open Knowledge Format (OKF) Guidelines

1. **Standard Frontmatter**: Every note should begin with YAML frontmatter enclosing metadata:
   ```yaml
   ---
   title: Descriptive Title
   type: knowledge
   created: YYYY-MM-DD
   tags:
     - tag1
     - tag2
   ---
   ```
2. **Pure Markdown**: Use standard CommonMark / GitHub-Flavored Markdown.
3. **Retrieval Architecture**: Knowledge notes are indexed by SilverBullet and retrieved on-demand by Hermes using `hermes_okf search` and `hermes_okf read` to preserve context window bandwidth.
4. **Starter Template**: Copy or use [[knowledge/template|knowledge/template.md]] when authoring new knowledge pages.
