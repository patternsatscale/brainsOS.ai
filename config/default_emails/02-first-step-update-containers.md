# FIRST STEP: Update Daily Containers

Before running demos on **{unit_name}**, pull the latest container updates:

1. Open **[System Manager]({base_url}/system)** (`Alt+8`).
2. Click **Check Updates / Update All Containers** so LiteLLM and Langfuse are current.
3. Open the **FIRST ACTION** email in your inbox (`Alt+1`) and send your first research request to **Bawtford**.
