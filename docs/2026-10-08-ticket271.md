# Walkthrough - Ticket #271: Refactor Control & Setup Scripts for Containerized LiteLLM Lifecycle

## 1. Overview
Ticket #271 refactors `scripts/control/start-control-plane.sh`, `scripts/setup/setup-host.sh`, and `scripts/control/bootstrap-env.sh` to transition the LiteLLM control plane gateway management entirely into native Docker Compose. This completely eliminates host-side Python dependencies (`prisma`, `litellm[proxy]`), removes background nohup execution and PID file tracking, and aligns host lifecycle management with containerized appliance operations.

---

## 2. Summary of Changes

### A. Control Plane Lifecycle Management (`scripts/control/start-control-plane.sh`)
- **`check_db_ready`**: Replaced loopback port 5432 polling (`nc -z 127.0.0.1 5432`) with Docker container health checks (`docker inspect --format '{{.State.Health.Status}}' brainsos-infra-litellm-db`), respecting **Rule 6 (Database Isolation)** where port 5432 has zero host port bindings.
- **`check_litellm_ready`**: Added helper probe verifying `http://127.0.0.1:${LITELLM_PORT}/health/liveness`.
- **`start_services` (Step 2 & 3)**:
  - Launches `litellm` gateway via `docker compose up -d litellm` rather than invoking `.venv/bin/litellm` in background `nohup`.
  - Removed host Python UI theme patching, combining certs for host, setsid commands, and PID file recording (`litellm.pid`).
  - Preserved administrative virtual key registration via HTTP against `http://127.0.0.1:${LITELLM_PORT}`.
- **`stop_services`**:
  - Halts containerized LiteLLM via `docker compose stop litellm`.
  - Cleans up legacy host PID files if present without killing Docker proxy processes.
- **`status_services`**:
  - Inspects container status and reports running state on `http://127.0.0.1:${LITELLM_PORT}` with isolated database confirmation.

### B. Host Setup Streamlining (`scripts/setup/setup-host.sh`)
- **Pruned Host Dependencies**: Removed `litellm[proxy]` and `prisma` installation from `.venv`.
- **Eliminated Prisma Generation**: Removed schema search and `prisma generate` step on the host machine.
- **Updated Precheck**: Changed external LiteLLM precheck to inform that the gateway runs containerized via Docker Compose.

### C. Environment Bootstrap Streamlining (`scripts/control/bootstrap-env.sh`)
- **Removed `litellm[proxy]` and `prisma`**: Pruned from `uv pip install` and `pip install` dev tooling commands.
- **Removed Host Prisma Generation**: Dropped `LITELLM_SCHEMA` check and `prisma generate` invocation.
