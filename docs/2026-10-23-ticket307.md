## 2. Acceptance Criteria Verification

- [x] **SOGo Settings Legibility**: All labels, dropdowns, and descriptions in SOGo preferences (`/SOGo/so/admin/Preferences`) render with high-contrast text (`#E2E8F0` / `#94A3B8`) on dark backgrounds (`#07090E` / `#141A26`).
- [x] **SOGo Thread View**: Message rows within expanded threads maintain dark slate backgrounds (`#0E1422` / `#141C2E`) and legible white/slate text when *"Sort messages by threads"* is enabled.
- [x] **SOGo Reading Pane**: Thread selections cleanly render email content in the detail view without blank white screens (`#detailView` and `div[ui-view="message"]` styled to `#07090E`).
- [x] **EFW Request Banner**: Request summary bar in mitmweb detail view (`.flow-detail .first-line`) uses dark slate background (`#141A26`) with cyber cyan method badge and clean white URL text (`#F8FAFC`).
- [x] **EFW Highlight Blocks Eliminated**: Header values, redacted tokens, and flow list status columns render cleanly without unstyled solid white highlight rectangles (`.inline-input` transparent).
- [x] **Authentik Navigation Contrast**: The active *"User interface"* pill and all sidebar navigation items satisfy WCAG AA contrast (slotted cyan text `#00F2FE` on translucent `#07090E` container, and crisp dark text `#07090E` on any solid cyan button).
- [x] **Cache Busting & Asset Propagation**: SOGo (`?v=20261023-1`), EFW (`?v=20261023-1`), and Authentik (`custom.css`) theme stylesheets updated and cache-busted for instant browser rendering.
