Rule 9, 12 & 14 • Two-Repository Architecture

Decoupled Platform Core vs. Versioned Fleet State

The stateless platform topology (brainsOS) is cleanly separated from proprietary agent personas, OKF Markdown memories, and workspaces (${BRAINSOS_DATA_DIR}), allowing zero-rebuild fleet updates and instant Git rollback via self-hosted Gitea. 

${BRAINSOS_DATA_DIR}/                  # Private Fleet Git Repository
├── settings/
│   └── agents.yaml                    # Declarative multi-tenant registry
├── control_plane/
│   ├── litellm_db/                    # Isolated PostgreSQL (brainsos-control-net)
│   ├── authentik_db/                  # SSO Identity store
│   └── vscode_config/                 # Operator code-server state
├── git/
│   └── gitea.db & repositories/       # Self-hosted Gitea (/git/ :3000)
├── telemetry/
│   ├── clickhouse/                    # Columnar OTel span analytics
│   ├── minio/                         # S3 event/media blobs
│   └── postgres/                      # Langfuse v4 metadata
└── agents/
    └── <tenant_id>/                   # e.g. cindypawford, terrastella, marvin
        ├── SOUL.md                    # Primary orchestrator persona
        ├── subagents/<id>.<role>.md   # Isolated sub-agent prompt (Rule 12)
        ├── memories/                  # Pure OKF Markdown (.md only, Rule 1)
        └── workspace/                 # Sandboxed tool & app execution root
Rule 2 & 3 • Hardware-Aware Serialization

Unified Memory Bus Protection & Millijoule Accounting

On unified memory architectures like the ASUS Ascent GX10 (NVIDIA GB10 ARM64, ~273 GB/s LPDDR5x) and Apple Silicon, system RAM and VRAM share a single physical bus. Unthrottled parallel agent loops cause severe bandwidth thrashing and thermal saturation. 

┌──────────────────────────────────────────────────────────────┐
│ 1. Async Queue Backpressure (packages/brainsOS-queue)        │
│    • Inbound emails & webhooks queued in FIFO order          │
│    • Hermes Runner enforces max_concurrent_runs: 1           │
├──────────────────────────────────────────────────────────────┤
│ 2. Control Plane Serialization (LiteLLM :4000)               │
│    • Enforces max_parallel_requests: 1 & --num_workers 1     │
│    • Per-tenant virtual keys & 300s request timeout          │
├──────────────────────────────────────────────────────────────┤
│ 3. Loopback-Only Native Inference (127.0.0.1:11434)          │
│    • Ollama / vLLM bound strictly to host loopback           │
│    • Zero external network exposure; zero KV cache thrashing │
├──────────────────────────────────────────────────────────────┤
