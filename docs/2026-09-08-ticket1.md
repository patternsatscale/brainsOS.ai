## 1. Summary of Changes

### Environment & Version Control
- [`README.md`](file:///home/patternsatscale/ProjectTitan/README.md): Documents system architecture, directory topology, and operational scripts including `setup-network.sh`.
- [`.gitignore`](file:///home/patternsatscale/ProjectTitan/.gitignore): Protects secrets (`.env`), live memories (`data/memories/*`), backup archives (`data/backups/`), and OS artifacts.
- [`.env.example`](file:///home/patternsatscale/ProjectTitan/.env.example) & `.env`: Configures user IDs (`1000:1000`), storage paths, ports, model aliases, hardware-adaptive context window, and keys.
- [`AGENTS.md`](file:///home/patternsatscale/ProjectTitan/AGENTS.md): Defines ticket-driven operational discipline, atomic scoping, walkthrough logging, pre-commit review gate, and architectural guardrails.
- [`.github/ISSUE_TEMPLATE/`](file:///home/patternsatscale/ProjectTitan/.github/ISSUE_TEMPLATE): Task and bug report templates with acceptance criteria and security checkboxes.

### Ingress & Network Topology
- [`docker-compose.yml`](file:///home/patternsatscale/ProjectTitan/docker-compose.yml): Declares isolated networks (`titan-ingress`, `titan-internal`, and `titan-litellm-net`).
- [`config/caddy/Caddyfile`](file:///home/patternsatscale/ProjectTitan/config/caddy/Caddyfile): Routes `hermes.titan.local`, `proxy.titan.local`, `memory.titan.local`, `dgx.titan.local`, and provides a responsive dark-mode portal landing page with internal TLS (`tls internal`), explicit `text/html` MIME types, and client-side LAN routing adaptation (`data-subdomain` attributes and dynamic URL rewriting).
- [`config/litellm/config.yaml`](file:///home/patternsatscale/ProjectTitan/config/litellm/config.yaml): Enforces hardware serialization (`max_parallel_requests: 1`) to protect unified LPDDR5x bandwidth.
- [`config/hermes/config.json`](file:///home/patternsatscale/ProjectTitan/config/hermes/config.json): Connects Hermes to LiteLLM with OKF storage guidelines and internal `/workspace` segregation.

### Operational Scripts & Security Hardening
- [`scripts/setup-host.sh`](file:///home/patternsatscale/ProjectTitan/scripts/setup-host.sh): Idempotent baseline script with cross-platform OS detection, automated Docker group verification/re-exec, external LiteLLM conflict checking, repository folder permissions (`750`), secret permissions (`chmod 600 .env`), hardware context detection (`is_gx10_hardware`), context window scaling (`32k` on GX10), automated `socat` installation, control plane launch, and comprehensive Section 8 smoke verification.
- [`scripts/start-control-plane.sh`](file:///home/patternsatscale/ProjectTitan/scripts/start-control-plane.sh): Native host service manager with clean process detachment via `setsid`, database readiness checks, and an automated DGX telemetry reverse proxy bridge bound strictly to the Docker bridge gateway interface (`get_docker_gateway()`).
- [`scripts/setup-network.sh`](file:///home/patternsatscale/ProjectTitan/scripts/setup-network.sh): Interactive static IP setup (Netplan / macOS) and `/etc/hosts` domain registration manager with hardware profile gating and confirmation review gates.
- [`scripts/setup-hermes.sh`](file:///home/patternsatscale/ProjectTitan/scripts/setup-hermes.sh): Automated unprivileged Hermes sandbox container build (`titan-hermes:latest`).
- [`scripts/setup-memories.sh`](file:///home/patternsatscale/ProjectTitan/scripts/setup-memories.sh): Flat-file OKF storage layout scaffolding, starter templates, and SilverBullet container caching.
- [`scripts/snapshot-memories.sh`](file:///home/patternsatscale/ProjectTitan/scripts/snapshot-memories.sh): Automated backup and rollback tool for the OKF memory directory with 14-snapshot retention pruning.
- [`scripts/emergency-stop.sh`](file:///home/patternsatscale/ProjectTitan/scripts/emergency-stop.sh): Immediate software kill-switch to pause the agent container and revoke the LiteLLM virtual key.
