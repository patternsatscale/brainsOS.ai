## 6. Post-Merge Operational Hardening & Fixes

During live developer testing, several additional edge cases and credential mappings were identified and resolved across commits `1047264`, `c7b1fc3`, and `263be0f`:

1. **Ingress Conflict Resolution (`BRAINSOS_MAIL_DOMAIN` vs `BRAINSOS_DOMAIN`)**:
   - When `BRAINSOS_MAIL_DOMAIN` was configured identical to `BRAINSOS_DOMAIN` (e.g. `osx.local.brainsos.ai`), Caddy threw `ambiguous site definition: https://osx.local.brainsos.ai` because both SOGo and the Landing Page Portal attempted to claim the root domain.
   - Updated `docker-compose.yml` to automatically derive `BRAINSOS_MAIL_HOST="mail.${BRAINSOS_DOMAIN}"` when the mail domain matches the base domain. Added `/SOGo*` and `/WebServerResources*` proxy handlers to the portal so both the portal and Webmail coexist without conflict.

2. **Operator IDE (VS Code) Basic Auth Automatic Bcrypt Hashing**:
   - Caddy's `basic_auth` directive validates against `OPERATOR_PASSWORD_HASH` (bcrypt). Newly generated `CODE_SERVER_PASSWORD` values in `.env` did not match Caddy's fallback hash, causing `401 Unauthorized`.
   - Added `OPERATOR_USER`, `OPERATOR_PASSWORD_HASH`, and `CODE_SERVER_PASSWORD` to Caddy in `docker-compose.yml`. Caddy now dynamically hashes `CODE_SERVER_PASSWORD` on startup via `caddy hash-password --plaintext` if the hash is unset. Updated `reload-env.sh` to sync the bcrypt hash to `.env`.

3. **Langfuse Admin User Migration**:
   - Legacy local instances created under Project Titan had `admin@titan.local` in `users`. Running `UPDATE users ... WHERE email = 'admin@brainsos.local'` updated 0 rows.
   - Enhanced the PostgreSQL sync in `reload-env.sh` and `setup-langfuse.sh` with a dynamic migration block that renames the legacy admin user to `LANGFUSE_INIT_USER_EMAIL` (`admin@brainsos.local`), updates the name to `brainsOS Admin`, and applies the new bcrypt password hash without breaking foreign key relationships.

4. **Service Directory (`make urls`) Webmail Account Display**:
   - Changed the `Webmail & SOGo Groupware` row in `scripts/control/show-urls.sh` to display the `admin` username and password (`admin@${email_account_domain}`) instead of `operator`.

5. **Shell Compatibility (`set -u` Array Safeguard)**:
   - Guarded empty array expansion `${#URLS_ARGS[@]}` in `scripts/control/reload-env.sh` to prevent `unbound variable` errors on macOS default bash 3.2.
