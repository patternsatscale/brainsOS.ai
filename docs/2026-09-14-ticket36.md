### B. Isolated SST Ion Infrastructure (`apps/cindypawford/infra/`)
- **Modern SST Ion Scaffold**:
  - `package.json` & `tsconfig.json`: Initialized Node ESM workspace configured with `sst@3.3.27`, `@aws-sdk/client-dynamodb`, `@aws-sdk/lib-dynamodb`, and strict TypeScript.
  - `sst.config.ts`: Provisioned isolated cloud resources on AWS `us-east-1`:
    1. **DynamoDB `Suggestions` Table**: Partitioned by `era_id` (HashKey) and `id` (RangeKey) with active/archived status tracking and locked voting upon reset.
    2. **ApiGatewayV2 `CindyApi`**: Serverless HTTP endpoints routing to `src/api.ts`:
       - `GET /api/top-suggestions`: Queries active era suggestions and vote tallies (also consumed by Cindy's daily drop prompt).
       - `POST /api/suggest`: Ingests proposals for Cindy's atelier, enforcing 140-char limits, spam/profanity heuristics, and active era locking.
       - `POST /api/vote/{id}`: Executes atomic vote increments (`ADD votes :inc`) via DynamoDB conditional expressions.
    3. **Production StaticSite (`ProductionSite`)**: S3 + CloudFront CDN hosting `cindypawford.com` with `www.cindypawford.com` redirect alias, injecting `CINDY_API_URL`.
    4. **Archive Museum StaticSite (`ArchiveSite`)**: S3 + CloudFront CDN hosting `apps/cindypawford/archive/` at `archive.cindypawford.com`.
- **Architectural Sandboxing**:
  - Strict adherence to **Rule 4 (Host Sandboxing)** and **Rule 7 (Compartmentalization)**: The Cindy agent container (`hermes`) has zero visibility into `apps/cindypawford/infra/`, mounts only `apps/cindypawford/site` at `/app/html`, and possesses zero AWS credentials or SST tooling.

### C. Closed Shadow DOM Floating Platform Shell (`shell.js`)
- **`apps/cindypawford/infra/src/shell.js` & `apps/cindypawford/site/_platform/shell.js`**:
  - Built zero-dependency Custom Element `<cindy-platform-dock>` encapsulated in **Closed Shadow DOM** (`this.attachShadow({ mode: "closed" })`).
  - **Un-nukeable Architecture**:
    - Host styles isolated with `all: initial` and `!important` declarations, resilient against global CSS resets (`* { display: none !important; }`, font collapses, margin resets).
    - Self-healing `MutationObserver` automatically re-appends the dock element if Cindy's autonomous scripts remove it from the DOM.
  - **Atelier Platform Drawer**:
    - Appliance Telemetry badge: *"Powered by ASUS Ascent GX10 • GB10 Unified Architecture • Hermes Agent"*.
    - Archive Vault links: Direct links to `https://archive.cindypawford.com` and `2024-genesis`.
    - Community Suggestion Box: 140-char live countdown, instant submission wired to `POST /api/suggest`.
    - Live Upvote Board: Real-time suggestion feed populated via `GET /api/top-suggestions` with one-click upvoting.
    - Autonomous Channel Link: Button linking to `@CindyPawford_bot` on Telegram.

### D. Direct Production Deployment & Deterministic Rollback Tooling
