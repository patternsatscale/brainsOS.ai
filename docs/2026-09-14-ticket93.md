## 1. Executive Summary

Ticket #93 eliminates ambient `GH_TOKEN` / `GITHUB_TOKEN` exposure inside sandboxed agent containers (such as Cindy Pawford in `titan-agent-cindy-pawford`) by establishing an **in-transit egress credential injection proxy** via the existing `titan-caddy` gateway.

### Core Achievements
1. **Zero Ambient Container Secrets (Rule 10)**:
   - `GH_TOKEN` and `GITHUB_TOKEN` have been completely eradicated from `docker-compose.agents.yml` and container runtime environments.
   - `env | grep -i -E '(gh_token|github_token|github_pat)'` returns 100% clean.
2. **In-Transit Credential Injection Gateway (`github-proxy.titan.local`)**:
   - `titan-caddy` terminates internal TLS (`tls internal`) for `github-proxy.titan.local` and `github-proxy.titan.internal` on `titan-ingress` and `titan-internal` networks.
   - **GraphQL & REST APIs**: Injects `Authorization: Bearer {$GITHUB_TOKEN_CINDY}` and rewrites enterprise CLI endpoints (`/api/graphql` -> `/graphql`, `/api/v3/*` -> `/*`) when proxying upstream to `https://api.github.com`.
   - **Git Smart HTTP**: Injects `Authorization: Basic {$GITHUB_BASIC_AUTH_CINDY}` when proxying upstream to `https://github.com` for `git-upload-pack`, `git-receive-pack`, and `info/refs`.
3. **Automated Internal PKI Trust**:
   - Docker volume `caddy_data:/etc/ssl/caddy:ro` is mounted into the agent container.
   - Boot hook `/etc/cont-init.d/00-caddy-ca` automatically installs Caddy's internal root CA into `/usr/local/share/ca-certificates/caddy-root.crt` and updates the system trust store on startup without compromising public internet CA roots.
4. **Transparent CLI & Git Redirection**:
   - Git system config rewrites `https://github.com/` -> `https://github-proxy.titan.local/` via `insteadOf`.
   - GitHub CLI (`gh`) configured with `GH_HOST=github-proxy.titan.local`.
   - `gh auth status`, `gh pr list`, `gh issue list`, `git fetch`, and `git push` operate seamlessly with zero client-side credentials.
5. **Dedicated Verification Suite**:
   - Created `scripts/verify/verify-egress-token-injection.sh`, which executes 7 rigorous assertion stages against live containers and remote repositories.
