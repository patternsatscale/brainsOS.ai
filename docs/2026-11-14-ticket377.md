## 1. Summary of Changes

To let operators drop a screenshot of Zoom / Google Meet / Teams participants into VS Code (Claude, Gemini, or Antigravity) and spin up 5–30+ single-tenant `brainsOS` appliances bound to permanent `<user>.<base_domain>` Route 53 URLs—either directly (`--apply`) or via a zero-dependency AWS CloudShell script (`--emit-script`):

### Created Files
- [`scripts/control/launch-fleet.sh`](../scripts/control/launch-fleet.sh):
  - **Roster Sanitization & Collision Disambiguation**: Strips Zoom/Meet/Teams chrome (`(Host)`, `(You)`, `(Guest)`, pronouns, titles), protects reserved slugs (`admin`, `akadmin`, `root`, `api`, `mail`, `git`, `sogo`), and deterministically disambiguates duplicate first names (`Alex Chen` + `Alex Rivera` + `Alex Clark` → `alexc`, `alexr`, `alex-clark`).
  - **Zero-Flag AWS Auto-Discovery**: Automatically resolves the public Route 53 Hosted Zone ID (`Z...`) by walking parent domain suffixes, discovers the newest `available` `brainsos-*` ARM64 AMI (`--owners self` or `--executable-users self` for cross-account shared AMIs), resolves `instanceRoleBedrock` (best-effort attaching an inline Route 53 DDNS policy scoped strictly to `arn:aws:route53:::hostedzone/${ZONE_ID}`), and creates/reuses `brainsos-fleet-https-sg` (ports `80`/`443` inbound only; port `22` closed).
  - **Execution Modes**:
    - `--dry-run` (default): Prints a Markdown preview table of participants, sanitized EC2 `Name` tags, and permanent `https://<slug>.<base_domain>` URLs with zero AWS mutations.
    - `--emit-script <path>`: Emits a **100% self-contained bash script** ready to paste/upload into AWS CloudShell when launching on an external AWS account without local CLI credentials.
    - `--apply`: Launches all fleet instances tagged with `BrainsOSFleet=<fleet-id>`, injects per-instance `#cloud-config` User Data (`domain` + `route53_zone_id` + `email`), and outputs Markdown + CSV **Participant Handoff Rosters** (`Participant | Permanent Appliance URL | First-Boot Instance ID Key`).
    - Optional `--hibernation-capable`: Enables encrypted root `gp3` (`500 MB/s`, `4000 IOPS`) + `HibernationOptions={Configured=true}`.
  - **Day-2 Lifecycle Modes**: `--list`, `--stop`, `--hibernate`, `--start`, and `--terminate` (gated by `--fleet <id>` and `--yes` confirmation for `--terminate`).
- [`.agents/skills/launch-fleet/SKILL.md`](../.agents/skills/launch-fleet/SKILL.md), [`config/default_skills/launch-fleet/SKILL.md`](../config/default_skills/launch-fleet/SKILL.md), & [`packages/brainsOS-skills/brainsos_skills/bundled/launch-fleet/SKILL.md`](../packages/brainsOS-skills/brainsos_skills/bundled/launch-fleet/SKILL.md):
  - Multimodal Workspace Skill (`/launch-fleet`) guiding Claude / Gemini / Antigravity to extract human attendees from meeting screenshots, run `--dry-run` preview, and execute `--apply` or `--emit-script` (zero symlinks per Rule 8).
- [`packages/brainsOS-appliance/tests/test_launch_fleet.py`](../packages/brainsOS-appliance/tests/test_launch_fleet.py):
  - 5 unit/integration tests validating `SKILL.md` schema & Rule 8 no-symlink compliance, UI noise stripping & collision disambiguation, `--emit-script` `bash -n` syntax + User Data generation, mocked end-to-end `--apply` Markdown/CSV handoff output, and Day-2 `--terminate --yes` safety gates.
