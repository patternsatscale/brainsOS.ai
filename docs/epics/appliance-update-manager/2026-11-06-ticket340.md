## 2. Acceptance Criteria Verification

- [x] **1. Containerized Gitea Service (`compose.apps.yml` & `compose.appliance.yml`)**:
  - `gitea` runs `gitea/gitea:1.22` (`brainsos-app-git`) with `security_opt: ["no-new-privileges:true"]`, SQLite3 backend, `GITEA__ui__DEFAULT_THEME=gitea-dark`, and Authentik reverse-proxy SSO (`X-Authentik-Username`, `X-Authentik-Email`, `X-Authentik-Name`).
  - `compose.appliance.yml` resets Gitea host ports (`ports: !reset []`) so port `3002` is never exposed on production appliance interfaces.
- [x] **2. Single-Origin `/git/*` and `/runner*` Caddy Ingress (`Caddyfile` & `Caddyfile.appliance`)**:
  - `/git` redirects (`308`) to `/git/`, and `/git/*` strips the `/git` prefix after `authentik_forward_auth` and proxies to `gitea:3000` with `X-Frame-Options` and `Content-Security-Policy` stripped for seamless Thin-Spine Portal iframe embedding.
  - `/runner*` and `(hermes_runner_backend)` proxy to `runner-hermes:9119` with `HERMES_DASHBOARD_HOST=0.0.0.0` (#334).
- [x] **3. Automated `/data` Git Initialization & VS Code SCM Wiring (`setup-git.sh` & `docker/editor/entrypoint.sh`)**:
  - `scripts/setup/setup-git.sh` initializes `${BRAINSOS_DATA_DIR}` on branch `main` with a clean `.gitignore`, commits initial souls/settings/memories, creates the `agent-box` repository in Gitea, configures `/data/.git/credentials`, and pushes `main` to `http://gitea:3000/<owner>/agent-box.git`.
  - `docker/editor/entrypoint.sh` configures `safe.directory /data` and VS Code SCM settings so the Source Control tab is immediately active when opening `/editor/`.
