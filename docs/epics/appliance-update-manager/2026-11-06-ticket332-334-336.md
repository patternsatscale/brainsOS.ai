## 2. Acceptance Criteria Verification

- [x] **Ticket #332 (Offline-First First-Boot, Instance-Bound `admin`, Named Superuser & Host Console Terminal)**:
  - `firstboot.sh` defaults `AUTO_PULL="false"` unless explicitly opted in via `BRAINSOS_AUTO_PULL=true` in EC2 `user-data` or `BRAINSOS_FIRSTBOOT_FORCE_PULL=true`.
  - `admin` and `akadmin` remain permanently bound to the EC2 Instance ID (`BRAINSOS_INSTANCE_ID` / `BRAINSOS_INSTANCE_ADMIN_PASSWORD`), while `set-domain.sh` and `reload-env.sh` provision the operator's named superuser (`BRAINSOS_SUPERUSER_NAME`, `BRAINSOS_SUPERUSER_USERNAME`, `BRAINSOS_SUPERUSER_PASSWORD`) and coherent local domain (`<username>.aws.cloud.brainsos.ai`).
  - `validate_password_complexity()` enforces length, uppercase, lowercase, digit, special character, and non-matching username/instance-id rules.
  - `/api/v1/system/terminal/ws` spawns an authenticated pseudo-terminal (`pty.openpty()`) and `/api/v1/system/terminal/exec` provides an HTTP fallback.
- [x] **Ticket #334 (Agent Runners & `FIRECRAWL_API_KEY` Configuration)**:
  - `GET /api/v1/system/runners` and `GET /api/v1/system/status` return runner topology (`hermes`, `claude`, `openai`) and masked tool key status (`FIRECRAWL_API_KEY`, `TAVILY_API_KEY`, `EXA_API_KEY`, `BRAVE_SEARCH_API_KEY`).
  - `POST /api/v1/system/runners/hermes/config` persists tool API keys to `.env` and `data/runners/hermes/.env` with `0600` permissions without ever echoing raw secret values.
- [x] **Ticket #336 (Host OS Security Patch Telemetry, APT Upgrade & Graceful Reboot)**:
  - `update.sh --check --json` and `GET /api/v1/system/status` expose live `os` telemetry (`distro`, `kernel`, `pending_packages`, `security_packages`, `reboot_required`, `reboot_packages`, `unattended_upgrades_active`).
  - `POST /api/v1/system/os-upgrade` runs `update.sh --os-only --unattended` with `docker-ce` and `containerd.io` held via `apt-mark hold`.
  - `POST /api/v1/system/reboot` executes `scripts/control/reboot-appliance.sh` to gracefully stop containers before scheduling host reboot.
