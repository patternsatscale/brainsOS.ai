## 1. Summary of Changes

This ticket establishes strict network perimeter isolation and single-origin TLS invariants for turn-key brainsOS appliance deployments ("project in a box", ARM64 AMIs, and edge nodes). All internal service ports have been unpublished from the host interface, routing 100% of user- and operator-facing traffic through Caddy on port 443 with automated TLS-ALPN-01 certificate issuance and immediate port 80 HTTP-to-HTTPS redirects.

| Action | Path | Description |
|---|---|---|
| **Created** | [`docker/compose/compose.appliance.yml`](file:///home/patternsatscale/brainsOS/os/docker/compose/compose.appliance.yml) | Appliance overlay unpublishing all host ports (`ports: !reset []`) across all internal services (`litellm`, `code-server`, `minio`, `langfuse-web`, `clickhouse`, `authentik-server`, `sogo`, `runner-*`, etc.), leaving only Caddy exposing ports 80 and 443. |
| **Created** | [`config/caddy/Caddyfile.appliance`](file:///home/patternsatscale/brainsOS/os/config/caddy/Caddyfile.appliance) | Appliance-specific Caddy configuration enforcing port 80 301 redirects, port 443 single-origin ingress with ACME `tls-alpn-01` challenge (with Route 53 DNS-01 and internal CA fallbacks), and forward-auth proxying for all subsystems. |
| **Modified** | [`config/caddy/Caddyfile`](file:///home/patternsatscale/brainsOS/os/config/caddy/Caddyfile) | Added forward-auth proxying for `/api/v1/system/*` (System Telemetry & Update API) and `/system*` (System Manager SPA route) to synchronize base development ingress with appliance routing. |
| **Created** | [`appliances/scripts/harden-host.sh`](file:///home/patternsatscale/brainsOS/os/appliances/scripts/harden-host.sh) | Idempotent host perimeter hardening script supporting `--dry-run` and `--check`: configures UFW default-deny incoming firewall with ports 80/443 open (zero SSH inbound; relies on AWS SSM), drops in `/etc/ssh/sshd_config.d/99-brainsos-harden.conf` to disable password authentication, and configures Docker daemon log rotation (`50m` max size, `3` files) in `/etc/docker/daemon.json`. |
| **Created** | [`scripts/verify/verify-appliance-ingress.sh`](file:///home/patternsatscale/brainsOS/os/scripts/verify/verify-appliance-ingress.sh) | Automated 5-stage verification harness validating Compose overlay port unpublishing, Caddyfile syntax, host hardening dry-run/check logic, and `/system` routing. |
| **Modified** | [`README.md`](file:///home/patternsatscale/brainsOS/os/README.md) | Documented Appliance Ingress Lockdown and Host Perimeter Security commands in Common Lifecycle Operations. |

## 2. Acceptance Criteria Verification

| Requirement | Status | Evidence / Implementation Details |
|---|---|---|
| **Overlay Port Unpublishing** | **PASSED** | `docker/compose/compose.appliance.yml` uses Docker Compose v2 `ports: !reset []` across all internal services. Python validation confirms only Caddy has published ports `['80', '443']`. |
| **Port 80 HTTP -> HTTPS Redirect** | **PASSED** | `:80 { redir https://{host}{uri} 301 }` configured in `config/caddy/Caddyfile.appliance`. |
| **Port 443 Single-Origin TLS-ALPN-01** | **PASSED** | `(appliance_tls)` snippet configures `issuer acme { email ...; disable_http_challenge }` enabling pure TLS-ALPN-01 challenge handling on 443 without open inbound port 80 challenge paths. Validated with Caddy. |
| **Subsystem Routing (/system & /api/v1/system/*)** | **PASSED** | Configured in both `Caddyfile` and `Caddyfile.appliance` with Authentik forward-auth protection and upstream proxying. |
| **UFW Host Firewall Hardening** | **PASSED** | `appliances/scripts/harden-host.sh` enforces `ufw default deny incoming`, `ufw default allow outgoing`, allows 80/tcp and 443/tcp, and keeps port 22 closed (AWS SSM). |
| **SSH Password Disabling** | **PASSED** | `appliances/scripts/harden-host.sh` writes `/etc/ssh/sshd_config.d/99-brainsos-harden.conf` with `PasswordAuthentication no`, `PermitRootLogin prohibit-password`, `MaxAuthTries 3`. |
| **Docker Log Space Safeguards** | **PASSED** | Safely merges `log-driver: json-file` and `log-opts: {max-size: 50m, max-file: 3}` into `/etc/docker/daemon.json` preserving any preexisting engine configurations. |
