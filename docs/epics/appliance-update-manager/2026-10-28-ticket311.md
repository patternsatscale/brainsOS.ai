## 1. Summary of Changes

This ticket delivers the interactive, cybernetic frontend subsystem for **brainsOS Appliance System Management & Updates** (`⌘6 System`) within the React Thin-Spine Portal SPA (`packages/brainsOS-portal`).

### Files Created:
- `packages/brainsOS-portal/src/components/SystemManager.tsx`:
  - Complete cybernetic dashboard component with obsidian dark styling.
  - Dynamic service & platform cards:
    - **brainsOS.ai Platform Core**: Prominent full-width card tracking Git source code branch, commit hash, upstream tracking branch (`origin/main`), sync status, commit history link, and dedicated "Pull Latest Source" action.
    - **LiteLLM Gateway**, **Langfuse Observability**, **Caddy Ingress**, and **Hermes Agent Runner** showing running versions vs. latest upstream releases, changelog hyperlinks, and one-click update actions.
  - Interactive controls: "Check for Updates", "Update Platform", "Update Containers Only", "Pull Latest Source", and per-service update buttons.
  - Pre-flight update confirmation modal with container restart warnings and automated backup safety assurances.
  - Collapsible terminal drawer with ANSI color parsing, real-time SSE stream consumption from `/api/v1/system/update`, auto-scrolling, log copying, and clearing.

### Files Modified:
- `packages/brainsOS-portal/src/data/subsystems.ts`:
  - Registered `system` subsystem entry with route `/system`, hotkey `⌘6`, icon `Cpu`, color `#00f2fe`, and obsidian dark preview HTML.
  - Remapped `users` subsystem hotkey from `⌘6` to `⌘7` (and preserved `⌘I`).
- `packages/brainsOS-portal/src/hooks/useHotkeys.ts`:
  - Wired keyboard shortcut `⌘6` to navigate to `system`, and `⌘7` to `users`.
- `packages/brainsOS-portal/src/components/ThinSpine.tsx`:
  - Added `Cpu` icon rendering for the `system` subsystem button in the thin spine.
- `packages/brainsOS-portal/src/components/ViewportFrame.tsx`:
  - Integrated native React rendering for `SystemManager` (avoiding nested iframe overhead).
  - Added `Cpu` icon and header path metadata.
- `packages/brainsOS-portal/src/App.tsx`:
  - Added initial key resolution for `/system` path.
- `packages/brainsOS-portal/src/components/HelpView.tsx`:
  - Documented `System Manager & Update Center` in the tool catalog and updated the hotkey cheat sheet (`⌘6` System, `⌘7` Identity).

### Key Interaction Points to Review:
1. **ThinSpine Navigation**:
   - Click the `Cpu` icon (6th button down) in the navigation spine or press `⌘6` on your keyboard.
   - Verify the squircle activates with a cyan glow (`#00f2fe`) and displays "System • ⌘6".
2. **Metrics & Service Cards**:
   - Inspect the top 4 status cards (ASUS Ascent GX10, Git Core, Auto-Rollback Guardrails, Registry Sync).
   - Check the LiteLLM Gateway card: shows `v1.105.0` vs. `1.106.5` with an animated amber "UPDATE AVAILABLE" badge and clickable changelog link.
   - Check the Langfuse Observability card: shows `4.58.0` vs. `4.71.0` with an animated amber "UPDATE AVAILABLE" badge and changelog link.
   - Check Caddy Ingress and Hermes Agent Runner: shows green "UP TO DATE" status.
3. **Interactive Controls & Pre-Flight Modal**:
   - Click "Check for Updates" to test the spinning refresh animation.
   - Click "Update LiteLLM" or "Update Platform": verify the modal pops up warning of container restarts and explaining the automated rollback guardrail.
   - Press `Escape` or click `Cancel` to dismiss the modal.
4. **Terminal Log Drawer**:
   - Click "Update Platform", confirm in the modal, and watch the collapsible terminal open with live streaming logs.
   - Verify ANSI colors (blue headers, green checkmarks, amber notices) render in rich HTML formatting.
   - Toggle the "Scroll: ON/OFF" button, "Copy" button, and "Clear" button.
5. **Mobile Viewport Emulation**:
