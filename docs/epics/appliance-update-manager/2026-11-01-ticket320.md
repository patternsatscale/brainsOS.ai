## 1. Summary of Changes

During the live AWS EC2 ARM64 (`c7g.xlarge`) rehearsal and cold-boot verification of the candidate AMIs, 21 real-world first-boot, container permission, single-origin SSO, observability routing, port-binding, cold-boot splash, fleet manifest seeding, email-to-agent pipeline, Hermes Langfuse tool-call tracing, and System Update Manager issues were uncovered, fixed in the repository, and verified:
