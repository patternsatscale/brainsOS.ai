## 1. Summary of Changes

### Ticket #332: Appliance Identity, `BRAINSOS_LOCAL_DOMAIN` vs `BRAINSOS_URL`, Admin Credentials & Coherent Hostname
- [`.env.example`](file:///home/patternsatscale/brainsOS/os/.env.example):
  - Introduced `BRAINSOS_URL=local.brainsos.ai` (external web access URL/hostname) and `BRAINSOS_LOCAL_DOMAIN=local.brainsos.ai` (coherent appliance unit FQDN & local mail domain), maintaining `BRAINSOS_DOMAIN` for backward compatibility.
- [`packages/brainsOS-appliance/scripts/firstboot.sh`](file:///home/patternsatscale/brainsOS/os/packages/brainsOS-appliance/scripts/firstboot.sh):
  - Added `normalize_url_host()` to strip `http(s)://`, ports, and trailing slashes from URLs.
  - Parsed `BRAINSOS_URL`, `BRAINSOS_LOCAL_DOMAIN`, and `BRAINSOS_ADMIN_USERNAME` from EC2 `user-data` (`brainsos.url`, `brainsos.local_domain`, `brainsos.admin_username`).
  - Decoupled `APPLIANCE_DOMAIN` (`BRAINSOS_URL`, external AWS EC2 URL) from `APPLIANCE_LOCAL_DOMAIN` (`BRAINSOS_LOCAL_DOMAIN`, defaulting to `local.brainsos.ai` instead of `mail.ec2-*.compute-1.amazonaws.com`).
- [`scripts/control/set-domain.sh`](file:///home/patternsatscale/brainsOS/os/scripts/control/set-domain.sh):
  - Added `--url <url>`, `--local-domain <fqdn>`, `--admin-username <user>`, `--admin-password <pass>` (plus environment-variable support via `BRAINSOS_NEW_ADMIN_PASSWORD` so plaintext passwords never appear in `ps` or job logs), and `--mark-wizard-completed`.
  - Applied reboot-persistent OS hostname (`hostnamectl set-hostname`, `/etc/hosts` `127.0.1.1 <fqdn> <short-host>`, and `/etc/cloud/cloud.cfg.d/99-brainsos-hostname.cfg` with `preserve_hostname: true`).
  - Synchronized `BRAINSOS_URL`, `BRAINSOS_LOCAL_DOMAIN`, `BRAINSOS_MAIL_DOMAIN`, `BRAINSOS_ADMIN_USERNAME`, `BRAINSOS_ADMIN_EMAIL`, and unified admin credentials across `.env`.
- [`scripts/control/reload-env.sh`](file:///home/patternsatscale/brainsOS/os/scripts/control/reload-env.sh):
  - Synchronized custom `BRAINSOS_ADMIN_USERNAME` and `BRAINSOS_LOCAL_DOMAIN` across SOGo `sogo_users`, Authentik SSO (`User` in `authentik Admins`, while rotating `admin`, `akadmin`, and `operator` away from the initial `instance-id` password), and Caddy `tls_policy.caddy` (`internal`, `acme`, and `route53`).
- [`scripts/setup/setup-mail.sh`](file:///home/patternsatscale/brainsOS/os/scripts/setup/setup-mail.sh), [`docker/mail/entrypoint.sh`](file:///home/patternsatscale/brainsOS/os/docker/mail/entrypoint.sh), [`docker/sogo/entrypoint.sh`](file:///home/patternsatscale/brainsOS/os/docker/sogo/entrypoint.sh), [`docker/compose/compose.apps.yml`](file:///home/patternsatscale/brainsOS/os/docker/compose/compose.apps.yml), [`docker/compose/compose.agents.yml`](file:///home/patternsatscale/brainsOS/os/docker/compose/compose.agents.yml):
  - Provisioned `@${BRAINSOS_LOCAL_DOMAIN}` mailboxes and `${BRAINSOS_ADMIN_USERNAME}@${BRAINSOS_LOCAL_DOMAIN}` with full Dovecot ACL oversight across all agent mailboxes.
  - Set Postfix `myhostname` and `mydomain` to `BRAINSOS_LOCAL_DOMAIN`.
- [`packages/brainsOS-mail/brainsos_mail/client.py`](file:///home/patternsatscale/brainsOS/os/packages/brainsOS-mail/brainsos_mail/client.py) & [`packages/brainsOS-agent/brainsos_agent/worker.py`](file:///home/patternsatscale/brainsOS/os/packages/brainsOS-agent/brainsos_agent/worker.py):
  - Used `BRAINSOS_LOCAL_DOMAIN` for RFC 5322 `Message-ID` generation, agent reply `From:` headers, and internal Postfix SMTP routing while preserving external Amazon SES routing.
- [`packages/brainsOS-agent/brainsos_agent/langfuse_trace.py`](file:///home/patternsatscale/brainsOS/os/packages/brainsOS-agent/brainsos_agent/langfuse_trace.py) & [`docker/hermes/plugins/observability/langfuse/__init__.py`](file:///home/patternsatscale/brainsOS/os/docker/hermes/plugins/observability/langfuse/__init__.py):
  - Exported `langfuse.trace.metadata.local_domain`, `langfuse.observation.metadata.local_domain`, and OTLP resource `host.name = <BRAINSOS_LOCAL_DOMAIN>`.

### Ticket #333: System API Endpoints, Portal 3-Step First-Boot Setup Wizard & Persistent Identity Card
- [`packages/brainsOS-telemetry/brainsos_telemetry/system.py`](file:///home/patternsatscale/brainsOS/os/packages/brainsOS-telemetry/brainsos_telemetry/system.py) & [`scripts/control/update.sh`](file:///home/patternsatscale/brainsOS/os/scripts/control/update.sh):
  - Extended `GET /api/v1/system/status` and added `GET /api/v1/system/identity` returning `firstboot_wizard_completed`, `url`, `local_domain`, `admin_username`, `admin_email`, `tls_mode`, `acme_email`, `hostname`, `preserve_hostname`, `public_ipv4`, `local_ipv4`, and `instance_id`.
  - Added `POST /api/v1/system/dns-check` for live DNS pre-flight verification against the appliance's public IPv4.
  - Added `POST /api/v1/system/setup` (and `/api/v1/system/domain`), protected by `X-BrainsOS-Internal`, Authentik identity headers, Origin/Sec-Fetch-Site validation, and CSRF token (`X-CSRF-Token`), streaming `set-domain.sh` via SSE and passing `BRAINSOS_NEW_ADMIN_PASSWORD` via subprocess environment.
- [`packages/brainsOS-portal/src/App.tsx`](file:///home/patternsatscale/brainsOS/os/packages/brainsOS-portal/src/App.tsx) & [`packages/brainsOS-portal/src/components/SystemManager.tsx`](file:///home/patternsatscale/brainsOS/os/packages/brainsOS-portal/src/components/SystemManager.tsx):
  - Automatically routes to System Manager and launches the **3-Step Guided First-Boot Setup Wizard** modal when `firstboot_wizard_completed === false`.
  - Added the persistent **Appliance Identity, Custom Domain & TLS Ingress** card with one-click **Download Root CA (`/system/ca.crt`)** and **Configure Domain & Identity** controls.

## 2. Acceptance Criteria Verification

### Ticket #332
- [x] `BRAINSOS_URL` and `BRAINSOS_LOCAL_DOMAIN` are cleanly separated across `.env.example`, `firstboot.sh`, `set-domain.sh`, and `reload-env.sh`.
- [x] `set-domain.sh --local-domain jsm.cloud.aws.brainsos.ai --url https://ec2-32-192-215-107.compute-1.amazonaws.com/ --internal` sets the OS hostname, writes `/etc/cloud/cloud.cfg.d/99-brainsos-hostname.cfg` (`preserve_hostname: true`), updates `/etc/hosts` (`127.0.1.1 jsm.cloud.aws.brainsos.ai jsm`), and configures Caddy/Authentik for the external EC2 URL while Postfix/Dovecot/SOGo use `@jsm.cloud.aws.brainsos.ai`.
- [x] Setting custom admin credentials (`--admin-username jsm` + `BRAINSOS_NEW_ADMIN_PASSWORD`) rotates the initial `instance-id` bootstrap password across Authentik, SOGo, Dovecot, Langfuse, and Code-Server.
- [x] Langfuse traces include `local_domain` metadata and OTLP `host.name`.

### Ticket #333
- [x] On initial login when `firstboot_wizard_completed` is `false`, the Portal opens the 3-Step First-Boot Setup Wizard.
- [x] Step 1 previews OS hostname (`preserve_hostname: true`), `@<local_domain>` mailboxes, and Langfuse telemetry tag.
- [x] Step 2 configures `BRAINSOS_ADMIN_USERNAME` and rotates `BRAINSOS_ADMIN_PASSWORD` with confirmation.
- [x] Step 3 configures `BRAINSOS_URL` and TLS mode (`Internal CA`, `Public ACME` with live `Verify DNS`, or `Route 53 DNS-01`).
- [x] Applying setup streams live SSE logs in the terminal drawer and marks `.brainsos-wizard-completed`.
