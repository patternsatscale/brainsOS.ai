## 1. Summary of Changes

1. **`packages/brainsOS-portal/package.json` & `packages/brainsOS-portal/package-lock.json` (#338)**:
   - Upgraded `vite` (`^7.3.7`), `esbuild` (`^0.28.2`), and `postcss-selector-parser` (`6.1.5`) so `npm audit` reports `0 vulnerabilities`.
2. **`packages/brainsOS-portal/src/data/subsystems.ts` (#333, #340)**:
   - Added the `git` (`Source Control`, route `/git/`, icon `GitBranch`, hotkey `⌘3`) subsystem for the local Gitea server and `brainsos/agent-box` prompt/memory versioning repository.
   - Updated `system` to `System OS` (`Appliance Operating System & Console`, hotkey `⌘0`).
3. **`packages/brainsOS-portal/src/components/ThinSpine.tsx` (#333, #340)**:
   - Added `GitBranch` icon rendering for the `git` subsystem in the application squircle cluster.
   - Separated `system` from the middle application icons and relocated `#spine-btn-system` to the **bottom control cluster** with a dedicated `OS` badge, `Sliders` icon, and cyan hardware ring.
4. **`packages/brainsOS-portal/src/components/SubsystemsDrawer.tsx`, `ViewportFrame.tsx`, `App.tsx` (#333, #340)**:
   - Added `/git` route handling in `App.tsx` and `GitBranch` icon rendering in `ViewportFrame.tsx`.
   - Updated `SubsystemsDrawer.tsx` to prioritize runtime `window.location.hostname` (when non-localhost) over build-time `VITE_APPLIANCE_HOST`.
5. **`packages/brainsOS-portal/src/components/SystemManager.tsx` (#333, #334, #336)**:
   - **Operating System Control Center Layout**: Replaced the card-heavy dashboard with a Left-Hand OS Navigation Rail (`overview`, `console`, `agents`, `updates`, `storage`) and structured OS tables.
   - **First-Boot Superuser Setup Wizard (#333)**:
     - Explains that `admin` is permanently bound to the EC2 Instance ID (`i-...`) for break-glass recovery while guiding the operator to create their personal **Superuser** account (`setupSuperuserName`, `setupAdminUsername`).
     - Dynamically suggests `<username>.aws.cloud.brainsos.ai` for `BRAINSOS_LOCAL_DOMAIN` as the user types their Superuser username.
     - Includes an explicit **Show passwords in plain text** checkbox, eye icon toggle, and live 6-point **Password Complexity & Security Checklist**.
   - **Interactive Host Console (`console` pane, #333)**:
     - Connects to `wss://<host>/api/v1/system/terminal/ws` with automatic fallback to `POST /api/v1/system/terminal/exec`, command history (`ArrowUp`/`ArrowDown`), quick-command toolbar (`make status`, `docker compose ps`, `git status`, `df -h`, `uname -a`), and a toggleable **System Job Output Stream** tab.
   - **Agents & Runners (`agents` pane, #334)**:
     - Displays registered agent execution runners (`Nous Hermes Warm Runner`, `Anthropic Claude SDK Runner`, `OpenAI Agents SDK Runner`), web search mode status (`Keyless Free Tier` vs `Firecrawl API Key Active`), a direct **Open Hermes Runner UI (`/runner/`)** button, and configuration inputs for `FIRECRAWL_API_KEY`, `TAVILY_API_KEY`, `EXA_API_KEY`, and `BRAVE_SEARCH_API_KEY` (`POST /api/v1/system/runners/hermes/config`).
   - **Software & OS Updates (`updates` pane) & Storage/Power (`storage` pane, #336)**:
     - Displays Ubuntu LTS & Linux Kernel security patch status, `unattended-upgrades` status, `/var/run/reboot-required` alert banner, **Apply OS Security Patches** (`POST /api/v1/system/os-upgrade`), container version pinning table, and a 2-step **Graceful Appliance Reboot** modal (`POST /api/v1/system/reboot`).
