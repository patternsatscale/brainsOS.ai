## 4. Follow-Up & Rehearsal Verification Items

### 4.1 Live EC2 IMDS Isolation Checks for Ticket `#320` Phase 3 Operator
When rehearsing the private AMI on EC2 in `#320` Phase 3, run the following checks:
1. Verify `imds-guard.sh` status on the appliance host:
   ```bash
   sudo /opt/brainsos/scripts/setup/imds-guard.sh --check
   ```
2. Verify agent runner containers **cannot** reach EC2 IMDSv2 (must time out or fail):
   ```bash
   docker exec brainsos-agent-runner-hermes curl -s -m 3 -X PUT http://169.254.169.254/latest/api/token -H 'X-aws-ec2-metadata-token-ttl-seconds: 60'
   ```
3. Verify a LiteLLM Bedrock completion succeeds using the ambient EC2 instance role.
