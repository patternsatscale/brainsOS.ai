## 2. Acceptance Criteria Verification

- [x] **Inbound emails trigger `agent-webhook.sh` via Sieve and return in < 200ms**:
  - Benchmarked execution time is **~47ms** total (0.01s user, 0.02s system), well within the <200ms requirement.
- [x] **No synchronous outbound echo email or sendmail call is generated within the container**:
  - Removed all legacy synchronous agent dispatcher and echo logic; no `/usr/sbin/sendmail` calls exist.
- [x] **Raw `.eml` files appear in `/var/spool/brainsos/inbound/` with unique high-resolution timestamps**:
  - Script creates high-resolution nanosecond timestamped `.eml` files (`$(date +%s%N).eml`) before network dispatch.
- [x] **Raw RFC 822 payloads successfully reach the control plane ingress endpoint**:
  - Payload streamed via `curl -sS -X POST "${BRAINSOS_INGRESS_URL}" --header "Content-Type: message/rfc822" --data-binary @"${SPOOL_FILE}"`.
- [x] **Exit code 0 is consistently returned even if the control plane is temporarily unreachable**:
  - Validated with unreachable mock endpoints (`http://127.0.0.1:9999/dummy`); script handles curl failure gracefully and always exits with code 0.
- [x] **Rule 1 (Memory Purity)**:
  - Spool files reside strictly in `/var/spool/brainsos/inbound/`, completely outside `/memories` or `agent_memories`.
- [x] **Rule 4 (Host Sandboxing)**:
  - Container remains unprivileged with zero docker socket mounts.
