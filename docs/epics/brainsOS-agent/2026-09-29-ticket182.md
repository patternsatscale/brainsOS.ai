## 2. Acceptance Criteria Verification

- [x] **Outbound emails display properly threaded under the initial message in standard email clients**:
  - `send_mail()` formats `In-Reply-To: <inbound.message_id>` and appends the message ID to `References: <root-references> <inbound.message_id>` with angle bracket normalization.
- [x] **Outbound agent responses appear immediately in the agent's `Sent` folder inside SOGo**:
  - `sync_to_sent_folder()` automatically connects to Dovecot IMAP and appends the raw RFC 822 bytes with `\Seen` flag to `Sent`.
- [x] **Threading headers correctly handle messages with missing or empty `References`**:
  - Validated by `test_send_mail_threading_headers_missing_or_empty_references`: When `references` is None or `""`, `References` is set to `In-Reply-To`.
- [x] **Unit tests verify header formatting, SMTP dispatch, and IMAP append execution**:
  - Validated by 8 unit tests in `packages/brainsOS-mail/tests/test_client.py`.
- [x] **Security Constraints**:
  - Credentials sourced safely via environment variables (`AGENT_MAIL_USER`, `AGENT_MAIL_PASSWORD`); zero credentials committed to Git.
