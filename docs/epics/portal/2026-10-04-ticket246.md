## 1. Executive Summary

This ticket replaces third-party link dashboards (Dashy) with a bespoke, cybernetic frontend application built with React 18, Vite 5, TypeScript, and TailwindCSS:
1. **56px Thin Navigation Spine**: Consumes < 4% screen width, leaving 96%+ full-bleed real estate for active tools.
2. **Slide-Over Frosted HUD Drawer (288px)**: Overlays on demand via hamburger button, `⌘B`, or `⌘K` **without shifting, remounting, or reloading the active workspace iframe DOM**.
3. **Users & Identity Provisioning**: Dedicated squircle icon in the spine (violet token `#a855f7`, hotkey `⌘6`/`⌘I`) directly embedding Authentik's administration interface (`/auth/if/admin/`) for user and tenant lifecycle provisioning.
4. **Operator Identity & SSO Session Modal**: Integrated profile trigger in the bottom-left spine with an animated pulse indicator. Clicking it (or pressing `⌘U`) opens a frosted-glass modal displaying Authentik session headers (`Remote-User: operator`) and an interactive logout confirmation flow.
5. **Global Hotkey Engine**: Instant switching (`⌘1`–`⌘6`, `⌘I`, `⌘H`), operator modal (`⌘U`), drawer toggle (`⌘B`/`⌘K`), and fullscreen (`F11`).
6. **Zero-Daemon Production Footprint**: Compiles to static HTML/JS/CSS (`dist/`) mounted directly into Caddy at `/srv/portal`.
