## Brand & Style

This design system establishes a high-performance, developer-first visual framework engineered specifically for synthetic intelligence runtimes, model telemetry, and agent orchestrators. It balances the raw deterministic utility of low-level systems engineering with the ethereal, cognitive depth of neuromorphic computing.

### Aesthetic Foundation
- **Cybernetic Minimalism & Terminal Precision**: Uncluttered data-dense workspaces built on high-density information displays, sub-pixel alignments, and disciplined spatial rhythms.
- **Luminescent Depth (Glassmorphism & Circuit Traces)**: Translucent, deeply layered backdrop containers that reflect computational state through subtle ambient luminescence, optical glass refraction, and laser-fine border geometries.
- **Deterministic Reliability**: No decorative fluff. Every visual artifact—from glowing trace lines to monospaced hash markers—denotes execution state, hardware telemetry, memory allocations, or cognitive thread hierarchy.

### Emotional Response
The interface must instill absolute control, cryptographic security, hyper-focus, and technological supremacy. It should feel less like a consumer application and more like a tactical mission control console designed to inspect, orchestrate, and compile autonomous artificial minds in real-time.

## Colors

The color palette is built around an obsidian substrate accented by polarized neon emitters, simulating a quantum terminal displaying active cognitive circuits.

### Palette Architecture
- **Primary Accent (`#00F2FE` - Cyber Cyan)**: Represents active computational runtime, laser focus, system readiness, and live telemetry execution. Used for primary interactive triggers, active tabs, operational graphs, and real-time trace lines.
- **Secondary Accent (`#7928CA` - Neural Violet)**: Denotes cognitive architecture, inference synthesis, neural weight manipulation, and asynchronous processes. Frequently paired with Cyber Cyan across directional linear gradients.
- **Tertiary Accent (`#10B981` - Synthetic Emerald)**: Reserved for deterministic health, zero-error kernel passes, verified cryptographic proofs, and nominal throughput metrics.
- **Surface Foundations (`#0B0E14` - Obsidian Dark)**: The deepest canvas layer. Layered tiers step upward through `#111622` (Substrate Layer 1), `#182030` (Container Layer 2), and `#222D42` (Interactive High-Light).
- **Typography & Content**:
  - `Matrix White` (`#F8FAFC`): Absolute clarity for headline metrics, critical code definitions, and active states.
  - `Slate Matrix` (`#94A3B8`): Balanced, low-fatigue tone for persistent body copy, parameter titles, and architectural metadata.
  - `Muted Phosphor` (`#475569`): Deep structure, inactive borders, disabled glyphs, and structural grid rules.
  - `System Critical` (`#F43F5E`): Kernel panics, context window overflows, and security privilege violations.

## Typography

The typography scale balances geometric futurism with monospaced terminal legibility.

- **Headlines (`Space Grotesk`)**: Provides an authoritative, technical, and structural tone for titles, telemetry headers, and model parameters. Tight negative tracking gives titles a solid, mechanical posture.
- **Body & Controls (`Geist`)**: Neutral, ultra-crisp, and mathematically balanced. Ensures high readability across deep contextual documentation, parameter trees, and chat-to-code agent logs.
- **Telemetry, Code, & Audits (`JetBrains Mono`)**: Applied to memory addresses, latency figures, tokens per second (TPS), execution logs, and cryptographic hashes. Always set uppercase when used in operational chips or telemetry indicators.

## Layout & Spacing

The layout is grounded in a continuous, high-density 12-column engineering grid with rigid modularity.

### Grid Rhythm & Layout Modes
- **Fluid Structural Canvas**: Workspaces expand edge-to-edge while respecting an outer safe canvas boundary (`margin: 2rem` desktop, `margin-mobile: 1rem` mobile).
- **Column Splits**:
  - **Desktop (>= 1280px)**: 12-column layout with fixed side navigation/telemetry docks (300px) and central multi-pane orchestration terminals.
  - **Tablet (768px - 1279px)**: 8-column layout with collapsing inspector drawers and horizontal scrolling telemetry feeds.
  - **Mobile (< 768px)**: 4-column layout; auxiliary panels collapse into bottom-sheet HUDs.
- **Microchip Trace Alignment**: Internal containers must sit on an 8px grid baseline (`space-xs: 4px`, `space-sm: 8px`, `space-md: 16px`, `space-lg: 24px`, `space-xl: 40px`). Component gaps follow deterministic 8px multipliers to maintain strict hardware-like precision.

## Elevation & Depth

Visual hierarchy uses physical elevation sparingly, favoring layered optical substrate depth, subtle refraction, and circuit luminescence over heavy drop shadows.

### Layer Stack Architecture
1. **Substrate (Level 0 - Ground)**: Flat `#0B0E14`. Rendered with a faint, low-contrast SVG circuit-mesh background grid at 4% opacity.
2. **Container Deck (Level 1)**: Solid `#111622` background with a 1px border colored `#1E293B`.
3. **Glassmorphic Glass Container (Level 2)**: Background set to `rgba(17, 22, 34, 0.75)` with a backdrop blur of `16px`. Borders are dual-layered using a 1px line of `rgba(255, 255, 255, 0.08)` and corner highlights.
4. **Focused / Intercept Layer (Level 3 - Modal/HUD)**: Background set to `rgba(24, 32, 48, 0.9)` with backdrop blur `24px` and a razor-thin Cyber Cyan border (`rgba(0, 242, 254, 0.4)`).

### Luminescent Glow Profiles
- **Idle State**: 0px blur, no shadow. Strict 1px borders define spatial planes.
- **Active / Computing Glow**: `box-shadow: 0 0 20px -4px rgba(0, 242, 254, 0.25)`.
- **Cognitive / Synthesis Glow**: `box-shadow: 0 0 24px -4px rgba(121, 40, 202, 0.35)`.

## Shapes

The design system employs a restrained, industrial radius scale (`roundedness: 1`) to preserve the feeling of physical microelectronics and server-grade control modules.

### Border Radius Rules
- **Core Elements (`rounded-sm` - 0.25rem / 4px)**: Buttons, inputs, chip labels, telemetry indicators, and table cell highlights. Soft enough to prevent harsh brutalism, sharp enough to feel engineered.
- **Containers & Glass Cards (`rounded-lg` - 0.5rem / 8px)**: Surface panels, modal consoles, and execution docks.
- **Specialized Overlays (`rounded-xl` - 0.75rem / 12px)**: Standalone floating system alerts or dialog triggers.
- **Chamfered Trace Accents**: Complex cards may feature an optional 45-degree chamfered corner on the top-right edge to evoke high-density PCB geometries.

## Components

### Buttons
- **Primary (Execution Trigger)**: Solid Cyber Cyan (`#00F2FE`) fill with pure Obsidian (`#0B0E14`) bold text. Hover introduces an inner edge highlight and a `0 0 16px rgba(0, 242, 254, 0.4)` bloom.
- **Secondary (Neural/Cognitive Action)**: 1px border gradient transitioning from `#00F2FE` to `#7928CA`, filled with `rgba(17, 22, 34, 0.6)`. Text in `Matrix White` (`#F8FAFC`).
- **Ghost/Tertiary**: No background, border in `rgba(148, 163, 184, 0.2)`, text in `Slate Matrix` (`#94A3B8`). On hover, border turns into `#00F2FE`.

### Input Fields
- Dark obsidian base (`#0E131D`) with a 1px border in `#1E293B`. Font: `JetBrains Mono` for precise character alignment.
- **Active Focus**: Border turns into `#00F2FE` accompanied by a localized `box-shadow: 0 0 8px rgba(0, 242, 254, 0.2)`. Placeholders in `#475569`.
- **Inline Validation**: Suffix indicator showing real-time token/payload calculations in uppercase monospaced labels.

### Telemetry Badges & Chips
- Compact, auto-padded elements displaying kernel state, memory usage, and node health.
- Monospaced 10px uppercase type with an integrated pulsing dot indicator:
  - *Active Node*: Background `rgba(0, 242, 254, 0.08)`, border `rgba(0, 242, 254, 0.3)`, text `#00F2FE`.
  - *Inference In-Progress*: Background `rgba(121, 40, 202, 0.1)`, border `rgba(121, 40, 202, 0.3)`, text `#D8B4FE`.

### Lists & Audit Tables
- Borderless rows separated by 1px horizontal hairpins (`rgba(255, 255, 255, 0.05)`).
- Alternate row striping using `rgba(255, 255, 255, 0.015)`. Hovering rows activates a left 2px vertical neon spine in Cyber Cyan.

### Checkboxes & Radios
- Sharp 2px roundedness for checkboxes; circular for radios. Solid `#111622` fill with 1px `#334155` border.
- **Checked**: Filled with `#00F2FE`; checkmark glyph rendered in obsidian black with high contrast.

### Cards & Execution Nodes
- Layer 2 glassmorphism containers with a top-border accent simulating circuit traces.
- Cards header features a monospaced identifier badge (`e.g., KERNEL::SYS_01`) aligned to the top-right corner.

### Specialized Components
- **Kernel Stream Log**: A fixed-height container with virtualized scrolling, timestamp prefixes in Slate Matrix, and syntax-highlighted JSON/Python outputs.
- **Node Topology Graph Node**: Translucent glass modules with input/output connection pips that highlight with neon traces when active data streams traverse them.
- **Application Dock ("Dockey" Launcher)**: A centered, floating frosted-glass shelf (`backdrop-filter: blur(24px)`, `bg: rgba(17, 22, 34, 0.88)`) situated at the bottom of the OS desktop. Hosts the 6 core appliance subsystems with hover scale transformations (`scale(1.18)`), glowing green active-running status pips, and launch dialogs:
  - **No Floor Mirror Reflections**: The dock floats above a pure matte obsidian substrate with zero bottom reflections (`-webkit-box-reflect: none`) to maintain a clean, high-contrast, professional OS aesthetic.
  - **The 6 Core Appliance Subsystems**:
    1. `Console`: Operator IDE & Monaco code editor (`:8443`, Cyan accent `#00F2FE`).
    2. `Comms`: SOGo Webmail & Dovecot IMAP (`:20000`, Pink/Magenta accent `#EC4899`).
    3. `Security`: LiteLLM Security Gateway & Virtual Keys (`:4000`, Amber accent `#F59E0B`).
    4. `Network`: mitmproxy Tool Egress Gateway & Traffic Inspector (`:8081`, Emerald accent `#10B981`).
    5. `Trace`: Langfuse LLM Observability & Tracing (`:3000`, Blue accent `#3B82F6`).
    6. `Help`: Appliance Documentation & L1–L7 Architecture Matrix (Yellow accent `#FBBF24`, switches to interactive documentation view).

## Screen Layouts & Approved Specifications

### 1. Side-by-Side Enterprise OS Login (`code.html`)
- **Equal-Sized 50/50 Desktop Split**: Left column displays the official BrainsOS logo (`image.png`) with cyan luminescent aura; right column displays the operator authentication card.
- **Enterprise OS Copy**:
  - Headline: `Sign into BrainsOS.AI`
  - Subtitle: `Enter your operator username and password`
- **Distraction-Free Visuals**: Removed sci-fi tags ("Encrypted", "IdP", "Strict Zero Trust"). Retains the authentic kernel build badge (`Kernel v1.0.0 • Build 247.10-arm64`).
- **Responsive Stacking**: On mobile viewports (<1024px), stacks cleanly into a vertical column with proportional scaling.

### 2. Dockey OS Workspace (`portal_prototype.html#dock`)
- **Substrate**: Pure obsidian black (`#0B0E14`) with subtle ambient gradient glow and watermark.
- **Hardware Telemetry Bar**: Real-time status for the NVIDIA GB10 GPU (load/temp), ARM64 CPU (load/clock), Memory Bandwidth (273 GB/s unified LPDDR5x bus), and NVMe Storage.
- **Floating Dock**: Centered 6-item application launcher with green status dots and launch modals.

### 3. Embedded Application Iframe Mode (`portal_prototype.html#dock` with Active App)
- **Persistent Floating Dock (`z-index: 50`)**: The frosted-glass dock floats over the lower portion of the active iframe (`bottom: 12px`, centered).
- **Top Window Title Bar**: OS header displays application name, route, Authentik SSO status, Minimize, and Pop Out controls.
- **In-Place App Swapping**: Clicking between dock items instantly switches the visible iframe while preserving runtime state (terminal commands, drafts, active editors).
- **Dock Auto-Hide**: Collapses to a discrete bottom tab to grant 100% vertical viewport height when needed.

### 4. Appliance Help & Architecture Matrix (`portal_prototype.html#help`)
- **Documentation Hub**: Repurposed from the initial portal mockup to serve as the comprehensive appliance manual.
- **Searchable Plane Matrix**: L1–L7 plane cards with live search, container port references, and isolation guardrails.

### 5. Dashy Unified Appliance Dashboard (`dashy_preview.html` / Ticket #246)
- **Architectural Shift**: Replaces brittle custom iframe wrappers with an industry-standard homelab appliance dashboard (`lissy93/dashy`), eliminating xterm/Monaco layout tree destruction and cursor offset bugs.
- **Declarative YAML Authority**: Configured via `config/dashy/conf.yml` with zero database dependencies.
- **Plane Architecture Sections**:
  - *Level 3: Operator & IDE Plane*: Operator IDE (`editor.brainsos.local`), Web Terminal (`terminal.brainsos.local`), Governance & Policy.
  - *Level 2: Agent & Fleet Comms Plane*: Hermes WebUI (`hermes.brainsos.local`), SOGo Webmail (`mail.brainsos.local`), Fleet Signals & DLQ.
  - *Level 1: Inference & Gateway Plane*: LiteLLM Gateway (`proxy.brainsos.local`), DGX Hardware Telemetry, Ollama Host Daemon (`127.0.0.1:11434`).
  - *Cross-Cutting: Telemetry, Auth & Egress*: Langfuse OTel Tracing, Tool Egress Proxy Console (`mitmweb:8082`), Authentik SSO (`auth.brainsos.local`).
- **Interactive Capabilities**:
  - *Fuzzy Search*: Instant live filter with `/` keyboard shortcut.
  - *Active Status Checks*: HTTP HEAD/GET health check pills (`● 200 OK • 12ms`) with real-time latency pings.
  - *Layout Flexibility*: Default Section Grid, Compact High-Density, Minimal Icon Launcher, and Workspace View (sidebar + active pane).
  - *Modal Inspection*: Built-in modal dialogs for LiteLLM, Governance guardrails, and Egress logs (`target: modal`), alongside clean new-tab launches (`target: newtab`) for IDE and Mail.
