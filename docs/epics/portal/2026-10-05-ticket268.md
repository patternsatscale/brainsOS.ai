## 2. Summary of Changes

### A. React Thin-Spine Portal Shell (`packages/brainsOS-portal/`)
- **Default Subsystem**: Reordered navigation so **Communications Plane (SOGo Webmail / `/mail/`)** is the default top button and landing view (`⌘1`). The Operator Studio (VS Code IDE) is mapped to `⌘2`.
- **Nominal Badge Purged**: Removed all hardcoded `"NOMINAL"` badge elements from the viewport header, tooltips, and status displays. Replaced with concise `"Appliance Active"`.
- **Branded Host URLs**: Viewport header displays host-qualified branded URLs (e.g. `osx.local.brainsos.ai/proxy/ui/usage` and `langfuse.osx.local.brainsos.ai/project/brainsos/sessions`) rather than raw internal paths.
- **Streamlined User Profile**: Redesigned `UserProfileModal` to a sleek Google-style popout menu showing live operator metadata from `/api/v3/core/users/me/` (User's real Name, Email, Username), "Profile Settings" (which loads the standalone settings flow inside the iframe), and a prominent Sign Out button that redirects to the root invalidation flow.
- **Streamlined Help & Documentation View (`HelpView.tsx`)**: Replaced dense multi-page documentation with 2 focused, high-utility tabs:
  - **Tool URLs**: Live, host-aware deep-link inventory for Langfuse, LiteLLM Admin, VS Code IDE, SOGo Webmail, mitmweb Egress Gateway, Authentik Admin Events, and the brainsOS GitHub repository, featuring 1-click copy with feedback and direct launch buttons.
  - **Hotkeys**: Interactive visual cheat sheet with 3D tactile keycaps, clear category groupings, and a live keypress event listener.
- **Dynamic Appliance Parameters**: `SubsystemsDrawer` dynamically displays the live `Appliance Host` and `BrainsOS Version` resolved via `import.meta.env` (`VITE_APPLIANCE_HOST` and `VITE_BRAINSOS_VERSION`), configured in `setup-portal.sh`.
- **Direct Navigation Support**: `App.tsx` initializes `activeKey` using URL pathname and hash (e.g. direct visits to `/docs/` or `#help` automatically activate the Help matrix).

### B. Authentik Identity Provider Theming (`config/authentik/themes/brainsos/`)
- **Login Card Centering**: Fixed the vertical offset bug caused by PatternFly's `@media (min-height: 60rem)` rule by enforcing strict flex centering (`justify-content: center; align-items: center; min-height: 100vh`) across `.pf-c-login`, `.ak-login-container`, and `ak-flow-executor`.
- **High-Contrast Button Typography**: Injected `--pf-c-button--m-primary--Color: #07090E !important` into `:root` and shadow boundaries, guaranteeing crisp, highly legible black text on cyan `#00F2FE` buttons (14:1 contrast).
- **Branded Login Header**: Added prominent `brainsOS • Operator Sign In` headline in `login.html` with Space Grotesk white typography.
- **Elimination of Sign-Out Loop**: Configured sign-out to route directly to Authentik's root invalidation flow (`/flows/-/default/invalidation/?next=/flows/-/default/authentication/`), hid the redundant `#ak-back-home` link, and promoted `#logout` to a primary action, preventing the "Go back to overview" re-login loop.
- **Scoping Global PatternFly Selectors**: Scoped `.pf-c-card`, `.pf-c-title`, `.pf-c-form__group-label`, `.pf-c-form-control`, `input[type="text"]`, and `button[type="submit"]` strictly to `.ak-flow-executor`, `.pf-c-login`, and `.ak-login-container`.
- **Admin Interface Isolation**: Preserves native responsive layout and typography in the Authentik Admin Interface (`/auth/if/admin/`) and user identity settings without 440px width restrictions or forced text-centering.

### C. Communications Plane (SOGo Webmail / `docker/sogo/theme-brainsos.css` & `nginx.conf`)
- **High-Contrast Silver Icons**: Added high-specificity `#CBD5E1` color, SVG fill, and `opacity: 1 !important` rules for all mailbox tree items (`md-sidenav md-icon`, `md-list-item.sg-mailbox-list-item .sg-item-name md-icon`, `p.sg-item-name md-icon`), folder tree expanders (`md-sidenav md-checkbox.sg-folder .md-container:after`), and secondary menu triggers.
- **Obsidian Active State Highlight**: Replaced stark white active mailbox selection with a sleek obsidian card (`#1A2234` with cybernetic pink `#EC4899` accent border and white text/icon) matching the rest of the dark sidebar.
- **Seamless White Reading Pane**: Extended pure clean white (`#FFFFFF`) background across the entire message detail pane (`.sg-detail-view`, `.sg-message-viewer`, `md-card`, `.sg-face`, `.sg-message-body`, and the underlying void), eliminating harsh contrast boundaries when viewing emails.
- **Refined Subtle Expand Button**: Replaced the awkward cyan block expand button with a clean, subtle transparent icon button (`#64748B` with `#F1F5F9` hover background and `#0F172A` icon state), seamlessly blending with the message toolbar.
- **Obsidian Calendar Event & Task Editor Modals**: Themed `md-dialog`, `md-dialog-content`, `.sg-has-form-sections`, and `.sg-form-section` with dark obsidian backgrounds (`#0E131F` / `#141A26`), crisp `#94A3B8` labels, cyan accents for priority tracks, and toned-down watermark icons (`opacity: 0.12`).
- **Cache-Busting & Zero Stale Asset Delay**: Injected `?v=20261006-2` in `sub_filter` and `theme-brainsos.js`, and configured `expires 0; add_header Cache-Control "no-cache, no-store"` in `docker/sogo/nginx.conf` to guarantee instant browser stylesheet updates without stale caching.

### D. Single-Origin Caddy Ingress Gateway (`config/caddy/Caddyfile`)
- **SOGo Static Asset Unauthenticated Bypass**: Added `@sogo_static` path matching `/SOGo.woa/WebServerResources/*`, `/SOGo/WebServerResources/*`, and `/WebServerResources/*` to proxy directly to `sogo:20000` without Authentik forward-auth intervention, ensuring stylesheets, scripts, and font glyphs never trigger unexpected SSO redirects.
- **LiteLLM Route Defaults**: Added 308 permanent redirect from `/proxy`, `/proxy/`, `/proxy/ui`, `/proxy/ui/`, `/ui`, and `/ui/` to `/proxy/ui/usage`.
- **Langfuse Subpath Preservation**: Updated `@langfuse_path` to strip prefix `/langfuse` and preserve `{uri}`, defaulting `/langfuse` and `/langfuse/` to `/project/brainsos/sessions 302`.
- **Documentation Route**: Explicitly handles `/docs` and `/docs/*` through `portal_content` and SSO forward-auth.

### E. Operator IDE Studio (`config/editor/` & `docker/editor/`)
- **Explorer View State Persistence**: Added `"workbench.editor.restoreViewState": true` and `"explorer.autoReveal": true` in `config/editor/settings.json` and entrypoint templates.
- **Preserved `workspaceStorage`**: Removed destructive `rm -rf .../User/workspaceStorage` from `docker/editor/entrypoint.sh`, allowing code-server to remember expanded folder tree state across container reboots.
- **Continue Extension Purged**: Added automated purge in `entrypoint.sh` for any remnant Continue extensions or `.continue` configuration folders.

### F. Tool Egress Gateway & Inspection Console (`config/egress/` & `docker-compose.yml`)
- **Obsidian Cybernetic Theme**: Created `config/egress/theme/brainsos-mitmweb.css` styling mitmweb's web console (`#07090E` background, `#00F2FE` cyan accents, dark tables, custom scrollbars, and styled request/response inspectors).
- **Startup Theme Injection**: Configured `tool-egress-proxy` in `docker-compose.yml` to dynamically inject `brainsos-mitmweb.css` into mitmweb's `index.html` on boot.
