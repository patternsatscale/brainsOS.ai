## 1. Executive Summary & Architectural Alignment

Ticket #191 implements the warm, shared stateless runner container for Nous Hermes (`brainsos-runner-hermes:latest`). 

Operating as a resident HTTP service on port 8642, the runner implements the universal IPC endpoint `POST /v1/agent/run` using `create_runner_app()`. It dynamically maps `request.system_prompt` and `request.conversation` into OpenAI-compatible chat messages, enforcing Rule 2 by routing all LLM completions strictly through LiteLLM (`http://litellm:4000/v1` or `http://host.docker.internal:4000/v1`), capturing tool calls into `AgentTurnResponse.tool_calls`, and extracting token metrics.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                      brainsOS Caller / Dispatcher                      │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ POST /v1/agent/run
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│            runner-hermes (brainsos-runner-hermes:latest)               │
│  - Port 8642 on brainsos-internal                                      │
│  - create_runner_app() FastAPI daemon                                  │
│  - Stateless execution across distinct agent identities                │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ Rule 2: All completions via LiteLLM
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                 LiteLLM Gateway (http://litellm:4000/v1)               │
│  - Serialized inference scheduling (max_parallel_requests: 1)          │

└────────────────────────────────────────────────────────────────────────┘
```
