## 1. Executive Summary & Architectural Alignment

Ticket #193 implements `brainsos-runner-claude:latest`, a warm resident runner container powered by the Anthropic Python SDK.

The runner supports two authentication and execution pathways:
1. Direct Anthropic API (`ANTHROPIC_API_KEY`).
2. Amazon Bedrock via AWS IAM credentials (`AsyncAnthropicBedrock` using `boto3`).

It exposes the universal IPC endpoint `POST /v1/agent/run` on port 8001, handles tool use blocks, aggregates token metrics (`input_tokens`, `output_tokens`), and returns structured responses compliant with brainsOS contracts.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   brainsOS Dispatcher / Agent                          │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ POST /v1/agent/run
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│              runner-claude (Port 8001 on brainsos-internal)            │
│                                                                        │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ Authentication Router:                                         │   │
│   │  ├─ AWS Bedrock Credentials? ──► AsyncAnthropicBedrock         │   │
│   │  └─ ANTHROPIC_API_KEY?       ──► AsyncAnthropic                │   │
│   └────────────────────────────────┬───────────────────────────────┘   │
│                                    ▼                                   │
│   client.messages.create(model, system, messages, max_tokens)         │
│   Extract text, tool_use blocks, input/output token metrics            │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Summary of Changes

### A. Container Definition & Server Implementation
- `docker/runners/claude-sdk/Dockerfile`:
  - Inherited `FROM brainsos-runner-base:latest`.
  - Installed `anthropic>=0.40.0`, `boto3`, `mcp>=1.0.0`, `httpx>=0.25.0`.
  - Configured entrypoint on port `8001`.
- `docker/runners/claude-sdk/server.py`:
  - Implemented dynamic client creation with Bedrock auto-detection.
  - Converted universal dialogue format into Anthropic Messages schema (separating system prompt from message turns).
  - Trapped errors and formatted outputs into `AgentTurnResponse`.

### B. Compose & Build Automation
- `docker-compose.yml`:
  - Added service `runner-claude` on port 8001 under `brainsos-internal`.
  - Injected AWS credentials and `ANTHROPIC_API_KEY` from environment.
