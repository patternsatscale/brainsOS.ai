## 1. Executive Summary & Architectural Alignment

Ticket #192 implements `brainsos-runner-openai:latest`, a warm resident runner container powered by the OpenAI Python SDK. 

The runner fulfills two execution modes:
1. Standard OpenAI function-calling and chat completion loops routed through LiteLLM (Rule 2).
2. Dynamic Script Execution: When `request.extra_params["script_path"]` is provided, the server dynamically loads custom agent scripts from the host via `importlib.util.spec_from_file_location` without restarting the container, executing `await user_module.handle_turn(...)` with full workspace isolation.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   brainsOS Dispatcher / Agent                          │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ POST /v1/agent/run
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│               runner-openai (Port 8002 on brainsos-internal)           │
│                                                                        │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ Check extra_params["script_path"]?                             │   │
│   │  ├─ Yes ──► Load script via importlib with path security check │   │
│   │  │          Execute await handle_turn(request, client)         │   │
│   │  └─ No  ──► AsyncOpenAI chat completion loop via LiteLLM       │   │
│   └────────────────────────────────┬───────────────────────────────┘   │
└────────────────────────────────────┼───────────────────────────────────┘
                                     │
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                 LiteLLM Gateway (http://litellm:4000/v1)               │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Summary of Changes

### A. Container Definition & Server Implementation
- `docker/runners/openai-sdk/Dockerfile`:
  - Inherited `FROM brainsos-runner-base:latest`.
  - Installed `openai>=1.50.0`, `mcp>=1.0.0`, `httpx>=0.25.0`.
  - Set entrypoint on port `8002`.
- `docker/runners/openai-sdk/server.py`:
  - Implemented dynamic script loader with path isolation safeguards (blocking `docker.sock` and `memories` traversal).
  - Built `AsyncOpenAI` function calling completion handler.
  - Formatted metrics and tool call records into `AgentTurnResponse`.

### B. Compose & Host Scaffolding
- `docker-compose.yml`:
  - Added service `runner-openai` on port 8002 with read-only `./data/runners:/data/runners:ro` and workspace mounts.
- `scripts/control/bootstrap-env.sh`:
  - Added `data/runners` to local scaffolded directories.
- `Makefile`:
  - Added build target `runner-openai`.
