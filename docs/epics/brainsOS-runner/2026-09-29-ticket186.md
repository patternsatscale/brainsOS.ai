## 1. Executive Summary & Architectural Alignment

Ticket #186 establishes the foundational universal, engine-agnostic Inter-Process Communication (IPC) data contracts for the brainsOS cognitive execution plane (`brainsOS-runner`). 

By standardizing turn execution payloads into strict Pydantic v2 schemas (`AgentTurnRequest`, `AgentTurnResponse`, `ChatMessage`, `McpServerConfig`, `ToolCallRecord`, `MemoryDelta`, `ExecutionMetrics`), higher-level agent coordination layers (`brainsOS-agent`) can execute cognitive turns across interchangeable LLM execution substrates (Hermes, OpenAI SDK, Anthropic Claude SDK, and OpenHands Docker sandboxes) with zero runtime container coupling.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   brainsOS-agent (Application Plane)                   │
│          Assembles persona, OKF memory context & user dialogue         │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
              AgentTurnRequest (Universal Cognitive IPC)
              - run_id, agent_id, model, system_prompt
              - conversation: list[ChatMessage]
              - mcp_servers: list[McpServerConfig]
              - workspace_dir, timeout_sec, extra_params
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   brainsOS-runner (Compute Plane)                      │
│            Warm HTTP Daemons & Ephemeral Docker Sandboxes              │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
              AgentTurnResponse (Universal Execution Result)
              - run_id, status: Literal["completed", "failed", "timed_out"]
              - output_text, tool_calls: list[ToolCallRecord]
              - memory_deltas: list[MemoryDelta], metrics: ExecutionMetrics
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                 OKF Memory Updates & Outbound Transport                │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Summary of Changes

### A. New Package: `packages/brainsOS-runner`
- `packages/brainsOS-runner/pyproject.toml`:
  - Configured standalone `brainsOS-runner` package with Python `>=3.10` compatibility, `uv` build backend, and runtime dependencies (`pydantic>=2.0.0`, `pyyaml>=6.0`, `httpx>=0.25.0`, `fastapi>=0.100.0`).
- `packages/brainsOS-runner/README.md`:
  - Package overview and IPC architecture documentation.
- `packages/brainsOS-runner/brainsos_runner/models.py`:
  - Defined engine-agnostic Pydantic v2 data models with `model_config = ConfigDict(extra="forbid")`:
    - `ChatMessage`: `role: Literal["system", "user", "assistant", "tool"]`, `content: str`, optional `author`, optional `tool_call_id`.
    - `McpServerConfig`: `name: str`, `url: str`, `transport: Literal["sse", "stdio"]`.
    - `ToolCallRecord`: `id: str`, `tool_name: str`, `arguments: dict[str, Any]`, `output: str`, `exit_code: int`.
    - `MemoryDelta`: `action: Literal["set", "append", "delete"]`, `key: str`, `value: Any`.
    - `ExecutionMetrics`: `prompt_tokens: int`, `completion_tokens: int`, `duration_ms: int`.
    - `AgentTurnRequest`: Strict request contract validating `timeout_sec > 0`.
    - `AgentTurnResponse`: Strict response contract with `status: Literal["completed", "failed", "timed_out"]`.
- `packages/brainsOS-runner/brainsos_runner/__init__.py`:
  - Clean exports for all schema models.
- `packages/brainsOS-runner/tests/test_models.py`:
  - 13 comprehensive unit tests validating roundtrip serialization/deserialization, strict schema validations, invalid role rejection, and non-positive timeout rejection.

## 5. Security & Isolation Constraints

- **Rule 1 & Rule 7 (Purity & Compartmentalization)**: Core models do not reference container paths, host daemons, or database internals. Memory updates are modeled strictly as structured `MemoryDelta` events.
