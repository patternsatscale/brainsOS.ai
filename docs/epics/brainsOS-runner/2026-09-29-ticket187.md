## 1. Executive Summary & Architectural Alignment

Ticket #187 establishes the declarative configuration authority and registry loader for all brainsOS cognitive compute nodes. In accordance with Rule 9 (Declarative Manifest Authority), all available execution backends—whether warm HTTP daemons or ephemeral Docker sandboxes—are declared in `config/runners.yaml` and loaded via `RunnerRegistry`.

The registry validates node configurations against strict schema requirements (e.g. requiring `endpoint` for `warm_http` and `image` for `ephemeral_docker`) and provides dynamic client instantiation via `get_runner(runner_id)`.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        config/runners.yaml                             │
│                  Declarative Compute Node Manifest                     │
│                                                                        │
│  - hermes-warm       (warm_http: http://runner-hermes:8642)            │
│  - openai-warm       (warm_http: http://runner-openai:8002)            │
│  - claude-warm       (warm_http: http://runner-claude:8001)            │
│  - openhands-sandbox (ephemeral_docker: brainsos-openhands-sandbox)    │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
                     RunnerRegistry.load_from_yaml()
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                       RunnerRegistry Engine                            │
│  - Validates schema, endpoints, image tags, timeouts & concurrency     │
│  - Instantiates typed RunnerClient instances (WarmHttp / Ephemeral)    │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Summary of Changes

### A. Manifest Authority
- `config/runners.yaml`:
  - Created authoritative YAML manifest registering 4 default cognitive execution nodes:
    - `hermes-warm`: port 8642, timeout 120s, concurrency limit 4.
    - `openai-warm`: port 8002, timeout 120s, concurrency limit 4.
    - `claude-warm`: port 8001, timeout 180s, concurrency limit 4.
    - `openhands-sandbox`: ephemeral container, 2GB memory cap, 2.0 CPU cap, 300s timeout.

### B. Configuration Models & Registry
- `packages/brainsOS-runner/brainsos_runner/config.py`:
  - Defined `RunnerConfig` with strict type validation (`warm_http` requires non-empty `endpoint`, `ephemeral_docker` requires non-empty `image`, `local_script` requires `script_path`).
- `packages/brainsOS-runner/brainsos_runner/registry.py`:
  - Implemented `RunnerRegistry` with:
    - `load_from_yaml(path: Union[str, Path]) -> RunnerRegistry`
    - `get_runner_config(runner_id: str) -> RunnerConfig`
    - `get_runner(runner_id: str) -> RunnerClient`
    - `list_runners() -> list[RunnerConfig]`
    - Dynamic factory registration mechanism for test isolation.
    - Typed exceptions: `RunnerRegistryError`, `RunnerNotFoundError`, `InvalidRunnerConfigError`.
- `packages/brainsOS-runner/brainsos_runner/__init__.py`:
  - Exported registry and configuration classes.
- `packages/brainsOS-runner/tests/test_registry.py`:
  - 9 comprehensive unit tests asserting parsing of `config/runners.yaml`, duplicate detection, missing field validation, and client factory instantiation.
