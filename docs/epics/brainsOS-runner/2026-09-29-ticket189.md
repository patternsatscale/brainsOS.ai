## 1. Executive Summary & Architectural Alignment

Ticket #189 implements `EphemeralDockerRunnerClient`, providing on-demand, disposable container sandboxing for deep execution agents (such as OpenHands or unvetted bash execution).

The client enforces strict isolation constraints defined in `AGENTS.md`:
- **Rule 4 (Host Sandboxing)**: Rejects any attempt to mount the Docker socket (`/var/run/docker.sock`). Runs containers with `--security-opt no-new-privileges:true`.
- **Rule 1 (Memory Purity)**: Forbids mounting the agent memory directory (`/memories` or `agent_memories`). Containers can only access their designated `/workspace` mount.
- **Resource Constraints (Rule 3)**: Caps memory (`--memory=2g`) and CPU cores (`--cpus=2.0`) to avoid thrashing unified memory buses.
- **Strict Lifecycles**: Enforces hard execution timeouts with `docker kill` and guaranteed container removal (`--rm` + `docker rm -f`).

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   EphemeralDockerRunnerClient                          │
│  - Pre-execution validation: Blocks docker.sock & memories mounting   │
│  - Mounts workspace: -v {workspace_dir}:/workspace:rw                 │
│  - Injects AgentTurnRequest payload                                   │
│  - Sets resource limits: --memory=2g, --cpus=2.0                      │
│  - Hard timeout guard: docker kill on timeout                         │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
                    docker run --rm -i ...
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                    Ephemeral Docker Sandbox Container                  │
│  - Isolated network (brainsos-internal or none)                       │
│  - Unprivileged non-root execution                                    │
│  - Automatic destruction upon process exit                            │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Summary of Changes

### A. Sandbox Client
- `packages/brainsOS-runner/brainsos_runner/clients/docker.py`:
  - Implemented `EphemeralDockerRunnerClient(RunnerClient)`:
    - Path validation enforcing Rule 1 and Rule 4 invariants before spawning containers.
    - Ephemeral execution using `asyncio.create_subprocess_exec`.
    - Injects request JSON payload via workspace file and stdin pipe.
    - Hard timeout enforcement with asynchronous container killing and removal.
    - Robust response parsing (structured JSON from stdout, workspace response file, or plain text fallback).

### B. Unit & Security Tests
- `packages/brainsOS-runner/tests/test_docker_runner.py`:
  - 7 unit tests:
    - `test_security_violation_docker_sock`: Asserts rejection of Docker socket.
    - `test_security_violation_memories`: Asserts rejection of `/memories` mount.
    - `test_successful_turn_structured_json`: Validates argument flags, resource caps, and JSON response parsing.
    - `test_successful_turn_plaintext_fallback`: Validates text output handling.
    - `test_container_failure`: Validates non-zero exit codes.
    - `test_container_timeout_and_kill`: Validates timeout triggers `docker kill`.
    - `test_registry_get_ephemeral_docker_runner`: Confirms registry factory returns `EphemeralDockerRunnerClient`.
