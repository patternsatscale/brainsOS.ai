## 1. Summary of Changes

### OpenBao Control Plane Secret Manager & Egress Proxy (`CRIT-04`, `HIGH-01`)
- **Created** `config/openbao/openbao.hcl` (built-in encrypted Raft storage at `/openbao/data`, `tls_disable = 1`, `disable_mlock = true`, bound inside container on `0.0.0.0:8200` with zero host port bindings).
- **Created** `scripts/setup/setup-secrets.sh` (initializes/unseals Raft under `${BRAINSOS_CONTROL_PLANE_DIR}/openbao`, enables KV v2 at `secret`, writes read-only `egress-proxy-ro` policy + `egress-proxy` AppRole credentials to `${BRAINSOS_CONTROL_PLANE_DIR}/openbao_approle/egress-approle.env` with `0600` permissions and `.seal.json` with `0600`).
- **Created** `packages/brainsOS-telemetry/brainsos_telemetry/openbao_client.py` (`put_tool_secrets`, supporting direct `OPENBAO_ADDR` HTTP KV v2 API writes and portable `docker exec -i bao kv put secret/tools -` fallback with zero host port exposure).
- **Modified** `packages/brainsOS-telemetry/brainsos_telemetry/system.py` so `get_runners_status` and `update_hermes_config` store third-party tool keys (`FIRECRAWL_API_KEY`, `TAVILY_API_KEY`, `EXA_API_KEY`, `BRAVE_SEARCH_API_KEY`, optional `GITHUB_TOKEN`) in OpenBao KV v2 while persisting non-secret `in-transit-openbao-managed` placeholders in `data/runners/hermes/.env`.
- **Modified** `config/egress/addons/github_auth.py` into `OpenBaoEgressAddon`: removed legacy `GITHUB_TOKEN_CINDY`/`GITHUB_BASIC_AUTH_CINDY`/`bawtford`/`[INJECTED_CINDY_TOKEN]` logic, added AppRole authentication reading `secret/data/tools`, added `is_blocked_destination` SSRF blocks for RFC1918/loopback/link-local/CGNAT/IMDSv4/IMDSv6 (`fd00:ec2::254/128`), enforced `TOOL_EGRESS_ALLOWED_CONTAINERS` + HTTPS + Host/SNI verification, and redacted injected headers to `[INJECTED_OPENBAO_SECRET]`.
- **Modified** `scripts/control/start-control-plane.sh` to invoke `setup-secrets.sh` (Step `4c`), removed legacy `GITHUB_TOKEN_CINDY`/`GITHUB_BASIC_AUTH_CINDY` provisioning, and standardized default virtual key spend ceiling via `DEFAULT_VKEY_BUDGET="${LITELLM_DEFAULT_MAX_BUDGET:-25.0}"`.

### Network Segmentation, Auth/Mail Hardening & Telemetry Bindings (`CRIT-03`, `MED-06`)
- **Modified** `docker-compose.yml` to declare `brainsos-auth-net`, `brainsos-secrets-net`, and `brainsos-mail-net`.
- **Modified** `docker/compose/compose.control.yml` to deploy `openbao` (`quay.io/openbao/openbao:${OPENBAO_IMAGE_TAG:-2.2.0}`, `brainsos-control-secrets`) on `brainsos-control-net` + `brainsos-secrets-net` with `cap_drop: [ALL]` and zero host ports.
- **Modified** `docker/compose/compose.apps.yml` to remove `code-server`, `sogo-db`, `sogo`, `authentik-db`, `authentik-redis`, `authentik-server`, `authentik-worker`, and `gitea` from `brainsos-internal-net`; moved Authentik stack onto `brainsos-auth-net` with `--requirepass`; isolated SOGo backend links onto `brainsos-mail-net`; restricted Gitea (`DISABLE_REGISTRATION=true`, `ALLOW_ONLY_EXTERNAL_REGISTRATION=true`, `REVERSE_PROXY_TRUSTED_PROXIES`); removed `LITELLM_MASTER_KEY`, superuser passwords, and `NODE_TLS_REJECT_UNAUTHORIZED=0` from `code-server`; pinned `CODE_SERVER_IMAGE_TAG:-4.145.2` and `signal-cli` image digest.
- **Modified** `docker/sogo/nginx.conf` to restrict `location ^~ /SOGo` to proxy subnets (`127.0.0.1`, `172.16.0.0/12`, `10.0.0.0/8`) and rely strictly on `$upstream_sogo_user`.
- **Modified** `scripts/setup/setup-git.sh` to create mirrored agent repos as `"private": true`.
- **Modified** `docker/compose/compose.telemetry.yml` & `docker/langfuse/docker-compose.yml` to default telemetry ports to `127.0.0.1:`, remove `NODE_TLS_REJECT_UNAUTHORIZED=0`, and pin `minio` image digest.

### Non-Root Runners, Runner Auth, IMDSv6, MCP/OKF Purity & Supply Chain Pinning (`CRIT-04`, `MED-02`, `MED-03`, `MED-06`, `LOW-03`)
- **Modified** `docker/runners/base/Dockerfile`, `docker/runners/hermes/Dockerfile`, `docker/runners/hermes/entrypoint.sh`, `docker/runners/openai-sdk/Dockerfile`, `docker/runners/claude-sdk/Dockerfile` to enforce non-root UID/GID `10001:10001`, pinned `uv:0.6.14`, and safe `${HOME:-/tmp}/.hermes` paths.
- **Modified** `docker/compose/compose.agents.yml` (`user: "10001:10001"`, `HERMES_UID/GID=10001`, `cap_drop: [ALL]`, `pids_limit: 256`, `RUNNER_AUTH_TOKEN`, OpenBao `in-transit-openbao-managed` placeholders, read-only `openbao_approle` dir mount + `brainsos-secrets-net` on `tool-egress-proxy`, removed `LITELLM_MASTER_KEY`/`AWS_*`/`${HOME}/.aws` mounts/superuser passwords).
- **Modified** `packages/brainsOS-runner/brainsos_runner/server.py` & `packages/brainsOS-runner/brainsos_runner/clients/http.py` to enforce and send `X-Runner-Token` when `RUNNER_AUTH_TOKEN` / `auth_token` is configured.
- **Modified** `docker/runners/hermes/server.py`, `docker/runners/openai-sdk/server.py`, `docker/runners/claude-sdk/server.py` to strip `LITELLM_MASTER_KEY` fallback/direct Bedrock runner access and enforce `agent_id` validation plus `os.path.realpath`/`os.path.commonpath` allowlisting in `_load_dynamic_script`.
- **Modified** `docker/caddy/Dockerfile`, `docker/editor/Dockerfile`, `docker/editor/entrypoint.sh`, `docker/egress/Dockerfile`, `docker/hermes/Dockerfile`, `docker/mail/Dockerfile.ingress` to pin image digests/tags, eliminate `curl | sh` `uv` installs and `/etc/skel/.config/gh/hosts.yml`, remove `NODE_TLS_REJECT_UNAUTHORIZED=0` & `LITELLM_MASTER_KEY` injection, and set default editor key `max_budget` via `LITELLM_DEFAULT_MAX_BUDGET` (`25.0`).
- **Modified** `scripts/setup/imds-guard.sh` to add `ip6tables` `BRAINSOS-IMDS6` drop rules (`fd00:ec2::254/128`) and `BRAINSOS_LITELLM_STATIC_IP` fallback (including `--dry-run` `-C` idempotency guard).
- **Modified** `packages/brainsOS-mcp/brainsos_mcp/modules/memory.py` (`BRAINSOS_AGENT_ID` strict single-tenant binding) and `packages/brainsOS-memory/brainsos_memory/okf/purity.py` (`realpath`+`commonpath`, symlink + non-`.gitkeep` dotfile rejection).
- **Modified** `scripts/control/emergency-stop.sh` (replaced `eval` with `printenv`), `scripts/control/generate-env.sh` (`AUTHENTIK_REDIS_PASSWORD`, `RUNNER_AUTH_TOKEN`), `.env.example`, `packages/brainsOS-agent/brainsos_agent/adapters/hermes.py` (`HERMES_RUN_MAX_SEC=3600.0`), `scripts/setup/setup-editor.sh` (`LITELLM_DEFAULT_MAX_BUDGET=25.0`), and `README.md` (updated L2/L3/L4/L6 architecture diagrams for OpenBao, 8 isolated bridge networks, and non-root runners).
- **Tests Created / Updated**: `packages/brainsOS-telemetry/tests/test_openbao_security.py`, `packages/brainsOS-runner/tests/test_http_runner.py`, `packages/brainsOS-telemetry/tests/test_alb_cognito_sso.py`, `packages/brainsOS-appliance/tests/test_imds_guard.py`, `packages/brainsOS-appliance/tests/test_gitea_source_control.py`.

## 2. Acceptance Criteria Verification

- [x] Segregated **OpenBao** container (`quay.io/openbao/openbao:2.2.0`, `brainsos-control-secrets`) with built-in Raft storage (`${BRAINSOS_CONTROL_PLANE_DIR}/openbao`), zero host ports, no shared DB/Redis.
- [x] Third-party tool secrets stored in OpenBao KV v2 via `brainsos-system-api` (`openbao_client.py`); `tool-egress-proxy` reads AppRole creds (`secret/data/tools`) for verified HTTPS in-transit header injection; `runner-hermes` holds `in-transit-openbao-managed` placeholders.
- [x] Legacy `GITHUB_TOKEN_CINDY`, `/etc/skel/.config/gh/hosts.yml`, and `bawtford` proxy hardcodes removed; `OpenBaoEgressAddon` blocks RFC1918, loopback, link-local, CGNAT, IMDSv4, and IMDSv6 destinations.
- [x] Networks segmented (`brainsos-auth-net`, `brainsos-secrets-net`, `brainsos-mail-net`); Authentik/SOGo/code-server/Gitea removed from `brainsos-internal-net`; Authentik Redis `--requirepass` enabled; Gitea registration locked down; telemetry ports defaulted to `127.0.0.1`.
- [x] `LITELLM_MASTER_KEY`, `AWS_*`, `${HOME}/.aws`, and superuser passwords stripped from runners/editor; non-root `10001:10001`, `cap_drop: [ALL]`, `pids_limit: 256`, `X-Runner-Token`, and SDK allowlisting enforced.
- [x] `ip6tables` `fd00:ec2::254/128` (`BRAINSOS-IMDS6`) and `BRAINSOS_LITELLM_STATIC_IP` added to `imds-guard.sh`; single-tenant MCP boundary and OKF `realpath`+`commonpath` / dotfile / symlink checks enforced.
- [x] `NODE_TLS_REJECT_UNAUTHORIZED=0` removed; floating `:latest` Docker images & `uv` installers pinned; `eval` removed from `emergency-stop.sh`; `LITELLM_DEFAULT_MAX_BUDGET=25.0` and `HERMES_RUN_MAX_SEC=3600.0` defaults configured.
