## 1. Summary of Changes

### External `api.<domain>` Virtual-Key AI Gateway & L7 Route Allowlist
- **Modified** `config/caddy/Caddyfile` and `config/caddy/Caddyfile.appliance`:
  - Added reusable `(litellm_external_virtual_key_gateway)` snippet enforcing:
    - `import strip_auth_identity_headers` and `request_header -Cookie` (stateless virtual-key API, zero ambient session cookies or spoofed identity headers).
    - `request_body { max_size 10MB }` to protect LiteLLM's serialized single-worker runtime (`Rule 3`).
    - Strict OpenAI & Anthropic inference route allowlist (`POST /v1/chat/completions`, `/v1/completions`, `/v1/responses`, `/v1/embeddings`, `/v1/moderations`, `/v1/rerank`, `/v1/messages`, `/v1/audio/*`, `/v1/images/*`; `GET /v1/models`, `/v1/models/*`), returning JSON `403 Forbidden` on all other paths (`/ui*`, `/sso*`, `/key*`, `/model/*`, `/user*`, `/team*`, `/config*`, `/credentials*`, `/spend*`, `/v1/sys*`, etc.).
    - Explicit L7 rejection (`403 Forbidden`) of `LITELLM_MASTER_KEY` (both `Authorization: Bearer ...` and `x-api-key: ...`) and any `sk-master-*` prefix.
    - Edge virtual-key format pre-filter (`sk-[A-Za-z0-9_.-]{8,}`), returning JSON `401 Unauthorized` before traffic reaches LiteLLM's Uvicorn worker when missing or malformed.
  - Added `api.{$BRAINSOS_DOMAIN:localhost}` to the HTTPS site listener in `config/caddy/Caddyfile.appliance` and `@api_host header_regexp Host (?i)^api\.` inside `(unified_ingress)` across both Caddyfiles.
  - Hardened `@proxy_host` (`proxy.<domain>`), `@proxy_api_path` (`/v1/*` & `/proxy/v1/*`), `handle /proxy/ui/*`, `handle @litellm_ui`, `handle @litellm_api`, and `handle @litellm_proxy_fallback` so LiteLLM management/admin/UI endpoints require `authentik_admin_forward_auth` (`authentik Admins` SSO) while programmatic `sk-*` calls go through `(litellm_external_virtual_key_gateway)`.

### Master Key Prefix Separation (`sk-master-*`) & AMI Hygiene Scan
- **Modified** `.env.example`, `scripts/control/generate-env.sh`, and `packages/brainsOS-appliance/packer/provision.sh`:
  - Updated `generate-env.sh` to generate `LITELLM_MASTER_KEY` with the distinct `sk-master-<32hex>` prefix (preserving existing custom keys on upgrade) and updated `.env.example` placeholder to `sk-master-brainsos-mock-key`.
  - Extended `snapshot_scan` in `packages/brainsOS-appliance/packer/provision.sh` to detect both `sk-brainsos-[0-9a-f]{32}` and `sk-master-[0-9a-f]{32}` anywhere in the baked filesystem tree.

### Route 53 DDNS, Fleet Launch & URL Directory Alignment
- **Modified** `scripts/control/sync-route53-ddns.py`:
  - Updated `sync_route53_record` to atomically synchronize `api.<fqdn>` (`A`) and `_brainsos-owner.api.<fqdn>` (`TXT` HMAC claim) alongside `<fqdn>` in a single `ChangeBatch` (with `--no-api-subdomain` / `BRAINSOS_ROUTE53_SYNC_API=false` opt-out).
- **Modified** `scripts/control/launch-fleet.sh`, `packages/brainsOS-terminal/brainsos_terminal/urls.py`, `scripts/control/show-urls.sh`, and `README.md`:
  - Surfaced `https://api.<domain>/v1` across fleet launch rosters, `show-urls.sh` (including `/etc/hosts` check), `brainsos_terminal.urls` (eliminating `LITELLM_MASTER_KEY` fallback from displayed gateway auth), and `README.md`.
- **Created** `packages/brainsOS-appliance/tests/test_ticket410_external_api_gateway.py`:
  - Added static, unit, and live local `brainsos-caddy:latest` TLS container L7 behavioral tests covering `api.<domain>`, virtual-key allowlisting, master-key `403`, missing-key `401`, admin-route `403`, header/cookie stripping, `sk-master-*` generation, and Route 53 `api.<fqdn>` DDNS synchronization.
