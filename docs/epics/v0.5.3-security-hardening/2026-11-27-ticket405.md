## 1. Summary of Changes

### Pre-Wizard API Redaction, Wizard Session Cookie & Brute-Force Lockout (`HIGH-1`)
- **Modified** `packages/brainsOS-telemetry/brainsos_telemetry/system.py`:
  - Restricted unauthenticated pre-wizard `GET /api/v1/system/identity` and `GET /api/v1/system/status` to strictly 4 minimal fields (`{firstboot_wizard_completed, unit_name, url, tls_mode}` via `_minimal_prewizard_metadata`), omitting `os`, `disk`, `runners`, `admin_email`, `user_sub`, `local_domain`, `instance_id`, `route53_zone_id`, and `userdata_routing_configured` until authenticated via Authentik Admin or a signed wizard session cookie.
  - Added `POST /api/v1/system/firstboot/session` verifying `bootstrap_token` against `_resolve_expected_bootstrap_tokens` and minting an HMAC-SHA256 signed `brainsos_wizard_session` cookie (`HttpOnly; Secure; SameSite=Strict`, `max_age=1800s`) so pre-SSO browser polling (`/status`, `/identity`, `/dns-check`, `/jobs/{job_id}`, `/jobs/{job_id}/stream`) works seamlessly during wizard execution.
  - Added per-IP `_BootstrapRateLimiter` stored on `app.state.bootstrap_limiter` using `_extract_client_ip` (relying strictly on rightmost Caddy-appended `X-Forwarded-For` or `request.client.host` — ignoring untrusted client-supplied `X-Real-IP` headers to prevent lockout bypass): 5 failed attempts trigger exponential backoff starting at `60s` (capped at `3600s`) with `HTTP 429` and `Retry-After` headers across `/firstboot/session`, `/setup`, `/domain`, and `/identity`.
- **Modified** `packages/brainsOS-portal/src/components/SystemManager.tsx`:
  - Converted Wizard Step 1 -> Step 2 transition (`Next Step →`) into an async call to `POST /api/v1/system/firstboot/session` (with `X-CSRF-Token` and `credentials: 'include'`), refreshing full pre-wizard identity/status on `200` and surfacing `403`/`429` errors inline.
  - Added `credentials: 'include'` across SystemManager API fetches (`/csrf`, `/status`, `/identity`, `/dns-check`, `/setup`, `/jobs/*`, `/runners/hermes/config`, `/security/breakglass`, `/sso/cognito`, `/reboot`, `/terminal/exec`), added custom high-entropy break-glass secret inputs (`wizardBreakglassSecret`, `breakglassAdminSecret`), and updated wizard Step 1 / Break-Glass copy to reflect one-time bootstrap token semantics and locked OS `admin`.
- **Modified** `packages/brainsOS-appliance/scripts/firstboot.sh`:
  - Replaced predictable `i-appliance-${HOST_HASH:-local}` non-EC2 fallback with a cryptographically random 128-bit `bt-<32hex>` token persisted with mode `0600` at `${TARGET_DATA_DIR}/control_plane/bootstrap-token` and written to `BRAINSOS_BOOTSTRAP_TOKEN` / `BRAINSOS_INSTANCE_ID`.

### Post-Wizard RBAC & Fail-Closed Admin Group Enforcement (`HIGH-1`)
- **Modified** `packages/brainsOS-telemetry/brainsos_telemetry/system.py`:
  - Removed `_require_system_auth` and switched `/api/v1/system/status`, `/api/v1/system/runners`, and post-wizard routes to `verify_admin_read_security`.
  - Applied `_require_wizard_or_admin_read` unconditionally to `/api/v1/system/jobs/{job_id}` and `/api/v1/system/jobs/{job_id}/stream` (removing the `("latest", "active")` partial check) as well as `POST /api/v1/system/dns-check`.
  - Updated `_is_authorized_admin` to fail closed (`False`) whenever `X-Authentik-Groups` is `None` outside `BRAINSOS_STAGE == "test"`, and enforced missing-username `403` on `/api/v1/system/me` outside `BRAINSOS_STAGE == "test"` while keeping `/me` and minimal `/identity` accessible to non-admin `brainsos-viewers`.
  - Moved `BRAINSOS_STAGE == "test"` check ahead of `_IMDS_CACHE` in `_query_imds_metadata` so production-stage tests cannot pollute test-stage `BRAINSOS_TEST_INSTANCE_ID` assertions.

### One-Time Instance ID Bootstrap & Locked OS `admin` Password (`HIGH-3`)
- **Modified** `packages/brainsOS-telemetry/brainsos_telemetry/system.py`:
  - Permanently disabled `bootstrap_token` / `INSTANCE_ID` bootstrap verification (`_resolve_expected_bootstrap_tokens` returns `[]`) and wizard session validation (`_verify_wizard_session_cookie` returns `False`) once `firstboot_wizard_completed` is `True` (including `POST /setup` with `dismiss_only=True`, which also clears `brainsos_wizard_session` and sets `BRAINSOS_BREAKGLASS_ENABLED=false`).
  - Enforced `_validate_breakglass_secret` (`>= 16` chars, password complexity rules, `!= INSTANCE_ID`) whenever explicitly enabling break-glass via `POST /api/v1/system/setup` (`breakglass_secret`) or `POST /api/v1/system/security/breakglass` (`admin_secret`).
- **Modified** `packages/brainsOS-appliance/scripts/firstboot.sh`, `scripts/control/reload-env.sh`, and `scripts/control/set-domain.sh`:
  - Locked OS `admin` login password via `passwd -l admin` across all three scripts and removed all `chpasswd` assignments of `INSTANCE_ID` to Linux `admin`.
  - Generated independent 192-bit random secrets in `firstboot.sh` for `BRAINSOS_ADMIN_PASSWORD`, `BRAINSOS_INSTANCE_ADMIN_PASSWORD`, and `AUTHENTIK_BOOTSTRAP_PASSWORD` (never equal to `INSTANCE_ID`), stopped falling back to `DETECTED_INSTANCE_ID` or `ADMIN_PASSWORD` in `reload-env.sh` and `set-domain.sh` (using `BRAINSOS_NEW_BREAKGLASS_SECRET` or an independent 192-bit random secret / `set_unusable_password`), and updated boot banner labels (`Wizard Bootstrap` / `OS/SSO Passwords`).

### Tests
- **Modified** `packages/brainsOS-telemetry/tests/{test_system.py,test_system_api.py,test_alb_cognito_sso.py,test_tracing_spi.py}`, `packages/brainsOS-appliance/tests/{test_firstboot.py,test_tls_byod.py}`, and `packages/brainsOS-appliance/tests/e2e/test_e2e_v053_tier{1,2}.py` for `#405` compatibility and comprehensive coverage of redaction, 5-attempt `429` lockout (including `X-Real-IP` spoofing immunity with constant `X-Forwarded-For`), cookie attributes + pre-SSO polling, post-wizard/dismiss revocation, viewer RBAC, fail-closed groups, 128-bit `bootstrap-token`, independent `AUTHENTIK_BOOTSTRAP_PASSWORD`, and `passwd -l admin`.

- **Modified (Tier 5 Remediation)** `packages/brainsOS-telemetry/brainsos_telemetry/system.py`, `packages/brainsOS-telemetry/tests/test_system_api.py`, and `README.md`:
  - Rejected `'` in `superuser_name` upfront with HTTP `400` in `POST /api/v1/system/setup` (`system.py:2337`, matching `unit_name` and `env-upsert.sh`) with regression coverage in `test_system_api.py`.
  - Updated `README.md` Quickstart Option A (`Step 2`) and the Appliance Service Endpoints table to document the EC2 Instance ID strictly as a one-time pre-wizard bootstrap token, locked OS `admin` (`passwd -l admin`), and randomized Authentik `admin` bootstrap password.

## 2. Acceptance Criteria Verification

- [x] **Pre-wizard redaction (`HIGH-1`)**: Unauthenticated pre-wizard `GET /identity` and `GET /status` return strictly `{firstboot_wizard_completed, unit_name, url, tls_mode}`.
- [x] **Brute-force protection & random non-EC2 bootstrap token (`HIGH-1`)**: `firstboot.sh` generates 128-bit `bt-<32hex>` (`0600`) in `control_plane/bootstrap-token`; per-IP rate limiter returns `429` + `Retry-After` on 5th bad attempt with exponential backoff.
- [x] **Signed wizard session cookie (`HIGH-1`)**: `POST /api/v1/system/firstboot/session` mints HMAC-SHA256 `brainsos_wizard_session` (`HttpOnly; Secure; SameSite=Strict`) enabling pre-SSO Portal polling on `/status`, `/identity`, `/dns-check`, `/jobs/{job_id}`, `/jobs/{job_id}/stream`.
- [x] **Post-wizard RBAC & fail-closed groups (`HIGH-1`)**: Admin-only enforcement on `/status`, `/runners`, `/dns-check`, and ALL `/jobs/{job_id}` + `/stream` routes; `_is_authorized_admin` fails closed when `X-Authentik-Groups` is `None` outside `BRAINSOS_STAGE=test`; `brainsos-viewers` allowed only on `/me` (`is_superuser: false`) and minimal `/identity`.
- [x] **One-time `INSTANCE_ID` & locked OS `admin` (`HIGH-3`)**: `passwd -l admin` enforced in `firstboot.sh`, `reload-env.sh`, and `set-domain.sh`; independent `AUTHENTIK_BOOTSTRAP_PASSWORD`; `INSTANCE_ID` bootstrap permanently disabled after wizard completion or dismissal; custom high-entropy secret required for break-glass.
- [x] **Protected files untouched**: `ViewportFrame.tsx` (`LOW-3`) and `test_e2e_v053_tier{3,4}.py` untouched (`git diff -- packages/brainsOS-portal/src/components/ViewportFrame.tsx` empty; `Caddyfile*` were later updated in `#407`).
