## 1. Summary of Changes

### Default Encrypted EBS Root Volumes (`MEDIUM-3`)
- **Modified** `scripts/control/launch-fleet.sh`:
  - Added `ENCRYPT_VOLUMES=true` default state and `--no-encrypt` CLI option (documented in `usage()`).
  - Updated Direct AMI mode `--block-device-mappings` generation so `Encrypted=true` is enforced by default; `--no-encrypt` sets `Encrypted=false` unless `--hibernation-capable` is active (which logs a warning and preserves `Encrypted=true`, as EC2 Hibernation requires an encrypted root volume).

- **Modified** `packages/brainsOS-appliance/tests/test_launch_fleet.py`:
