## 1. Summary of Changes

### OpenBao Web UI Enablement & Isolated Ingress Attachment
- **Modified** `config/openbao/openbao.hcl`: enabled `ui = true` while preserving encrypted integrated Raft storage and zero host port bindings.
- **Modified** `docker/compose/compose.control.yml`: attached `openbao` (`brainsos-control-secrets`) to `brainsos-ingress-net` (keeping `caddy` isolated from `brainsos-control-net` and `brainsos-secrets-net`, preserving Rule 6 DB isolation) and mounted `${BRAINSOS_CONTROL_PLANE_DIR}/caddy_root.crt` read-only at `/etc/ssl/caddy/root.crt:ro`.
- **Modified** `docker/compose/compose.ingress.yml`: aligned Caddy's internal ingress alias with `${BRAINSOS_URL:-${BRAINSOS_DOMAIN:-local.brainsos.ai}}` so internal OIDC discovery resolves Caddy cleanly over HTTPS without NAT hairpinning.

### Authentik OIDC Single Sign-On Integration
- **Modified** `config/authentik/blueprints/brainsos-portal.yaml`: added `openbao-vault` `OAuth2Provider` (`OpenBao Secrets Vault OIDC`, `sub_mode: "user_email"`, `litellm_groups_mapping`, and `/ui/vault/auth/oidc/oidc/callback` redirect URIs) plus `openbao-vault` Application entry.
- **Modified** `scripts/control/generate-env.sh` & `.env.example`: auto-generate `AUTH_OPENBAO_CLIENT_SECRET`.
- **Modified** `scripts/setup/setup-secrets.sh`: added `sync_openbao_oidc` and `--sync-oidc` flag enabling the `oidc` auth backend (`default_role="admin"`), provisioning the `openbao-admin` policy and `auth/oidc/role/admin` bound to `["authentik Admins", "admins", "admin", "appliance-admins"]`, and building a combined system CA + Caddy root CA PEM for OIDC discovery TLS verification.
- **Modified** `scripts/setup/setup-portal.sh` & `scripts/control/reload-env.sh`: synchronize `openbao-vault` provider secrets and redirect URIs across domain updates and trigger `./scripts/setup/setup-secrets.sh --sync-oidc`.

### Caddy Ingress Routing & ThinSpine Portal Icon
- **Modified** `config/caddy/Caddyfile` & `config/caddy/Caddyfile.appliance`: added `@openbao_root` (`/secrets`, `/secrets/`, `secrets.*` host `/`) and `@openbao_paths` (`/ui/vault*`, `/ui/assets/*`, `/ui/engines-dist/*`, `/ui/sw*`, `/ui/favicon.svg`, `/v1/sys/*`, `/v1/auth/*`, `/v1/secret/*`, `/v1/identity/*`, `/v1/cubbyhole/*`) protected by `import authentik_forward_auth` **before** LiteLLM `/ui/*`, `@litellm_api`, and `@litellm_ui_referer` so OpenBao Ember assets and Vault APIs never collide with LiteLLM Gateway paths; added `secrets.{$BRAINSOS_DOMAIN:localhost}` subdomain routing in `Caddyfile.appliance`.
- **Modified** `packages/brainsOS-portal/src/data/subsystems.ts`, `ThinSpine.tsx`, `ViewportFrame.tsx`, and `useHotkeys.ts`: added `secrets` (**Secrets Vault**, `KeyRound` icon, `/secrets/` -> `/ui/vault/`, hotkey `Alt+V`) without altering existing `Alt+1..9` bindings.
- **Modified** `README.md` & `packages/brainsOS-telemetry/tests/test_openbao_security.py`: updated Appliance Service Endpoints table and added `test_openbao_web_ui_oidc_and_caddy_isolation`.
