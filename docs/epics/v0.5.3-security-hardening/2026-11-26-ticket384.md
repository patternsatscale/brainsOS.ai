## 2. Acceptance Criteria Verification

- [x] **Fail-Closed Caddy `forward_auth`**: `(system_api_auth_true)` returns `401` on `302/401/403` and `error 503` on `404/502/503/504`, never emitting `X-Authentik-Outpost-Fallback`, and strips inbound `X-Authentik-*` / `Remote-User` headers.
- [x] **Strict Pre-Wizard Route Allowlist**: `(system_api_auth_false)` allows only First-Boot Wizard bootstrap routes (`/csrf`, `/health`, `/status`, `/identity`, `/dns-check`, `/setup`, `/firstboot/*`, `/jobs/*`) and blocks `/terminal/*`, `/runners/*`, `/domain`, `/tls/*`, and `/update/*` with `403`.
- [x] **Hardened System API Identity & Admin Group Check**: `_resolve_authenticated_identity` rejects outpost-fallback headers, unverified `authentik_session` cookies, and double-submit CSRF-as-identity; `_is_authorized_admin` enforces `authentik Admins` group membership.
- [x] **Host Terminal `Origin` & Privilege Dropping**: `/api/v1/system/terminal/exec` and `/api/v1/system/terminal/ws` validate `Origin`, drop `root` (`UID 0`) privileges to the operator OS account, and scrub master control-plane tokens (`SYSTEM_API_TOKEN`) from child shell environments.
- [x] **Instance-ID Redaction Across Status & DNS TXT**: Post-wizard `/identity` and `/status` mask `instance_id` (`i-••••••••••••<last4>`); raw `instance_id` requires authenticated admin `GET /api/v1/system/identity/instance-id`; `sync-route53-ddns.py` writes `owner-sha256=<hmac>`.
- [x] **`.env` Command-Injection Defense & `extra_env` Allowlist**: `env-upsert.sh` enforces POSIX single-quoting and strips outer quotes; `/runners/hermes/config` restricts keys to `ALLOWED_HERMES_TOOL_KEYS` and `HERMES_CUSTOM_*`.
- [x] **Host Firewall, Bridge Listener & Browser Headers**: `harden-host.sh` blocks external NICs (`ens5`/`eth0`) on ports `8000`/`8010`, `start-control-plane.sh` binds to `get_default_api_host()`, and Caddy emits HSTS, `nosniff`, `Referrer-Policy`, and `Content-Security-Policy: frame-ancestors 'self'`.
