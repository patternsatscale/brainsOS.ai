## 1. Summary of Changes

### Authoritative SES Receipt Verdicts & Topmost Header Alignment (`CRIT-05`)
- **Modified** `infra/src/components/ses.ts`, `infra/src/flows/email-ingress.ts`, and `infra/src/functions/sanitizer/handler.ts`: wired authoritative AWS SES receipt verdicts (`spfVerdict`, `dkimVerdict`, `dmarcVerdict`) from `SesEvent` into `processEmailThroughPipeline` (rejecting non-`PASS` verdicts at receipt), enforced `MAIL_INGRESS_BUCKET` checks on both `S3Event` and `SesEvent`, and enforced `^[A-Za-z0-9._-]+$` validation on `messageId` and `receipt.action.objectKey` before any S3/SQS calls.
- **Modified** `infra/src/functions/sanitizer/pipeline.ts`: hardened `verifyCryptographicOrigin`, `evaluateMechanismVerdict`, `extractSingleFromAddress`, and `domainsAligned` to strip RFC 5322 comments/quoted strings, evaluate strictly `trustedEntries[0]` (topmost prepended `Authentication-Results` header), fail closed when `alignmentCandidates.length === 0` or multiple `From:` addresses appear, and enforce directional domain alignment (`fromDomain === candidate || fromDomain.endsWith('.' + candidate)`).

### Boot-Safe Hashed Mail & SOGo Credential Synchronization (`HIGH-04`)
- **Modified** `scripts/setup/setup-mail.sh` and `scripts/setup/setup-sogo.sh`: updated `setup-mail.sh` (including `--accounts-only` boot runs) to write `{SHA512-CRYPT}` / `{BLF-CRYPT}` password hashes rather than `{PLAIN}` cleartext entries, and replaced `chmod -R 777` with strict `5000:5000` ownership and `0750`/`0640` file modes.
- **Modified** `scripts/control/reload-env.sh` (`sync_sogo_users`) and `docker/sogo/entrypoint.sh`: updated `sync_sogo_users` to store `{SHA512-CRYPT}` hashes in `sogo_users.c_password` and removed `c_password` from the `sogo_addressbook` SQL view in both `reload-env.sh` and `docker/sogo/entrypoint.sh`.

### Strict S3 Bucket & `approved/` Prefix Validation in SQS Consumer (`MED-03`)
- **Modified** `packages/brainsOS-mail/brainsos_mail/ingress/{claim_check.py,sqs_consumer.py}`: enforced `s3_bucket == self.config.s3_bucket`, `s3_key.startswith("approved/")`, 16-pass bounded URL-unquoting rejecting `%` / control chars / `..` traversal segments prior to `get_object` or `delete_object`, and moved `load_dotenv()` out of import time in `packages/brainsOS-mail/brainsos_mail/ingress/config.py` into `load_runtime_dotenv()` / `IngressConfig.from_env()`.

### Markdown Reply Link & CSS Style Sanitization (`MED-04`)
- **Modified** `packages/brainsOS-agent/brainsos_agent/mail_runs.py` and `scripts/control/send-welcome-email.py`: passed `markdown_to_clean_html()` output through `sanitize_html()`, enforced `https:`/`http:`/`mailto:` URL scheme allowlisting in `_format_inline_markdown` / `_replace_markdown_links`, and hardened `_sanitize_style` fail-closed against CSS comments (`/*...*/`) and backslash hex-escape obfuscation.

### Postfix Sender-Login, Structured JSONL Thread Context, MCP Queue, IMAP Escaping & `0600` Webhook Secret (`MED-05`)
- **Modified** `docker/mail/postfix/{main.cf,master.cf}` and `docker/mail/entrypoint.sh`: configured `smtpd_sender_login_maps` and `reject_sender_login_mismatch` to prevent authenticated SMTP sender spoofing.
- **Modified** `docker/mail/{entrypoint.sh,agent-webhook.sh}`: stored `MAIL_WEBHOOK_SECRET` in `/etc/dovecot/mail-webhook-secret` (`0600 vmail:vmail`) read directly by `agent-webhook.sh`, eliminating writes to world-readable `0644` `/etc/environment`.
- **Modified** `packages/brainsOS-agent/brainsos_agent/context.py`: serialized thread history using structured `okf-jsonl-v1` JSONL rather than delimiter-parsed Markdown headings to prevent thread history injection while remaining compliant with Rule 1 memory purity.
- **Modified** `packages/brainsOS-mcp/brainsos_mcp/modules/queue.py`: restricted `enqueue_task` with tenant binding (`BRAINSOS_AGENT_ID`), allowlisted task types, payload size/depth-64 limits, and canonical keys.
- **Modified** `packages/brainsOS-mail/brainsos_mail/client.py`: escaped quotes/backslashes and stripped CR/LF in IMAP `SEARCH` terms (`_escape_imap_search_term`) and mailbox names (`_sanitize_imap_mailbox`).

### Tests Created / Updated
- `infra/src/functions/sanitizer/{sanitizer.test.ts,handler.test.ts (created)}`, `packages/brainsOS-mail/tests/{test_ingress.py,test_client.py,test_mail.py}`, `packages/brainsOS-agent/tests/{test_mail_runs_html.py,test_runtime.py,test_config.py}`, `packages/brainsOS-mcp/tests/test_queue_security.py (created)`, `packages/brainsOS-appliance/tests/test_comms_standby_iam_security.py`, and `packages/brainsOS-appliance/tests/e2e/test_e2e_v053_tier{1..4}.py`.
