## 2. Acceptance Criteria Verification

- [x] **Break-Glass Toggle (`BRAINSOS_BREAKGLASS_ENABLED`)**: Implemented across `.env.example`, `set-domain.sh`, `reload-env.sh`, and `/api/v1/system/security/breakglass`, refusing `false` when neither a named Superuser nor `BRAINSOS_USER_SUB`+SSO is present.

- [x] **Script Parameterization & Credential/Permission Hardening**: Replaced interpolated SQL/Python in `reload-env.sh`, `setup-litellm-sso.sh`, `setup-langfuse.sh`, and `setup-portal.sh`; removed hardcoded session hashes/passwords; enforced `0600` on `.git/credentials`, `docker/langfuse/.env`, and `.env.bak*`, and `0750` on telemetry directories.
