## 1. Summary of Changes

### SES Inbound Sanitizer Hardening (`HIGH-04`)
- **Modified** `infra/src/functions/sanitizer/handler.ts`: removed hardcoded default fallback for `ALLOWED_EXTERNAL_SENDERS` so missing configuration fails closed.
- **Modified** `infra/src/functions/sanitizer/pipeline.ts`:
  - Updated `verifyCryptographicOrigin` to verify trusted AWS SES receipt verdicts (`spfVerdict`, `dkimVerdict`, `dmarcVerdict === "PASS"`) or AWS SES `Authentication-Results` (`*.amazonses.com`) requiring `dkim=pass`, `spf=pass`, `dmarc=pass`, and strict `From:` domain alignment against `header.from` / `header.d` / `header.i`.
  - Updated `verifySenderAllowlist` to fail closed when `allowedSenders` is empty and enforce dot-bounded recipient domain matching (`toDomain === dn || toDomain.endsWith('.' + dn)`).
  - Updated `envelopeContent` to strip `<<<EXTERNAL_UNTRUSTED_CONTENT>>>` / `<<</EXTERNAL_UNTRUSTED_CONTENT>>>` breakout markers prior to boundary wrapping.
- **Modified** `infra/src/functions/sanitizer/sanitizer.test.ts`: added coverage for DMARC verification, spoofed non-SES headers, `From:` domain alignment mismatches, SES receipt verdicts, empty allowlist fail-closed behavior, recipient domain suffix rejection, and delimiter stripping.

### Webmail XSS Mitigation & Authenticated Spool Ingress (`HIGH-05`, `HIGH-06`)
- **Modified** `packages/brainsOS-agent/brainsos_agent/mail_runs.py`: added allowlist HTML sanitizer (`_AllowlistHtmlSanitizer` + `sanitize_html`) stripping `<script>`, `<iframe>`, `<object>`, `<embed>`, `<svg>`, `<style>`, `on*` event attributes, `javascript:`/`vbscript:`/`data:` URLs, and unsafe CSS expressions; enforced in both `markdown_to_clean_html` and quoted `inbound_email.html_body` rendering inside `compose_reply_body`.
- **Modified** `packages/brainsOS-agent/brainsos_agent/worker.py`: enforced mandatory HMAC validation on `X-Mail-Webhook-Secret` in `handle_inbound_http` (`/api/v1/mail/inbound`, failing closed with `401` if unset or mismatched) and restricted `X-Spool-Filename` via `os.path.basename` + `.resolve().is_relative_to(spool_root)`.
- **Modified** `docker/mail/agent-webhook.sh`, `docker/mail/dovecot/dovecot.conf`, `docker/compose/compose.apps.yml`, `scripts/control/generate-env.sh`, `.env.example`, and `scripts/verify/verify-ami-coldboot.sh` to propagate and forward `MAIL_WEBHOOK_SECRET`.
- **Created / Updated Tests**: `packages/brainsOS-agent/tests/test_mail_runs_html.py` and `packages/brainsOS-agent/tests/test_mail_webhook_security.py`.

### Mail Credential Hashing, Postfix SASL & Signal CLI Tech Debt Removal (`MED-04`, `MED-05`)
- **Modified** `docker/mail/dovecot/dovecot.conf` & `docker/mail/entrypoint.sh`: replaced `{PLAIN}` passwd-file entries with `BLF-CRYPT`/`SHA512-CRYPT` hashes (`doveadm pw`), enabled `scheme=SHA512-CRYPT`, and replaced broad `allow_nets=172.16.0.0/12` proxy bypass with dynamically resolved SOGo container IP + loopback (`!include_try /etc/mail-brainsos/sogo-proxy-passdb.conf`).
- **Modified** `docker/sogo/Dockerfile`, `docker/sogo/sogo.conf`, and `docker/sogo/entrypoint.sh`: updated `sogo_users` provisioning to `{SHA512-CRYPT}` via `openssl passwd -6` and switched `userPasswordAlgorithm` to `sha512-crypt`.
- **Modified** `docker/mail/postfix/main.cf` & `docker/mail/entrypoint.sh`: restricted `mynetworks` to `127.0.0.0/8 [::1]/128` and required SASL authentication (`permit_sasl_authenticated, reject_unauth_destination, reject`) for container-to-container mail.
- **Modified** `packages/brainsOS-mail/brainsos_mail/ingress/config.py`, `local_injector.py`, `sqs_consumer.py`, and `docker/compose/compose.agents.yml`: wired optional SMTP SASL (`LOCAL_SMTP_USERNAME` / `LOCAL_SMTP_PASSWORD`) for `mail-ingress`.
- **Removed** `signal-cli` tech debt completely: deleted `docker/signal/` (`entrypoint.sh`, `gateway_proxy.py`), `scripts/setup/link-signal.sh`, and `scripts/verify/verify-signal.sh`; removed `signal-cli` service & configuration from `docker/compose/compose.apps.yml`, `config/default_settings/agents.yaml`, `config/default_runners/hermes/config.yaml`, `.env.example`, `scripts/control/bootstrap-env.sh`, `scripts/setup/setup-hermes.sh`, `scripts/verify/verify-hermes.sh`, `scripts/verify/verify-tool-egress-proxy.sh`, and `README.md`.

### Warm-Standby Root Scrub & Scoped Fleet IAM (`MED-01`, `LOW-01`)
- **Modified** `packages/brainsOS-appliance/scripts/release-user-volume.sh`: added root-disk scrubbing for `docker/langfuse/.env`, `.brainsos-wizard-completed`, host `data/system_jobs/*` (guarded against resolving inside `MOUNT_PATH`), prior tenant Linux OS accounts listed in `/etc/sudoers.d/90-brainsos-admin` + removal of the sudoers file, and removal of ephemeral named volumes (`brainsos_caddy_config`, `brainsos_tool_egress_proxy_data`).
- **Modified** `scripts/control/launch-fleet.sh` and `infra/src/components/iam.ts`: scoped `route53:ChangeResourceRecordSets` with `ForAllValues:StringLike` conditions on `route53:ChangeResourceRecordSetsNormalizedRecordNames` and `route53:ChangeResourceRecordSetsRecordTypes`.
- **Created** `packages/brainsOS-appliance/tests/test_comms_standby_iam_security.py`.
