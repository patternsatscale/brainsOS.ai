## 1. Summary of Changes

### Ephemeral Per-Tenant Docker Runner Execution & Containment (`HIGH-02`, `Rule 9`)
- **Modified** `packages/brainsOS-runner/brainsos_runner/{models.py,config.py,registry.py,clients/docker.py,clients/http.py}`, `packages/brainsOS-agent/brainsos_agent/{models.py,adapters/__init__.py,adapters/hermes.py,adapters/runner.py}`, and `config/default_settings/runners.yaml`:
  - Upgraded `EphemeralDockerRunnerClient` (`docker.py`) and runtime adapters (`hermes-ephemeral`, `openai-ephemeral`, `claude-ephemeral`) to execute each agent turn in a fresh ephemeral `docker run --rm` sandbox with `--cap-drop=ALL`, `--security-opt no-new-privileges:true`, `--pids-limit=256`, `--user=10001:10001`, `--read-only`, `--tmpfs /tmp:rw,noexec,nosuid,size=128m`, and `--label brainsos.tenant=<tenant_id>`.
  - Mounted strictly `/data/agents/<tenant_id>/workspace:/workspace:rw` and `/data/agents/<tenant_id>/memories:/memories:rw`, validated via component-wise symlink rejection + `os.path.realpath` + `os.path.commonpath` containment (`_validate_workspace`, `_validate_memories`) and `SAFE_RUN_ID_RE`, stripping untrusted `extra_params` (`litellm_api_key`, `egress_proxy_token`, `virtual_key_env`), and fixing `WarmHttpRunnerClient` payload serialization (`exclude_none=True`).
- **Modified** `docker/runners/base/Dockerfile`, `docker/runners/{openai-sdk,claude-sdk,hermes}/server.py`, and `docker/hermes/Dockerfile`: added ephemeral stdin/request-file execution support alongside non-root `10001:10001` alignment (and fixed mypy `union-attr` checks in `docker/runners/openai-sdk/server.py`).

### Single-Tenant Keys, Anchored Sessions, Write-Only Lens OTLP & Signed Proxy Allowlists (`HIGH-02`, `Rule 10`)
- **Modified** `packages/brainsOS-mcp/brainsos_mcp/modules/memory.py` and `docker/hermes/plugins/model-providers/brainsos-litellm-session/__init__.py`: anchored session parsing strictly to `^mail-([a-z0-9_-]+)-` with symlink and `agent_id` containment checks, forbidding cross-tenant prefixes.
- **Modified** `docker/hermes/plugins/observability/langfuse/{lens_otel.py,__init__.py}` and `docker/compose/compose.agents.yml`: stripped `LANGFUSE_SECRET_KEY` and shared fleet/memory mounts from agent execution containers, routing telemetry via write-only LiteLLM Lens OTLP (`LENS_OTLP_ENDPOINT`, `LITELLM_TRACING_KEY`), and resolved mypy `union-attr` warnings.
- **Modified** `packages/brainsOS-runner/brainsos_runner/clients/docker.py` and `config/egress/addons/github_auth.py`: added per-run HMAC-signed `v2` `Proxy-Authorization` tokens with embedded `repos` claims (`_mint_proxy_token`) and `GITHUB_ALLOWED_REPOS` validation in `OpenBaoEgressAddon`.

### Fail-Closed Runner Auth, Master-Key Fallback Removal & Hermes Dashboard Auth (`HIGH-06`)
- **Modified** `packages/brainsOS-agent/brainsos_agent/adapters/hermes.py`: updated `HermesMailAdapter._headers` to read `RUNNER_AUTH_TOKEN` -> `API_SERVER_KEY` -> `HERMES_API_KEY` and removed the `LITELLM_MASTER_KEY` fallback completely.
- **Modified** `packages/brainsOS-runner/brainsos_runner/server.py`: updated `create_runner_app` to fail closed (`HTTP 503`) whenever `RUNNER_AUTH_TOKEN` is unset or empty.
- **Modified** `docker/hermes/01-tool-egress-ca`, `docker/runners/hermes/{entrypoint.sh,webui.py}`, `docker/compose/{compose.agents.yml,compose.ingress.yml}`, and `config/caddy/{Caddyfile,Caddyfile.appliance}`: enforced separated `X-Hermes-Proxy-Token` vs `X-Runner-Token` authentication on Hermes Dashboard (`9119`), aligned `10001:10001` ownership, and gated legacy `webui.py` (`8787`) behind explicit opt-in (`HERMES_RUNNER_WEBUI_ENABLED=true` + `RUNNER_AUTH_TOKEN`).

### Appliance Emergency Kill-Switch (`SAF-02`) & Bedrock Concurrency Caps (`HIGH-05`, `Rule 3`)
- **Modified** `scripts/control/emergency-stop.sh`: dynamically discovers LiteLLM's container IP when `127.0.0.1:${LITELLM_PORT}` is unpublished (`compose.appliance.yml`), kills active ephemeral containers via `docker kill` (`--filter label=brainsos.tenant=...` with `grep -qxF` exact match), stops host `brainsos_agent.worker`, and reads `${BRAINSOS_DATA_DIR}/settings/agents.yaml` (fallback `config/default_settings/agents.yaml`).
- **Modified** `config/litellm/config.bedrock.yaml`: added `router_settings: { max_parallel_requests: 2 }`.
- **Modified** `README.md` & `AGENTS.md`: updated Rule 9, Rule 10, architecture diagrams, and `Appliance Service Endpoints` for ephemeral `10001:10001` runners, `9119` Hermes Dashboard, and Bedrock concurrency limits.

### Tests Created / Updated
- `packages/brainsOS-runner/tests/{test_docker_runner.py,test_http_runner.py,test_registry.py,test_runner_images_and_compose.py (created)}`, `packages/brainsOS-agent/tests/test_hermes_adapter.py`, `packages/brainsOS-mcp/tests/test_memory_tenant_isolation.py (created)`, `packages/brainsOS-telemetry/tests/test_openbao_security.py`, and `packages/brainsOS-appliance/tests/e2e/test_e2e_v053_tier{1..4}.py`.
