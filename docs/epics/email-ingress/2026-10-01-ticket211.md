## 1. Summary of Changes

Implemented the inbound email ingress submodule in `packages/brainsOS-mail/brainsos_mail/ingress/`, providing an SQS long-polling consumer, S3 claim-check payload resolver, RFC 822 MIME message reconstructor with security headers and boundary tags, and a local SMTP injector delivering verified emails directly to agent mailboxes.

### Files Created & Modified
- **`packages/brainsOS-mail/brainsos_mail/ingress/config.py`**:
  - Defined Pydantic v2 `IngressConfig` schema with parameter-driven defaults for AWS region, SQS queue URL, S3 bucket name, local SMTP host/port, polling interval, and batch size.
- **`packages/brainsOS-mail/brainsos_mail/ingress/claim_check.py`**:
  - `ClaimCheckMessage`: Pydantic schema matching the Cloud Sanitizer Lambda claim-check format.
  - `fetch_and_build_email()`: Downloads approved JSON from S3 and reconstructs a standards-compliant RFC 822 `EmailMessage` with `X-BrainsOS-Security-Verdict: VERIFIED_OPERATOR`, `X-BrainsOS-Origin: external-ses`, and the security-enveloped body (`<<<EXTERNAL_UNTRUSTED_CONTENT>>>`).
- **`packages/brainsOS-mail/brainsos_mail/ingress/local_injector.py`**:
  - `LocalMailInjector`: Injects the reconstructed `EmailMessage` into the local Postfix mail engine over SMTP (`host:port`).
- **`packages/brainsOS-mail/brainsos_mail/ingress/sqs_consumer.py`**:
  - `SqsIngressConsumer`: Long-polls SQS queue, downloads payloads from S3, triggers local SMTP injection, and acknowledges/deletes the SQS message and S3 object **only upon verified local delivery**. Supports graceful shutdown signals (`SIGINT`, `SIGTERM`).
- **`packages/brainsOS-mail/brainsos_mail/ingress/cli.py`**:
  - CLI daemon with argument parsing (`--once`, `--poll-wait`, `--max-messages`, `--smtp-host`, `--smtp-port`, `--queue-url`, `--bucket`, `-v`) and single-batch processing support for testing harnesses.
- **`packages/brainsOS-mail/pyproject.toml`**:
  - Added `boto3>=1.26.0` dependency and registered CLI script `brainsos-mail-ingress = "brainsos_mail.ingress.cli:main"`.
- **`packages/brainsOS-mail/tests/test_ingress.py`**:
  - 9 unit tests covering config defaults, claim-check validation, RFC 822 building, mock SMTP injection, SQS poll/delete lifecycle, delivery failure backoff, and CLI invocations.
