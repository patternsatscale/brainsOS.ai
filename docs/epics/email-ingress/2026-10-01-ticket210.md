## 1. Summary of Changes

Implemented the Cloud Sanitizer Lambda in `infra/src/functions/sanitizer/` enforcing a sequential 5-stage defensive gate on all inbound external emails triggered by S3 `s3:ObjectCreated:*` events on the raw inbox prefix (`/raw/`).

### Files Created & Modified
- **`infra/src/functions/sanitizer/types.ts`**:
  - Defined payload schemas for `ApprovedEmailPayload`, `QuarantinedEmailPayload`, `ClaimCheckMessage`, and `PipelineVerdict`.
- **`infra/src/functions/sanitizer/pipeline.ts`**:
  - **Stage 1 (Cryptographic Origin Verification)**: `verifyCryptographicOrigin()` inspects SES `Authentication-Results` asserting `dkim=pass` and `spf=pass`. Rejects spoofed or unsigned payloads with `REJECTED_CRYPTO_AUTH`.
  - **Stage 2 (Strict Sender Allowlist)**: `verifySenderAllowlist()` verifies `From` address against `ALLOWED_EXTERNAL_SENDERS` (e.g. `patternsatscale@gmail.com`) and recipient domain. Rejects unauthorized senders with `REJECTED_UNAUTHORIZED_SENDER`.
  - **Stage 3 (Structural & MIME Normalization)**: `normalizeContent()` strips zero-width Unicode characters (`\u200B-\u200D`, `\uFEFF`, bidirectional controls), hidden HTML/CSS elements (`display:none`, `visibility:hidden`, `font-size:0px`, `color:transparent`, `opacity:0`), and tracking pixels (`<img width="1" height="1">`). Converts multipart HTML into clean UTF-8 text.
  - **Stage 4 (Heuristic Prompt Injection Scanner)**: `scanPromptInjection()` evaluates subject and body against deterministic prompt injection signatures (`ignore all previous instructions`, `system override`, `you are now in developer mode`, `cat /memories`, bash/exfiltration syntax). Rejects with `REJECTED_PROMPT_INJECTION`.
  - **Stage 5 (Safe Context Enveloping)**: `envelopeContent()` wraps approved content in security boundary delimiters:
    ```text
    <<<EXTERNAL_UNTRUSTED_CONTENT>>>
    <Sanitized Message Body>
    <<</EXTERNAL_UNTRUSTED_CONTENT>>>
    ```
    Prepares structured JSON payload and SQS claim-check message.
- **`infra/src/functions/sanitizer/handler.ts`**:
  - S3 Event handler fetching raw MIME from S3 `/raw/{id}`, parsing via `mailparser`, executing the 5-stage defensive pipeline, writing approved JSON to `/approved/{id}.json` with SQS claim-check emission, or writing diagnostic records to `/quarantine/{id}.json` with zero SQS emission on rejection.
- **`infra/src/functions/sanitizer/sanitizer.test.ts`**:
  - Comprehensive unit test suite covering all 5 defensive stages with synthetic MIME fixtures.
- **`infra/src/flows/email-ingress.ts`**:
  - Wired `sst.aws.Function` for the sanitizer Lambda with scoped least-privilege IAM permissions.
  - Attached `aws.lambda.Permission` and `aws.s3.BucketNotification` triggering the Lambda on `s3:ObjectCreated:*` in `raw/`.
- **`infra/package.json`**:
  - Added dependencies: `@aws-sdk/client-s3`, `@aws-sdk/client-sqs`, `mailparser`, `vitest`.
  - Added `"test": "vitest run"` script.
