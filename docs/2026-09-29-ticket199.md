## 2. Acceptance Criteria Verification

- [x] **All baseline souls reside in `config/default_souls/*.md` using the dot-namespaced convention**:
  - `config/default_souls/` populated with `bawtford.md`, `bawtford.web-developer.md`, `marvin.md`, `terrastella.md`, `ping.md`, `claude.md`, and `gpt.md`. Redundant runner-coupled files deleted.
- [x] **`data/souls/` is properly initialized via `bootstrap-env.sh` and ignored by git**:
  - `bootstrap-env.sh` scaffolds `data/souls/`, copies missing files from `config/default_souls/`, and `.gitignore` ignores `data/souls/*` except `!data/souls/.gitkeep`. Verified by `git status` and `git check-ignore`.
- [x] **An agent configured in `agents.yaml` loads its persona from `data/souls/{soul}.md` if present, and seamlessly falls back to `config/default_souls/{soul}.md`**:
  - Validated by unit tests `test_fallback_to_default_souls` and `test_runtime_override_in_data_souls`.
- [x] **Sub-agent personas like `bawtford.web-developer` load without requiring nested folders**:
  - Validated by unit test `test_dot_namespaced_subagent_resolution` loading `bawtford.web-developer.md` without subdirectories.
- [x] **Switching an agent's `runner` (e.g., from `hermes` to `claude-sdk`) retains the exact same soul without file relocation**:
  - Validated by `test_agent_profile_with_soul_and_manifest_dict` where `bawtford-web` runs under `claude-sdk` while resolving `bawtford.web-developer`.
- [x] **All existing test suites pass**:
  - Full suite passed: 135 passed, 1 skipped across all 7 packages.
