## 1. Summary of Changes

This ticket migrates the root-level `agent_apps/` directory into declarative template blueprints under `config/sample_agent_app/` and active runtime application workspaces under `data/agent_apps/`. This change aligns application workspaces with the standard brainsOS seed-to-data pattern (`default_settings` -> `settings`, `default_runners` -> `runners`, `default_souls` -> `souls`, `sample_agent_app` -> `agent_apps`).
