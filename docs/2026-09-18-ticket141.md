## 2. Root Cause Analysis & Prevention Architecture

### Root Causes
1. **Canvas Git Working Tree Pollution**:
   Host deployment scripts (`deploy-cindypawford-com.sh`) and sync scripts (`sync-cindy-site.sh`) previously executed `cp infra/src/shell.js apps/cindypawford/site/_platform/shell.js` and ran `sed` across HTML files directly in `apps/cindypawford/site`. Because `apps/cindypawford/site` is bind-mounted directly into Cindy's container at `/app/html`, running tests, dry-runs, or deployments immediately left uncommitted changes in Cindy's Git working tree. When Cindy ran `git status` inside `/app/html`, she reasonably refused to overwrite another session's work.
2. **Duplicate Clone Discrepancy**:
   During earlier development (e.g. PR #13 "The Ten"), Cindy cloned `CindyPawford-Online` directly into `/workspace/site`. Cindy's working memory (`MEMORY.md`) recorded this location, creating a direct conflict with newly introduced rules directing work to `/app/html`.
3. **Missing Subagent Tool Catalog**:
   `titan-subagents` was copied into `plugins/titan-subagents/`, but Hermes Agent requires plugins to be explicitly listed under `plugins.enabled` in `config.yaml`. Without this, Hermes never registered `build_website_feature`, presenting only its generic `delegate_task`.
4. **Deploy Script Contradiction in Rules**:
   `ticket-workflow.md` mistakenly told Cindy to run `/workspace/scripts/apps/cindypawford/deploy-cindypawford-com.sh --dry-run`. Cindy's container has no mount to `ProjectTitan/scripts` (Rule 4), and her Operational Rule 2 defines publishing as an unreachable black box.
5. **Indiscriminate Permissions Stripping in `sync-agents.sh`**:
   `sync-agents.sh` previously executed `find apps -type f -exec chmod 664 {} +`, which stripped executable bits (`+x`) from `node_modules/.bin` (breaking `tsc`) and altered git filemodes on canvas files.

### Architectural Prevention Guardrails
1. **Out-of-Tree Build Distribution (`dist/site`)**:
   Build injection now targets `apps/cindypawford/infra/dist/site/`, which is outside Cindy's mount and ignored by Git. `apps/cindypawford/site` is treated strictly as source code.
2. **Automated Zero-Pollution Test Assertion**:
   `verify-cw1-staging.sh` now executes `deploy-cindypawford-com.sh --dry-run` and explicitly asserts:
   ```bash
   assert_success "deploy-cindypawford-com.sh preserves canvas git purity" test -z "$(git -C "${SITE_DIR}" status --porcelain)"
   ```
   If any deploy or test script touches Cindy's source working tree, CI/CD fails.
3. **Automated Manifest Synchronization for Subagent Plugins**:
   `scripts/control/sync-agents.sh` now automatically injects `titan-subagents` into `plugins.enabled` for any agent configured with subagents.
4. **Permissions Guard**:
   `sync-agents.sh` uses `chmod -R ug+rw "${REPO_ROOT}/apps"` and re-asserts `chmod +x` on binaries, preserving execution modes.
