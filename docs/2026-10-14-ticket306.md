# Walkthrough: [#306] Modular Settings Architecture & Prompt Injection Pipeline

## Context & Objective
Issue [#306](https://github.com/patternsatscale/brainsOS.ai/issues/306) reorganizes `/data/settings` (and the core canonical baseline `config/default_settings`) into a human-readable, human-writable, and modular architecture. 

Previously:
- `_MANIFESTO.md` and `email_instructions.md` sat as disconnected, loose files at the top level of `/data/settings`.
- The system prompt in `brainsos-agent` (`HermesMailAdapter`, `RunnerMailAdapter`, `ContextAssembler`) only loaded the agent's persona (`SOUL.md`) and memory rules, ignoring the manifesto and channel directives.
- Inbound emails were presented to LLM runners as bare message body strings without RFC envelope metadata (`From`, `Subject`, `Date`, `Thread-ID`), depriving models of the explicit context that they are conversing via asynchronous email.
- `README.md` was an abstract table of `config/` vs `data/` instead of an actionable operator handbook.

---

## 1. Summary of Changes

### A. Modular Settings & Prompt Directives (`config/default_settings/` & `data/settings/`)
- **`prompts/global/00_manifesto.md`**: Placed the *Patterns at Scale Manifesto* (energy stewardship, computational discipline, millijoule-per-token awareness) into the global prompt hierarchy so it is automatically injected into every agent turn across the entire fleet.
- **`prompts/channels/email.md`**: Created declarative channel instructions combining email pacing, curiosity, long-term memory formation, automatic delivery (forbidding `send_email` tool for replies), and modern semantic HTML email formatting rules (without code fences).
- **`prompts/envelopes/email.md`**: Created the inbound turn envelope template wrapping incoming email turns with structured RFC metadata headers (`From`, `To`, `Subject`, `Date`, `Thread-ID`) and an explicit directive instructing the model that its text output is automatically captured and sent as the reply.
- **`README.md`**: Rewrote `README.md` in both `config/default_settings/` and `data/settings/` into a comprehensive operator manual explaining manifest declarations (`agents.yaml`, `runners.yaml`), the 5-layer prompt hierarchy, and customization cascades.
- **Cleaned Loose Files**: Purged loose `_MANIFESTO.md` and `email_instructions.md` from the root of `data/settings/`.

### B. Python Package Core (`packages/brainsOS-agent`)
- **`brainsos_agent.prompts`**:
  - `get_prompts_dirs()`: Discovers prompt candidate directories across active settings and defaults.
  - `resolve_global_prompts()`: Resolves and concatenates all global directives (`prompts/global/*.md`) in alphabetical/numeric order.
  - `resolve_channel_prompt()`: Resolves channel-specific directives with cascading fallback (`data/agents/<id>/prompts/` -> `data/settings/prompts/` -> `config/default_settings/prompts/`).
  - `render_inbound_envelope()`: Wraps incoming turns in structured channel envelope templates with safe attribute fallbacks.
  - `assemble_system_prompt()`: Centralized 5-layer prompt assembler combining Global Directives, Persona (`SOUL.md`), Working Memory Rules, Runtime Guidelines, and Channel Directives.
- **`brainsos_agent.adapters.hermes` (`HermesMailAdapter`)**:
  - Integrated `assemble_system_prompt` to inject global directives and channel prompts.
  - Wrapped user turn input in `render_inbound_envelope("email", ...)` so Hermes receives complete email metadata on every turn.
  - Robust date formatting handling both `datetime` instances and serialized string representations.
  - Preserved clean message bodies in OKF thread dialogue history (Rule 1 compliance).
- **`brainsos_agent.adapters.runner` (`RunnerMailAdapter`)**:
  - Updated `_assemble_system_prompt_with_working_memory` to use `assemble_system_prompt`.
- **`brainsos_agent.context` (`ContextAssembler`)**:
  - Updated `assemble_messages` to use `assemble_system_prompt` for multi-adapter consistency.
- **`brainsos_agent/__init__.py`**:
  - Exported `assemble_system_prompt`, `get_prompts_dirs`, `resolve_global_prompts`, `resolve_channel_prompt`, and `render_inbound_envelope`.

### C. Operational Scripts & Tooling
- **`scripts/control/bootstrap-env.sh`**:
  - Added non-destructive seeding (`cp -n -R`) of `config/default_settings/prompts/` (`global`, `channels`, `envelopes`) into `${DATA_ROOT}/settings/prompts/`.
- **`REPO_MAP.md`**:
  - Updated directory tree to document `prompts/` under `config/default_settings/` and `data/settings/`.

### D. Automated Unit Test Suites
- **`packages/brainsOS-agent/tests/test_prompts.py`**:
  - Added 7 unit tests covering global prompt resolution, sorted loading, channel prompt resolution, per-agent overrides, envelope rendering with templates, and fallback behavior.
- **`packages/brainsOS-agent/tests/test_hermes_adapter.py`**:
  - Updated assertions to validate inbound email envelope wrapping in `body["input"]`.
