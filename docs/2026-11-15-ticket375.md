## 1. Summary of Changes

### Created Files
- [`config/clickhouse/lens-keeper.xml`](../config/clickhouse/lens-keeper.xml): Embedded single-node ClickHouse Keeper configuration (`/var/lib/clickhouse/coordination`, `<keeper_map_path_prefix>/lens/keeper-map</keeper_map_path_prefix>`) enabling `KeeperMap` coordination inside the existing `brainsos-telemetry-clickhouse` instance without deploying a second OLAP cluster.
- [`docker/lens/Dockerfile`](../docker/lens/Dockerfile): Reproducible multi-stage ARM64 build of `BerriAI/lens` pinned to immutable commit `fa1b82f6ad67c63e82b949d73f0ea50914397dd5`, running rootless (`USER 65532:65532`) with Chainguard Wolfi runtime base and an assertive build-time fix for an upstream trailing-comma CTE SQL bug in `crates/traces-clickhouse/query/lens_availability.sql` (`/lens/activity/available`).
- [`scripts/setup/setup-lens.sh`](../scripts/setup/setup-lens.sh): Idempotent Day-1/Day-2 operational script (`--pre-up`, `sync`, `status`) that upgrades/provisions ClickHouse (`26.2`, `KeeperMap`, isolated `lens` database + `lens` SQL user while preserving Langfuse's `default` database), generates 64-character hex Lens tokens in `.env`, mints/rotates a tenant-scoped `LITELLM_TRACING_KEY` (`owner=admin`) via LiteLLM `POST /lens/tracing/keys`, and prints redacted readiness diagnostics.
- [`docker/hermes/plugins/observability/langfuse/lens_otel.py`](../docker/hermes/plugins/observability/langfuse/lens_otel.py): Parallel OpenTelemetry GenAI HTTP exporter (`POST http://lens:4318/v1/traces`) for Hermes Agent emitting `invoke_agent`, `chat`, `execute_tool`, and `litellm.gateway.client` `gateway.request` spans correlated 1:1 with LiteLLM spend logs via W3C `traceparent`.
- [`packages/brainsOS-agent/brainsos_agent/lens_trace.py`](../packages/brainsOS-agent/brainsos_agent/lens_trace.py): Host queue-worker OTLP trace envelope exporter (`invoke_workflow` / `email-run`) mirroring `langfuse_trace.py` and remaining active even when `LANGFUSE_ENABLED=false`.
- [`packages/brainsOS-agent/tests/test_lens_trace.py`](../packages/brainsOS-agent/tests/test_lens_trace.py): Unit tests covering `lens_trace.py` OTLP GenAI spans, `LANGFUSE_ENABLED=false` isolation, W3C `traceparent` header injection in `brainsos-litellm-session`, and multi-step Hermes `invoke_agent` + `chat` + `gateway.request` + `execute_tool` export.
- [`packages/brainsOS-appliance/tests/test_lens_integration.py`](../packages/brainsOS-appliance/tests/test_lens_integration.py): Integration and security boundary tests verifying hardened `compose.telemetry.yml`, `compose.control.yml` (`v1.109.1`), `compose.appliance.yml` (`ports: !reset []`), `docker/lens/Dockerfile`, `Caddyfile` / `Caddyfile.appliance` routing, and `generate-env.sh` secret generation.
