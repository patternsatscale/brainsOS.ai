## Acceptance Criteria Verification

- [x] **Defensive HTTP Response Parsing & Console Logging (`shell.js`)**:
  - `if (res.ok)` checked before reading/parsing body.
  - `Content-Type: application/json` checked before calling `res.json()`, preventing `SyntaxError: Unexpected token '<'` when S3 or CloudFront returns XML/HTML error responses.
  - `console.error` logs diagnostics for all failed requests so DevTools console is never silent.
  - Distinguishes network transport failures (`TypeError`) from server HTTP errors.
- [x] **Direct API Gateway (`api.cindypawford.com`)**:
  - `sst.aws.ApiGatewayV2` configured with `domain: "api.cindypawford.com"`.
  - In `shell.js`, `API_BASE` resolves `window.CINDY_API_URL || document.querySelector('meta[name="cindy-api-url"]')?.content || "https://api.cindypawford.com"`.
- [x] **Runtime Config Fallback Injection**:
  - `scripts/apps/cindypawford/deploy-cindypawford-com.sh` updated with cross-platform sed and automatic staging of `_platform/config.js`.
- [x] **Regression Testing**:
  - Validated simulation with non-JSON 405 XML responses, 400 Bad Request JSON responses, and network transport failures.
  - `npm --prefix apps/cindypawford/infra run typecheck` passed (0 errors).
  - `./scripts/verify/verify-cw1-staging.sh` passed (20/20 checks).
