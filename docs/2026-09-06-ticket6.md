## 1. Summary of Changes

### GitHub Workflows
- [`.github/workflows/pre-commit.yml`](file:///Users/pats/Development/project_titan/.github/workflows/pre-commit.yml): Native GitHub Actions workflow executing on every push and pull request to `main`:
  - **Secret Scanning (Gitleaks)**: Scans commits for API keys, passwords, and tokens.
  - **Environment Protection**: Asserts no `.env`, `.pem`, or private keys exist in Git tracking.
  - **Memory Plane Purity**: Asserts that `data/memories/` only contains `.gitkeep`, blocking accidental commits of live agent notes.
  - **Shell Syntax Validation**: Runs `bash -n scripts/*.sh`.
  - **Docker Compose Topology**: Validates `docker compose config` against `.env.example`.

### Cleanliness & Architecture Integrity
- Avoided redundant `.pre-commit-config.yaml` and client-side hooks, standardizing entirely on GitHub's native workflow and server-side scanning.
