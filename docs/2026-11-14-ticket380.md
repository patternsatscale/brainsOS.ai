## 1. Summary of Changes

To give operators on a work computer (`macOS` Bash 3.2+, `Linux`, `WSL`, or `AWS CloudShell`) a single copy-pasteable / `curl`-able standalone utility with an interactive **EC2 Launch Template picker**, flexible count-or-names sizing, and clean exit handling:

### Modified & Created Files
- [`scripts/control/launch-fleet.sh`](../scripts/control/launch-fleet.sh):
  - **100% Standalone & Bash-3.2/macOS Compatible**: Removed `mapfile` and repository-path dependencies so the single script runs anywhere with only `bash`, `aws` CLI v2, and `python3`.
  - **Interactive TUI Menu & Launch-Template Wizard** (default when invoked with zero arguments `./launch-fleet.sh`, or via `--wizard`):
    - Main menu covering Launch Fleet, List Active Fleets, Stop Fleet, Hibernate Fleet, Start/Resume Fleet, Terminate Fleet, Switch AWS Region/Profile, and instant `q` / `exit` / `Ctrl+C` clean exit.
    - Live **EC2 Launch Template picker** (`aws ec2 describe-launch-templates` + `describe-launch-template-versions`) inspecting AMI ID, Instance Type, IAM Profile, NetworkInterfaces, TagSpecifications, and base64-decoded User Data.
    - **Safe Launch-Template Parameter Merging**: Avoids passing conflicting `--security-group-ids` when a Launch Template owns `NetworkInterfaces`, preserves existing Launch Template instance tags while injecting `Name`, `BrainsOSFleet`, `BrainsOSParticipant`, and `BrainsOSDomain`, and merges per-instance `BRAINSOS_DOMAIN` + `BRAINSOS_ROUTE53_ZONE_ID` into shell or cloud-config User Data.
    - **Dual Sizing Input**: Enter a number (`10` → `user01..user10`), comma-separated participant names, or multi-line `paste`.
  - **CLI Flag Parity**: Added `--launch-template <id|name>`, `--lt-version <ver>`, `--count <N>`, `--prefix <str>`, and `--profile <aws-profile>`.
- [`.agents/skills/launch-fleet/SKILL.md`](../.agents/skills/launch-fleet/SKILL.md), [`config/default_skills/launch-fleet/SKILL.md`](../config/default_skills/launch-fleet/SKILL.md), [`packages/brainsOS-skills/brainsos_skills/bundled/launch-fleet/SKILL.md`](../packages/brainsOS-skills/brainsos_skills/bundled/launch-fleet/SKILL.md), & [`packages/brainsOS-appliance/README.md`](../packages/brainsOS-appliance/README.md):
  - Updated documentation with standalone `curl` download instructions and Launch-Template workflows.
- [`packages/brainsOS-appliance/tests/test_launch_fleet.py`](../packages/brainsOS-appliance/tests/test_launch_fleet.py):
  - Added tests for standalone execution outside the repo, `--launch-template` + `--count` + `--prefix` (`NetworkInterfaces` & tag preservation), scripted interactive `--wizard` Launch-Template flow, and immediate `q` exit.
