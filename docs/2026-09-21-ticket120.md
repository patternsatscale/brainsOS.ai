## 3. Inviolable Security & Architectural Invariants

- **Rule 1 (Memory Plane Purity)**: Trace logs, metrics, ClickHouse records, and cache files strictly route to dedicated data volumes (`data/langfuse_*`). The `/memories` mount remains 100% human-auditable flat Markdown files.
- **Rule 2 (Inference Boundary)**: All agent completions route strictly through LiteLLM gateway (`127.0.0.1:4000`), never directly to raw inference engines (`11434`).
- **Rule 3 (Hardware Serialization)**: `max_parallel_requests: 1` preserved across all models to protect the unified memory bus.
- **Rule 4 (Host Sandboxing)**: Agent containers run strictly unprivileged (UID 1000) with zero host Docker socket exposure.
- **Rule 6 (Database Isolation)**: `titan-langfuse-db` runs on `titan-langfuse-net` on port 5433, completely segregated from `titan-litellm-db` on port 5432 and `titan-litellm-net`.
- **Rule 7 (Information Compartmentalization)**: Persona prompts and configs do not expose backend infrastructure names or database credentials.
- **Rule 8 (Script-Driven Discipline)**: Zero ad-hoc container patching; all lifecycle actions codified in `scripts/`.
- **Rule 9 (Multi-Tenant Partitioning)**: Telemetry streams between agents (`terrastella`, `football-dan`, `cindy-pawford`) remain compartmentalized.
- **Rule 11 (Separation of Build and Record)**: `docs/lab-work/` strictly out of scope; no files accessed or modified.

## 5. Web UI Visual Verification Guide

To inspect real-time traces and agent metrics in the Langfuse web interface:

### Local Web Preview URLs
- **Direct Web Access**: [http://127.0.0.1:3001](http://127.0.0.1:3001)
- **Local Ingress Domain**: [http://langfuse.localhost](http://langfuse.localhost) (via Caddy)
- **LAN / Local DNS**: [http://langfuse.titan.local:3001](http://langfuse.titan.local:3001)

### Visual Checklist in Dashboard
1. **Traces View (`/project/<project_id>/traces`)**:
   - Verify traces list populated with `litellm-acompletion` and `Received Proxy Server Request`.
   - Filter by user: select `cindy-pawford` to isolate traces initiated by the Cindy Pawford agent unit.
2. **Generations Detail View (`/project/<project_id>/generations`)**:
   - Inspect generation cards for `model: titan-core`.
   - Confirm token usage metrics: Prompt Tokens, Completion Tokens, Total Tokens, and Latency breakdown.
   - Inspect prompt and output payloads.
3. **Trace Tree & Spans**:
   - Open a trace to view the waterfall span hierarchy: `router` -> `self` -> `batch_write_to_db` and execution spans.
4. **OTLP Endpoints**:
   - Confirm OTLP stream ingestion from agent containers via `/api/public/otel/v1/traces`.
