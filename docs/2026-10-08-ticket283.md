## 2. Acceptance Criteria Verification

- [x] **Fix SOGo draft folder creation error and Dovecot trusted authentication network allowlist**:
  - `docker/sogo/entrypoint.sh` initializes `/var/spool/sogo` with `sogo:sogo` ownership.
  - `docker/mail/dovecot/dovecot.conf` allows trusted proxy authentication from `172.16.0.0/12`.
  - Sending/drafting emails in SOGo Webmail succeeds without draft folder creation errors.
- [x] **Stateless dispatch to upstream Hermes container**:
  - `HermesMailAdapter` statelessly dispatches the turn request via HTTP POST to `runner-hermes` (`http://127.0.0.1:8642/v1/agent/run`).
  - Upstream `nousresearch/hermes-agent` handles autonomous reasoning, tool execution, and memory writing natively.
- [x] **Expanded context window prevents truncation**:
  - `num_ctx: 131072` in `config/litellm/config.yaml` ensures multi-turn research iterations do not truncate the opening user prompt.
- [x] **Session traces tagged by email ID and visible in Langfuse telemetry**:
  - Trace session IDs and Langfuse credentials passed to Hermes container for end-to-end trace attribution.
- [x] **Egress traffic cleanly routed through Tool Egress Proxy**:
  - External web search queries route through `http://brainsos-net-egress-proxy:8082` with CA cert trust.
- [x] **Agent replies dispatched to recipient with correct `@dgx.local.brainsos.ai` sender address**:
  - `AgentQueueWorkerDaemon` resolves appliance-bound agent sender addresses to `bawtford@dgx.local.brainsos.ai`.
