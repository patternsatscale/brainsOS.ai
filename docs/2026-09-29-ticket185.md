## 1. Summary of Changes

Epic #185 establishes the decoupled **Cognitive Compute Plane (`brainsOS-runner`)**, abstracting agent execution away from monolithic container-per-agent models into unified warm HTTP runner services and ephemeral Docker sandboxes. It also introduces end-to-end multi-runner starter demos (Anthropic Claude SDK and OpenAI SDK) and restructures `config/` around version-controlled default templates (`default_*`) that seed local runtime state into `data/`.

### Packages & Architecture
- **`packages/brainsOS-runner/`** (New Package):
  - `brainsos_runner/models.py`: Unified cognitive IPC schemas (`AgentTurnRequest`, `AgentTurnResponse`, `ChatMessage`, `ToolCallRecord`, `ExecutionMetrics`).
  - `brainsos_runner/config.py`: Declarative runner configuration schemas (`RunnerConfig`, `WarmHttpRunnerConfig`, `EphemeralDockerRunnerConfig`).
  - `brainsos_runner/registry.py`: Authoritative runner registry loader resolving `runners.yaml` across `data/settings/` and `config/default_settings/`.
  - `brainsos_runner/server.py`: Standard FastAPI runner application factory with `/healthz` and `/v1/agent/run`.
  - `brainsos_runner/clients/http.py`: Resilient HTTP client for warm runner daemons with retries, timeouts, and health probes.
  - `brainsos_runner/clients/docker.py`: Ephemeral Docker sandbox runner enforcing Rule 1 (Memory Purity) and Rule 4 (Host Sandboxing).
- **`packages/brainsOS-agent/`** (Adapter Substrate):
  - `brainsos_agent/adapters/runner.py`: `RunnerMailAdapter` bridging universal inbound mail to `WarmHttpRunnerClient`.
  - `brainsos_agent/adapters/__init__.py`: Dynamic runtime routing across `hermes`, `claude`, and `openai`.
  - `brainsos_agent/models.py`: Manifest parser with candidate path resolution for `agents.yaml` and agent `SOUL.md` personas.

### Container Topology & Runtimes
- **`docker/runners/`**:
  - `base/Dockerfile`: Lightweight Debian-slim base image (`brainsos-runner-base:latest`) with Python 3.12, `uv`, and `fastapi`.
  - `hermes/Dockerfile` & `server.py`: Nous Hermes warm runner daemon (:8642).
  - `claude-sdk/Dockerfile` & `server.py`: Anthropic Claude SDK warm runner daemon (:8001), dynamically executing `/data/runners/claude-sdk/<agent>/agent.py`.
  - `openai-sdk/Dockerfile` & `server.py`: OpenAI SDK warm runner daemon (:8002), dynamically executing `/data/runners/openai-sdk/<agent>/agent.py`.
- **`docker-compose.yml`**:
  - Registered `runner-hermes`, `runner-claude`, and `runner-openai` services with host loopback bindings, egress proxy isolation, and memory mounts.

### Configuration Restructuring (`default_*`)
- **`config/default_runners/`**:
  - `hermes/`: Full Hermes configuration, tools, and agent personas (`terrastella`, `marvin`, `bawtford`, `ping`).
  - `claude-sdk/claude/`: Starter Claude SDK agent dynamically generating jokes about Claude via `AsyncAnthropic` over LiteLLM.
  - `openai-sdk/gpt/`: Starter OpenAI SDK agent dynamically generating jokes about Sam Altman via `AsyncOpenAI` over LiteLLM.
- **`config/default_memories/`**:
  - Starter Open Knowledge Format (OKF) Markdown templates and purity guardrails.
- **`config/default_settings/`**:
  - `agents.yaml`: Multi-agent fleet manifest authority.
  - `runners.yaml`: Cognitive compute and runner manifest authority.
  - `README.md`: Explaining the defaults vs. runtime state architecture.
- **`scripts/control/bootstrap-env.sh`**:
  - Scaffolds `data/settings/` and `data/runners/`, non-destructively seeding templates (`cp -n -R`).
- **`.gitignore`**:
  - Explicitly tracks `!config/default_*/**` while ignoring local modifications in `data/settings/*` and `data/runners/*`.
