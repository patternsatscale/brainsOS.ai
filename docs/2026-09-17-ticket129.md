## 5. Architectural Alignment & Isolation Guarantees

- **Closed Shadow DOM**: `this.attachShadow({ mode: "closed" })` ensures host document JavaScript cannot pierce or inspect the internal console DOM, and console scripts cannot manipulate host DOM.
- **Strict Selector Encapsulation**: All styling rules are scoped inside the ShadowRoot `<style>`. No `<style>` or `<link>` elements are ever injected into `document.head`.
- **Inheritance Firewall**: `:host { all: initial !important; }` resets all inherited styling properties from the parent document.
- **Event & Pointer Isolation**: When closed, `.drawer-panel` has `visibility: hidden !important; pointer-events: none !important;` and `.drawer-backdrop` has `pointer-events: none !important; opacity: 0 !important;`.
- **Mobile Safe Area & Responsiveness**: Applied `env(safe-area-inset-bottom)`, bottom sheet `88dvh`, input font-size 16px to eliminate iOS zoom, and responsive `hidden xl:flex` on desktop sidebars to prevent narrow viewport blockage.
