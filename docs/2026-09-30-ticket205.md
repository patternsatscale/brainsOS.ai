## 1. Summary of Changes

This task fulfills the requirement to make the external private fleet data repository (`BRAINSOS_DATA_DIR`, e.g. `patternsatscale/project-mJ`) 100% autonomous and self-restoring. Point-in-time snapshot creation and full disaster recovery scripts are now colocated directly within the data plane repository's `backups/` directory, removing any runtime dependency on the open-source platform repository (`brainsOS.ai`).

### Files Created & Modified

#### Platform Core Repository (`brainsOS.ai`)
- [config/templates/backups/backup.sh](file:///Users/pats/Development/brainsOS.ai/config/templates/backups/backup.sh): Standalone, self-contained backup engine that resolves `DATA_ROOT` relative to its own location, archives all active planes (`agent_memories/`, `souls/`, `settings/`, `agent_workspaces/`, `agent_apps/`, `comms/`, `control_plane/litellm_db`), verifies archive integrity with `tar -tzf`, and enforces configurable retention pruning.
- [config/templates/backups/restore.sh](file:///Users/pats/Development/brainsOS.ai/config/templates/backups/restore.sh): Standalone disaster recovery tool featuring `--dry-run`, `--force`, pre-restore safety snapshots, plane-by-plane integrity verification, and directory permission restoration.
- [config/templates/backups/README.md](file:///Users/pats/Development/brainsOS.ai/config/templates/backups/README.md): Standalone operator documentation explaining autonomous backup and restore workflows directly within the data repository.
- [config/templates/data-repo.gitignore](file:///Users/pats/Development/brainsOS.ai/config/templates/data-repo.gitignore): Updated to track executable scripts (`!backups/*.sh`, `!backups/README.md`) while strictly ignoring binary archives (`backups/*.tar.gz`, `backups/*.tgz`, `backups/*.zip`).
- [scripts/control/bootstrap-env.sh](file:///Users/pats/Development/brainsOS.ai/scripts/control/bootstrap-env.sh): Updated to automatically seed `config/templates/backups/` into `${DATA_ROOT}/backups/` during `make setup` / bootstrapping.
- [scripts/control/backup.sh](file:///Users/pats/Development/brainsOS.ai/scripts/control/backup.sh): Updated to dynamically detect and delegate to `${BACKUP_DIR}/backup.sh` and `${BACKUP_DIR}/restore.sh` when present in the external data repository.
- [Makefile](file:///Users/pats/Development/brainsOS.ai/Makefile): Added `make backup` and `make restore` lifecycle targets.
- [docker/mail/dovecot/dovecot.conf](file:///Users/pats/Development/brainsOS.ai/docker/mail/dovecot/dovecot.conf): Removed `user = vmail` from `service lmtp` to allow Dovecot LMTP listener to query the auth userdb and set process UID/GID for local mailbox delivery.

#### External Private Fleet Data Repository (`project_mJ`)
- Updated `/Users/pats/Development/project_mJ/.gitignore` to ignore archive binaries and track `backups/*.sh`.
- Seeded `/Users/pats/Development/project_mJ/backups/backup.sh`, `restore.sh`, and `README.md`.
- Committed and pushed to `project-mJ` `origin/main` (`commit 7500277`).

## 4. Architectural Invariants Preserved

1. **Rule 14 (Two-Repository Architecture)**: The platform core (`brainsOS.ai`) remains completely free of proprietary fleet state and intellectual property. The data repository (`project_mJ`) possesses full disaster recovery autonomy.
2. **Rule 1 (Memory Plane Purity)**: Only Markdown OKF documents and human-readable configurations are packaged into memory backups.
3. **Rule 8 (Script-Driven Discipline)**: No manual commands or ad-hoc interventions are necessary. Backup and restoration are codified as idempotent, self-contained shell scripts.
