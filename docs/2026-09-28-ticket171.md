### Architectural Guarantees:
1. **Secret Hygiene & Zero Secret Leakage (Rule 5)**:
   - `.gitignore` enforces exclusion of all environment files (`.env*` except `!.env.example`), dynamic agent memory subpaths (`memories/**/*`), database files (`*.db`, `*.sqlite`), and proxy state (`.mitmproxy/`).
   - `.env.example` sanitizes all sensitive keys with dummy placeholders (`LITELLM_MASTER_KEY=sk-brainsos-mock-key`).
   - `.gitleaksignore` defines targeted fingerprints for historical documentation false-positives, allowing Gitleaks to scan all commits with 0 leaks detected.
2. **Container Sandboxing & Attack Surface Minimization (Rule 4)**:
   - **Rootless & Capability Minimization**: Dropped all Linux capabilities (`cap_drop: [ALL]`), adding strictly necessary privileges (`SETUID`, `SETGID`, `CHOWN`, `DAC_OVERRIDE`, `FOWNER`) to enable upstream s6-overlay container initialization to drop from root to unprivileged UID 1000 (`hermes`) without running as privileged root.
   - **Read-Only Root Filesystem**: Root filesystem mounted as `read_only: true`, preventing tampering, unauthorized package installations, or backdoor persistence.
   - **Privilege Escalation Prevention**: `security_opt: ["no-new-privileges:true"]` prevents container processes from gaining additional privileges via `setuid` binaries.
   - **Cgroup Resource Quotas (Rule 3)**: Agent processes are constrained by `cpus: "2.0"`, `memory: 4096M`, and `pids: 200` to prevent fork bombs and CPU/memory starvation on the ASUS Ascent GX10 unified memory bus.
3. **Reproducible Image Build (Rule 8)**:
   - Upstream Hermes base images configure user `hermes` with UID 10000. Under `read_only: true`, runtime `/etc/passwd` modifications by `usermod` fail. Pinned user `hermes` and group `hermes` to UID/GID 1000 directly during build time in `docker/hermes/Dockerfile`.

## 2. Summary of Changes

### A. Secret Hygiene & Git Tracking
- `.gitignore`:
  - Added explicit patterns: `memories/**/*`, `!memories/**/.gitkeep`, `*.db`, `*.sqlite`, `.mitmproxy/`.
- `.env.example`:
  - Sanitized `LITELLM_MASTER_KEY` to dummy mock key `sk-brainsos-mock-key`.
- `.gitleaksignore`:
  - Created ignore configuration for false positives in historical documentation walkthroughs (`docs/2026-09-06-ticket2.md`).

### B. Container Hardening & Manifest Generator
- `scripts/control/sync-agents.sh`:
  - Updated the agent container template in `generate_compose()` with:
    - `read_only: true`
    - `security_opt: ["no-new-privileges:true"]`
    - `cap_drop: ["ALL"]`
    - `cap_add: ["SETUID", "SETGID", "CHOWN", "DAC_OVERRIDE", "FOWNER"]`
    - `deploy.resources.limits`: `cpus: "2.0"`, `memory: 4096M`, `pids: 200`
    - `tmpfs`: `/tmp:rw,noexec,nosuid,size=64m`, `/run:rw,exec,nosuid,size=64m`, `/etc/ssl/certs:rw,size=10m`, `/usr/local/share/ca-certificates:rw,size=10m`
- `docker-compose.agents.yml`:
  - Regenerated using `./scripts/control/sync-agents.sh` across all agents (`terrastella`, `marvin`, `bawtford`).

### C. Hermes Dockerfile Hardening
- `docker/hermes/Dockerfile`:
  - Added build-time user/group ID remap: `usermod -u 1000 hermes && groupmod -g 1000 hermes && chown -R hermes:hermes /home/hermes`.
  - Ensures s6-overlay starts without runtime `/etc/passwd` edits on a read-only rootfs.

### D. Ingress & Setup Script Alignments
- `config/caddy/Caddyfile`:
  - Fixed hostname collision where duplicate `brainsos.local` domains were declared on `localhost` site blocks following the rebrand.
- `scripts/setup/setup-memories.sh`:
  - Added exception for `subagents.json` in memory plane purity validation to match `scripts/verify/verify-memories.sh`.
- `config/agents.local.yaml`:
  - Synchronized host-local manifest with `config/agents.yaml` so host-local overrides reflect brainsOS naming.
