## 1. Summary of Changes

This ticket establishes a decoupled, standalone Python domain package for managing agent skills (`packages/brainsOS-skills`), transforms `/plan` into a front-door intelligent intent router, adopts dot-namespaced planning archetypes (`plan.epics`, `plan.ux`, `plan.copy`), and enforces the Rule 14 OS vs. Data separation boundary for proprietary skill intellectual property.

### Modified & Created Files:
- **`packages/brainsOS-skills/`**:
  - `pyproject.toml`: Modern PEP 621 packaging for editable installs.
  - `brainsos_skills/models.py`: Data models (`Skill`, `SkillMetadata`, `SkillSourceType`).
  - `brainsos_skills/validator.py`: Frontmatter validator supporting dot-namespaced identifiers (`^[a-z0-9]+([.-][a-z0-9]+)*(:[a-z0-9]+)*$`).
  - `brainsos_skills/registry.py`: In-memory skill registry with trigger matching.
  - `brainsos_skills/loader.py`: Hierarchical loader supporting `config/default_skills`, `${BRAINSOS_DATA_DIR}/skills`, and `.agents/skills`.
  - `brainsos_skills/cli.py`: CLI (`brainsos-skills list`, `validate`, `sync`) with hierarchical discovery.
  - `brainsos_skills/bundled/`: Canonical bundled fallback skills (`agents-discipline`, `plan`, `plan.epics`, `plan.ux`, `plan.copy`).
  - `tests/test_skills.py`: Unit test suite (6/6 tests passing).
- **`config/default_skills/`**:
  - Canonical open-source baseline templates (`agents-discipline`, `plan`, `plan.epics`, `plan.ux`, `plan.copy`).
- **`scripts/control/bootstrap-env.sh`**:
  - Scaffolds `${DATA_ROOT}/skills`.
  - Seeds default skills via `cp -n -R "${REPO_ROOT}/config/default_skills/"* "${DATA_ROOT}/skills/"`.
  - Automatically synchronizes active skills to `.agents/skills/` for Antigravity IDE during bootstrap.
  - Installs Git pre-commit hook blocking accidental private fleet name commits.
- **`scripts/verify/verify-no-private-refs.sh`**:
  - Full audit and auto-remediation tool preventing private fleet leakage across staged commits, codebase, and GitHub issues/PRs.
- **`.github/workflows/pre-commit.yml`**:
  - Adds automated CI enforcement step for `verify-no-private-refs.sh`.
- **`.gitignore`**:
  - Tracks `!config/default_skills/**`.
  - Ignores `data/skills/*` (only tracks `.gitkeep`), ensuring proprietary fleet IP is never committed to core.
- **`PLAN.md` & `PLANNING.md`**:
  - Documents the `/plan` Intent Router topology and the three specialized sub-archetypes (`plan.epics`, `plan.ux`, `plan.copy`).
