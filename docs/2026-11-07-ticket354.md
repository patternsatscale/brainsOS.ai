## 1. Summary of Changes

- [`scripts/control/update.sh`](../scripts/control/update.sh):
  - Increased default `HEALTH_TIMEOUT` from `90` to `120` seconds.
  - Updated Step 5/5 health probes for `brainsos-control-litellm` and `brainsos-telemetry-langfuse-web` to fall back to Docker container health (`docker inspect` `.State.Health.Status == "healthy"`) and in-container health endpoints when host ports `4000` and `3001` are unpublished under `docker/compose/compose.appliance.yml`.
- [`docker/editor/entrypoint.sh`](../docker/editor/entrypoint.sh):
  - Added `wait_for_litellm(30)` retry loop waiting for `http://litellm:4000/health/liveness` before validating/provisioning the operator virtual key so `code-server` does not race ahead of LiteLLM on sequential startup.
  - Added AWS Bedrock model aliases (`claude-sonnet-4-5`, `claude-haiku-4-5`, `claude-3-5-haiku`, `amazon-nova-pro`, `amazon-nova-lite`, `cindy-active-coding-model`) to `litellm-connector.modelCapabilitiesOverrides`.
- [`config/caddy/Caddyfile`](../config/caddy/Caddyfile), [`packages/brainsOS-telemetry/brainsos_telemetry/system.py`](../packages/brainsOS-telemetry/brainsos_telemetry/system.py), [`packages/brainsOS-portal/src/App.tsx`](../packages/brainsOS-portal/src/App.tsx), [`packages/brainsOS-portal/src/components/UserProfileModal.tsx`](../packages/brainsOS-portal/src/components/UserProfileModal.tsx):
  - Unwrapped Authentik's nested `data.user` payload from `/api/v3/core/users/me/` (`SessionUserSerializer`) and added `/api/v1/system/me` fallback so the bottom-left user profile modal reflects the signed-in Authentik user instead of staying hardcoded to `"Appliance Administrator"`.
- [`packages/brainsOS-telemetry/pyproject.toml`](../packages/brainsOS-telemetry/pyproject.toml), [`scripts/control/bootstrap-env.sh`](../scripts/control/bootstrap-env.sh), [`packages/brainsOS-portal/src/components/SystemManager.tsx`](../packages/brainsOS-portal/src/components/SystemManager.tsx):
  - Added `"websockets>=12.0"` to `brainsOS-telemetry` dependencies and `bootstrap-env.sh` so `uvicorn` supports `/api/v1/system/terminal/ws` WebSocket upgrades inside the appliance `.venv`.
  - Allowed `verify_internal_auth` and `terminal_ws` to validate `SYSTEM_API_TOKEN` against both `os.environ` and `.env` on disk.
  - Removed `executeConsoleCommand` and `status` from the XTerm `useEffect` dependency array in `SystemManager.tsx` (using refs instead) and added a 15s ping/auto-reconnect keepalive so polling refreshes never tear down the active WebSocket PTY session.
- [`packages/brainsOS-telemetry/tests/test_system_api.py`](../packages/brainsOS-telemetry/tests/test_system_api.py):
  - Added `test_system_me_endpoint` covering `/api/v1/system/me`.
