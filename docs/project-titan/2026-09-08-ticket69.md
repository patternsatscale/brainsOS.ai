## 1. Summary of Changes

### Upstream Hermes Runtime & Sandboxing
- [`docker/hermes/Dockerfile`](file:///home/patternsatscale/ProjectTitan/docker/hermes/Dockerfile): Rebuilt from the official `nousresearch/hermes-agent:latest` distribution. Pre-installs the Titan OKF memory plugin (`/opt/hermes/hermes_okf.py`) and establishes `/opt/data` as the working directory. Unprivileged runtime mapping (`PUID=1000`, `PGID=1000`) is managed dynamically by s6-overlay at boot.
- [`docker/hermes/server.py`](file:///home/patternsatscale/ProjectTitan/docker/hermes/server.py): **DELETED**. Fully retired the bespoke 1,140-line prototype HTTP server and unauthenticated endpoints.
- [`config/hermes/config.yaml`](file:///home/patternsatscale/ProjectTitan/config/hermes/config.yaml): **NEW**. Pre-configured Hermes Agent configuration template specifying custom OpenAI-compatible provider (`http://proxy.local:4000/v1`), default model `titan-core`, and WAL SQLite settings.

### Messaging Gateways & Topology Separation
- [`docker-compose.yml`](file:///home/patternsatscale/ProjectTitan/docker-compose.yml):
  - Added companion service `signal-cli` (`bbernhard/signal-cli-rest-api:latest`) running in JSON-RPC daemon mode on the isolated `titan-internal` network.
  - Bound Signal session keys and registration state strictly to `${TITAN_WORKSPACE_DIR}/signal`.
  - Added `proxy.local:host-gateway` to `extra_hosts` and configured `OPENAI_BASE_URL=http://proxy.local:4000/v1` to isolate backend infrastructure names from agent context (Rule 7).
  - Updated `hermes` service to expose ports `8642` (API) and `9119` (Web Dashboard), and injected Signal and Telegram environment hooks (`SIGNAL_HTTP_URL`, `SIGNAL_ACCOUNT`, `SIGNAL_ALLOWED_USERS`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USERS`).
- [`config/caddy/Caddyfile`](file:///home/patternsatscale/ProjectTitan/config/caddy/Caddyfile): Updated `hermes.titan.local` reverse proxy target to `hermes:9119`, directly serving the official Nous Research Hermes Web Dashboard with internal TLS and compression.
- [`.env.example`](file:///home/patternsatscale/ProjectTitan/.env.example): Added `HERMES_DASHBOARD_PORT=9119`, dashboard local basic auth credentials, Signal configuration variables, and Telegram bot token variables.

### Operational Scripts & Verification
- [`scripts/setup-hermes.sh`](file:///home/patternsatscale/ProjectTitan/scripts/setup-hermes.sh): Automated scaffolding for `${WORKSPACE_DIR}/signal` and `${WORKSPACE_DIR}/skills`, seeded `config.yaml`, pulled companion images, and compiled `titan-hermes:latest`.
- [`scripts/verify-hermes.sh`](file:///home/patternsatscale/ProjectTitan/scripts/verify-hermes.sh): Updated verification harness to validate Hermes Web Dashboard (port 9119 HTTP 200/302), Signal-CLI daemon connectivity on `titan-internal`, `proxy.local:4000` gateway reachability, Zero Docker Socket presence, and Memory Plane purity.
- [`scripts/verify-memories.sh`](file:///home/patternsatscale/ProjectTitan/scripts/verify-memories.sh): Migrated note parsing and rule synthesis checks from deprecated `server.py` HTTP endpoints to the native `hermes_okf.py` CLI plugin.
- [`README.md`](file:///home/patternsatscale/ProjectTitan/README.md): Aligned directory tree and Phase 2 system specifications with the upstream Hermes Agent and messaging channels.
