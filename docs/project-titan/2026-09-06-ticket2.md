## 1. Summary of Changes

### Native Host Control Plane & Inference Architecture
- [`scripts/setup-host.sh`](file:///Users/pats/Development/project_titan/scripts/setup-host.sh): Enhanced with cross-platform OS detection (macOS via Homebrew, Ubuntu/DGX OS on ASUS GX10 via official installer) for native Ollama inference and automated `uv`/Python virtual environment setup for LiteLLM. Added native model seeding logic (`--pull-model`).
- [`scripts/start-control-plane.sh`](file:///Users/pats/Development/project_titan/scripts/start-control-plane.sh): New control plane service manager to start, stop, monitor, and restart host Ollama (`127.0.0.1:11434`) and LiteLLM proxy (`0.0.0.0:4000`) with health checks and PID management.
- [`config/litellm/config.yaml`](file:///Users/pats/Development/project_titan/config/litellm/config.yaml): Reconfigured `api_base` to host loopback (`http://127.0.0.1:11434`), mapped `titan-core` alias to `ollama_chat/gemma2:2b`, enforced hardware serialization (`max_parallel_requests: 1`), and configured native master key validation via `HERMES_LITELLM_KEY`.

### Docker Topology & Network Boundaries
- [`docker-compose.yml`](file:///Users/pats/Development/project_titan/docker-compose.yml): Removed containerized `ollama` and `litellm` services, eliminating multi-gigabyte container overhead and enabling native GPU/Metal acceleration. Configured `caddy` and `hermes` containers with `extra_hosts: ["host.docker.internal:host-gateway"]` to route control plane traffic to `http://host.docker.internal:4000/v1`.
- [`config/caddy/Caddyfile`](file:///Users/pats/Development/project_titan/config/caddy/Caddyfile): Updated reverse proxy upstream for `proxy.titan.local` to `host.docker.internal:4000`. Formatted and validated Caddyfile.
- [`.gitignore`](file:///Users/pats/Development/project_titan/.gitignore): Added rules for `.venv/`, `venv/`, `__pycache__/`, and runtime control plane state (`data/control_plane/*`).
- [`data/control_plane/.gitkeep`](file:///Users/pats/Development/project_titan/data/control_plane/.gitkeep): Initialized control plane runtime directory.

### Documentation Alignment
- [`AGENTS.md`](file:///Users/pats/Development/project_titan/AGENTS.md): Updated **Rule 2: Inference Boundary** to codify native host inference on loopback `127.0.0.1:11434` with LiteLLM gateway isolation.
- [`README.md`](file:///Users/pats/Development/project_titan/README.md): Updated script directory listing and Phase 1 roadmap description to reflect the native host control plane.
