## 1. Executive Summary

Ticket #144 implements end-to-end operator onboarding, cryptographic session persistence, and bidirectional messaging integration for the **Signal Messaging Gateway** (`titan-net-signal-cli`), connecting the primary autonomous agent (`titan-agent-terrastella`) to authorized human operators via the encrypted Signal protocol.

### Core Architectural Achievements

1. **Dual-Protocol Gateway Multiplexer (`docker/signal/gateway_proxy.py` & `docker/signal/entrypoint.sh`)**:
   - **Protocol Divergence Solved**: The upstream `nousresearch/hermes-agent` built-in Signal adapter expects native `signal-cli daemon --http` endpoints (`/api/v1/check`, `/api/v1/events` Server-Sent Events, and `/api/v1/rpc` JSON-RPC 2.0), while operator onboarding, device linking, and QR code generation utilize `bbernhard/signal-cli-rest-api` (`/v1/qrcodelink`, `/v1/about`, `/v1/accounts`, `/v1/register`).
   - **Zero-Extra-Container Solution**: Implemented an internal `asyncio` reverse proxy inside the `titan-net-signal-cli` container listening on standard port `8080`.
   - **Smart Path Dispatch & Header Rewrite**:
     - Routes `/api/v1/*` directly to native `signal-cli daemon --http` running on `127.0.0.1:8082`, rewriting the incoming `Host` header to `127.0.0.1:8082` to satisfy `signal-cli` loopback host protection.
     - Routes all other traffic (`/v1/*`, `/v2/*`) to `signal-cli-rest-api` running on `127.0.0.1:8084`.
     - Maintains complete backward compatibility for Hermes agent configuration (`SIGNAL_HTTP_URL=http://signal-cli:8080`) while allowing REST and SSE/JSON-RPC protocols to coexist simultaneously.

2. **Operator Onboarding & QR Linking CLI (`scripts/setup/link-signal.sh`)**:
   - Built a standalone, idempotent operator onboarding utility supporting both linked-device mode (linking to an existing Signal account on iOS/Android/Desktop) and primary phone registration (SMS/voice challenge-response).
   - **Terminal ANSI QR Rendering**: Generates terminal ANSI QR codes using `python3 -m qrcode` so operators can link their mobile devices directly from SSH/terminal sessions without requiring an external browser.
   - Provides subcommand interfaces:
     - `--link [device_name]`: Generates device link URI, renders ANSI QR code, and awaits operator confirmation.
     - `--register <phone>`: Submits registration request for a new phone number (supports `--voice` for voice verification).
     - `--verify <phone> <code>`: Completes SMS/voice code verification.
     - `--status`: Inspects registered accounts, daemon status, and active links.

3. **Cryptographic Session Persistence & Memory Plane Purity (Rule 1)**:
   - Configured dedicated session key storage under `${TITAN_WORKSPACE_DIR}/signal` (`./data/workspace/signal` on development workstation, `/data/titan/workspace/signal` on GX10 appliance).
   - Container executes strictly under unprivileged UID `1000:1000` (`signal-api`).
   - **Rule 1 Enforced**: Signal session databases (`.db`), pre-keys, identities, and avatar caches reside strictly in workspace storage and are completely excluded from `/memories`.

4. **Declarative Fleet Manifest & Strict Operator Allowlisting**:
   - Updated `config/agents.yaml` and `config/agents.local.yaml` to declare `comms.signal` block for `terrastella`.
   - Updated `scripts/control/sync-agents.sh` to inject `SIGNAL_HTTP_URL`, `SIGNAL_ACCOUNT`, and `SIGNAL_ALLOWED_USERS` into container environments and seed Hermes `platforms.signal` configuration.
   - Hermes Signal adapter enforces strict sender allowlist validation (`dm_allow_from`), blocking unauthorized message envelopes from entering the agent execution pipeline.

5. **Automated Verification Harnesses**:
   - Created `scripts/verify/verify-signal.sh` covering 7 comprehensive verification stages (daemon health, accounts, internal network reachability, `/api/v1/check` HTTP 200, native JSON-RPC `/api/v1/rpc`, memory purity audit, Hermes adapter allowlist unit assertions, and zero manifest drift).
   - Enhanced `scripts/verify/verify-hermes.sh` with native `/api/v1/check` endpoint validation.
