## 1. Summary of Changes

This ticket establishes a clean, decoupled sub-agent architecture in Project Titan, resolving conversational persona contamination during autonomous web development while preserving full supervisory authority for the primary conversational agent.

### Personas & Canonical SOUL.md Directory Hierarchy
- **Hierarchical Reorganization**: Retired flat `config/hermes/personas/` and established the clean directory convention:
  - `/config/hermes/<agent_id>/SOUL.md` for primary agents.
  - `/config/hermes/<agent_id>/<subagent_id>/SOUL.md` for specialized sub-agents.
- **Created Canonical Primary Personas**:
  - `config/hermes/primary/SOUL.md`: Primary operations agent identity and sandboxing boundaries.
  - `config/hermes/football-dan/SOUL.md`: Sports analytics companion identity and data boundaries.
  - `config/hermes/cindy-pawford/SOUL.md`: Cindy Pawford primary conversational voice and Creative Director orchestrator directives (supervision of `/app/html`, community ideation, structured delegation via `build_website_feature`, zero code pollution, witty fan reporting).
- **Created Specialized Sub-Agent Persona**:
  - `config/hermes/cindy-pawford/web-developer/SOUL.md`: Dedicated Website Builder software engineering persona with zero conversational banter, zero roleplay, zero barking/bacon humor, standards-compliant HTML5/CSS/JS, and artifact purity rules.
- **Removed Legacy Flat Personas**:
  - Deleted `config/hermes/personas/cindy-pawford.md`, `primary.md`, and `football-dan.md`.

### Generic Fleet Manifest & Synchronization (`config/agents.yaml` & `scripts/control/sync-agents.sh`)
- **`config/agents.yaml`**:
  - Updated all agent units to reference `config/hermes/<agent_id>/SOUL.md`.
  - Added generic `subagents` fleet manifest schema under `cindy-pawford` with `id: web-developer`, `tool_name: build_website_feature`, dedicated `SOUL.md`, target directory `/app/html`, parameter schemas, and `web_code` quality gates.
  - Updated `daily-feature-drop` cron prompt to direct Cindy as Creative Director to formulate technical requirements and invoke `build_website_feature`.
- **`scripts/control/sync-agents.sh`**:
  - Updated persona seeding to copy canonical `SOUL.md` files.
  - Added subagent synchronization: seeds subagent `SOUL.md` into `${MEM_DIR}/subagents/<sub_id>/SOUL.md` and `${WORK_DIR}/subagents/<sub_id>/SOUL.md`.
  - Renders declarative `subagents.json` catalog in workspace and memory partitions.
  - Scaffolds `titan-subagents` plugin into `${WORK_DIR}/plugins/titan-subagents/`.
  - Updated SilverBullet PKM index to link primary and subagent SOUL files.
  - Maintained zero drift (`--check` passes 100%).

### Sub-Agent Execution Engine & Quality Gate Sanitizer
- **`scripts/apps/cindypawford/cindy-web-builder.py`**:
  - Standalone Python module and CLI execution engine for the website builder sub-agent.
  - Accepts parameters: `--feature-name`, `--specification`, `--target-files`, `--design-tokens`, `--canvas-dir`, `--model`, `--dry-run`.
  - Enforces automated quality gate & artifact sanitization:
    - Strips Markdown code fences (` ``` `) from raw file writes.
    - Strips conversational preambles/postscripts.
    - Checks for persona leakage markers.
    - Validates JavaScript syntax with `node -c`.
  - Generates git diffs and records human-auditable OKF logs in `/memories/logs/YYYY-MM-DD-<slug>.md` (Rule 1).
- **`docker/hermes/plugins/titan-subagents/`**:
  - Generic Hermes backend plugin (`plugin.yaml`, `__init__.py`).
  - Reads `subagents.json` and dynamically registers native Hermes tools (`build_website_feature`) with parameter schemas, delegating execution to the sub-agent engine.

### Host-Local Manifest Override & Dynamic Verification
- **`.gitignore`**: Added `config/agents.local.yaml` and `config/agents.override.yaml` so developers can maintain host-specific agent manifests without risk of merge conflicts or overwrite by `git pull`.
- **`scripts/control/sync-agents.sh`**: Supports `MANIFEST_FILE` override and automatically falls back from `config/agents.local.yaml` to `config/agents.yaml`.
- **`scripts/verify/verify-fleet.sh`**: Step 1 validates both the canonical open-source manifest (`config/agents.yaml`) and the host-local manifest (`config/agents.local.yaml`), ensuring zero drift across both.
- **`config/hermes/terrastella/SOUL.md`**: Created persona for host-local primary agent identity.

### Automated Issue Assignment to Project "In Progress"
- **`.github/workflows/project-issue-assigned.yml`**: GitHub Action triggered on `issues: [assigned]`. Automatically queries the issue's GitHub Projects (v2) item, locates the single-select `Status` field option for "In Progress", and runs the GraphQL mutation `updateProjectV2ItemFieldValue`.

### Operational Guardrails & Verification
- **`AGENTS.md`**:
  - Added **Rule 11: Sub-Agent Persona Isolation & Code Quality Protection**.
- **`README.md`**:
  - Updated architecture diagram and directory tree to reflect the `/config/hermes/<agent_id>/SOUL.md` and `subagents/` hierarchy.
- **`scripts/apps/cindypawford/verify-cindy-agent.sh`**:
  - Updated Step 4 to assert primary `SOUL.md` and sub-agent `SOUL.md` isolation and purity.
  - Added Step 8: generic subagent manifest verification, execution dry-run test, quality gate sanitization unit tests, and plugin scaffolding checks.
