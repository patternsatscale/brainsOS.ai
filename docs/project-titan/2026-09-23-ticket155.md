## 1. Executive Summary

Ticket #155 establishes a **Split-Horizon (Split-Brain) DNS** and public wildcard SSL certificate architecture for Project Titan:
1. **Decoupled SST v3 Platform Cloud Infrastructure (`infra/`)**: Created a dedicated, decoupled SST v3 (Ion) platform cloud stack. It provisions Route 53 DNS records, an automated public CloudFront/Edge redirect for `titan.<domain>` to the open-source GitHub repository, least-privilege IAM credentials for Caddy's ACME challenge, and modular SES (Amazon Simple Email Service) domain identity building blocks (Easy DKIM, SPF, DMARC, and IAM send policies).
2. **Zero Domain Leakage & Local Execution Model**: To protect open-source repository privacy, neither `patternsatscale.com` nor production domains are hardcoded in committed code. All domain names and AWS configurations consume uncommitted local `.env` variables (`TITAN_ZONE_NAME`, `TITAN_DOMAIN`, `SES_DOMAINS`) with generic `example.com` fallbacks. Platform cloud deployments run exclusively via local operator CLI (`./scripts/setup/deploy-infra.sh`) with zero automated triggers in GitHub Actions.
3. **Native AWS Credential Chain & Namespaced Isolation**: Platform deployments seamlessly resolve credentials from the operator's configured AWS CLI environment (`~/.aws/credentials` and `~/.aws/config`) with zero requirement to hardcode access keys in `.env`. If custom overrides are needed, `TITAN_INFRA_AWS_ACCESS_KEY_ID`, `TITAN_INFRA_AWS_SECRET_ACCESS_KEY`, and `TITAN_INFRA_AWS_REGION` are supported, completely partitioning platform infrastructure audits from application keys.
4. **Caddy Route 53 ACME DNS-01 Plugin**: Replaced the base Caddy image with a multi-stage Docker build (`docker/caddy/Dockerfile`) compiled with `xcaddy build --with github.com/caddy-dns/route53`, enabling native wildcard TLS without exposing any open inbound router ports to the internet.
5. **Dynamic TLS Policy & Localhost Preservation**: Updated `scripts/control/sync-agents.sh` to dynamically compile `config/caddy/tls_policy.caddy`. When using a public domain with Route 53, public routes invoke `import titan_tls` (`dns route53`). Localhost fallback routes (`*.localhost` and `127.0.0.1`) remain strictly bound to `tls internal` so ACME CAs are never asked to issue certificates for non-public domains.
6. **Automated Verification Suite (`scripts/verify/verify-dns-ssl.sh`)**: Added a 7-stage automated verification suite validating TypeScript types, dry-run deployment diffs, Caddy plugin binaries, Caddyfile syntax, localhost fallback preservation, and dual-mode fleet sync zero-drift.
