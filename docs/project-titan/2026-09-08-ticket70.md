## 1. Summary of Changes

### Native Hermes Plugin: `hermes-okf`
- [`docker/hermes/plugins/hermes-okf/plugin.yaml`](file:///home/patternsatscale/ProjectTitan/docker/hermes/plugins/hermes-okf/plugin.yaml): **NEW**. Upstream-compliant plugin manifest defining name (`hermes-okf`), version (`1.0.0`), kind (`backend`), and provided tools (`read_okf_note`, `write_okf_note`, `synthesize_active_rules`).
- [`docker/hermes/plugins/hermes-okf/okf.py`](file:///home/patternsatscale/ProjectTitan/docker/hermes/plugins/hermes-okf/okf.py): **NEW**. Modular Open Knowledge Format engine managing `/memories/knowledge`, `/memories/rules`, and `/memories/logs`. Enforces Rule 1 (Memory Plane Purity: flat Markdown only, zero binary or database artifacts, path traversal protection) and Rule 7 (Information Compartmentalization: zero host database or infrastructure leakage).
- [`docker/hermes/plugins/hermes-okf/tools.py`](file:///home/patternsatscale/ProjectTitan/docker/hermes/plugins/hermes-okf/tools.py): **NEW**. Native tool schemas and handlers:
  - `read_okf_note`: parses YAML frontmatter metadata and extracts Markdown body.
  - `write_okf_note`: atomic file persistence enforcing purity and schema constraints.
  - `synthesize_active_rules`: synthesizes active directives into a prioritized, token-budgeted prompt context.
- [`docker/hermes/plugins/hermes-okf/__init__.py`](file:///home/patternsatscale/ProjectTitan/docker/hermes/plugins/hermes-okf/__init__.py): **NEW**. Plugin entrypoint implementing `register(ctx)` to register the three native tools into Hermes Agent's global `tools.registry`. Also exposes `HermesOKFMemoryProvider` implementing the upstream `agent.memory_provider.MemoryProvider` interface.
- [`docker/hermes/hermes_okf.py`](file:///home/patternsatscale/ProjectTitan/docker/hermes/hermes_okf.py): **DELETED**. Eliminated the legacy 516-line standalone script to eliminate technical debt.

### Runtime Configuration & Container Image

- [`config/hermes/config.yaml`](file:///home/patternsatscale/ProjectTitan/config/hermes/config.yaml): Added `plugins.enabled: [hermes-okf]` to ensure the plugin auto-loads on container boot.

### Operational Scripts & Verification Harness
