## 1. Summary of Changes

This ticket resolves two critical bugs identified in the Cindy Pawford digital museum archive and ingestion pipeline:
1. **Preventing Project-Titan PR Ingestion**: Previously, when `.github/workflows/deploy-sst.yml` ran on `patternsatscale/project-titan` (e.g. merging PR #136), `ingest-pr-logbook.py` inspected `GITHUB_EVENT_PATH` without verifying repository origin, causing `project-titan` PRs to be ingested into the Cindy Pawford archive and scoreboard.
2. **Clarifying Canonical Eras vs. Incremental Pull Requests**: Previously, PR #13 (*"The Ten"*) was categorized as `"new-era"`, blurring the architectural boundary between weekly/wipe macro Eras (e.g. Era 0: Genesis, Era 1: The Golden Hour Gala) and incremental code releases / room expansions.

  - Added `data-is-pr` and micro-indicator pills (`★ CANONICAL ERA` vs `📦 PULL REQUEST`) to timeline entries.
