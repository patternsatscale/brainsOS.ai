## 1. Executive Summary

Ticket #92 implements **CW-0A.1** by isolating Cindy Pawford's public HTML canvas from her private agent runtime environment and binding her canvas to the dedicated external repository [`patternsatscale/CindyPawford-Online`](https://github.com/patternsatscale/CindyPawford-Online).

Key achievements:
1. **Explicit Three-Way Mount Topology**:
   - `/workspace` & `/opt/data` bind to `./data/workspace/cindy-pawford` (Hermes home, custom skills, cron jobs, `user.md`, state).
   - `/app/html` binds to `./apps/cindypawford/site` (dedicated public web canvas).
   - `/memories` binds to `./data/memories/agents/cindy-pawford` (pure OKF Markdown journals, rules, and logs).
2. **Zero Amnesia Guarantee**: Erasing or resetting `/app/html` during weekly era transitions leaves all skills, tools, user state, and episodic memories in `/workspace` and `/memories` completely untouched.
3. **GitHub CLI (`gh`) & Git Provisioning**: Added `gh` and `git` to `docker/hermes/Dockerfile` with container-safe defaults (`safe.directory '*'`, credential helper `!gh auth git-credential`).
4. **Environment Secret Injection with Fallback**: Injected `GH_TOKEN` and `GITHUB_TOKEN` from `GITHUB_TOKEN_CINDY` into `docker-compose.agents.yml` along with Git author identity (`Cindy Pawford <cindy@cindypawford.com>`).
5. **Dedicated Repository Binding**: Initialized and pushed the vanilla web canvas (`index.html`, `styles.css`, `app.js`, `assets/`) to `https://github.com/patternsatscale/CindyPawford-Online`, cloned it into `apps/cindypawford/site`, and decoupled it from `project-titan` tracking via `.gitignore`.
6. **Comprehensive Automated Verification**: Created `scripts/verify-cindy-canvas.sh` validating boundary separation, GitHub CLI authentication, remote branch push, and sandbox invariants.
