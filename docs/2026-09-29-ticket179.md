## 2. Acceptance Criteria Verification

- [x] **Multiple jobs for Thread A queued simultaneously are processed sequentially (one after another)**:
  - Validated by `test_sequential_execution_same_partition` and `test_worker_fifo_partition_execution_timeline`.
- [x] **A job for Thread B executes in parallel alongside Thread A without blocking**:
  - Validated by `test_concurrent_execution_distinct_partitions`: Worker 2 skips blocked Thread A tasks and immediately executes Thread B.
- [x] **Partition locks automatically expire after 120s if a worker crashes without releasing**:
  - Validated by `test_partition_lock_lease_expiration_and_reclaim`: Crashed worker leases expire, status reclaims to failed for retry, and subsequent tasks proceed without deadlocks.
- [x] **Unit test coverage validates FIFO ordering and multi-thread concurrency**:
  - All 6 tests in `test_partition_lock.py` pass cleanly.
- [x] **Rule 1 (Memory Purity)**:
  - Attempting to place SQLite queues in `/memories` or `agent_memories` raises `ValueError` (`test_rule1_memory_plane_purity`).
